# 测算模型设计说明 · 居住服务模块化单元经济

**选题 2**：从"一名经纪人包办一单"到客户管家×懂盘者×履约模块——居住服务进入「专业角色可拆分、可验证、可单独付费」时代？

**设计时间**：2026-08-25 · 智见点评团队（杨现领/柴强/廖俊平/徐斌）融合研判后落地
**口径说明**：模型数字均为研判推演（标注「研判推断」），客户管家数据为单源内部样本；验证协议（2 万线索 RCT）出结果前不可外推为结论。

---

## 一、模型目标

回答专家团的核心判断：**模块化服务的增量价值（决策质量↑+经纪人收入↑+平台利润↑）是否高于协同成本（分账复杂度、搭便车、激励扭曲）？**

- 若「模块贡献毛利 > 协同成本」→ 模块化可扩张（GO）
- 否则 → 只保留客户管家岗位，不进入"可单独付费"（NO-GO）

## 二、模块链与参数（据专家研判共识）

| 模块 | 角色 | 价值锚点 | 计费方式（假设） |
|---|---|---|---|
| M1 顾问/咨询 | 客户管家 | 决策质量（删选项、避坑） | 咨询费（与成交脱钩） |
| M2 信息/懂盘 | 懂盘者 | 房源深度数据、盘面判断 | 订阅/单次报告 |
| M3 撮合/带看 | 带看撮合 | 匹配效率 | 按带看计费 |
| M4 履约/签约 | 签约专员 | 交易安全、流程合规 | 按单固定费 |
| M5 报告/评估 | 报告模块 | 书面报告、披露合规 | 单份计费 |
| M6 售后/改造/租赁管家 | 服务延伸 | 装修、租后运营 | 项目制/月度 |

**基准参数（研判假设，非实测）**：
- 单线索成本（获客+AI 维护）：C_lead = 60 元（研判推断）
- 客户管家组转带看率：7.4%（内部样本，单源）；大盘 5%
- 带看转签率：基准 15%（研判推断，参考行业区间）
- 单均佣金（二手）：2.0% × 300 万 = 6 万元/单
- 平台贡献利润率（Q2 实测）：14.6%
- 模块化分账结构：顾问 15% / 信息 10% / 撮合 20% / 履约 25% / 报告 5% / 平台与售后 25%（假设合计 100%）
- 协同成本（分账系统+责任扯皮+培训）：按佣金的 8%（研判推断）

## 四、结论判定规则（写入模型）

1. **扩张闸门**：模块贡献毛利 > 0 且「删选项后满意度」不降（杨现领补充：转化率仅参考）
2. **一票否决**：责任事故归责清晰度不达标（徐斌补充：RCT 增加该否决项）
3. **窗口期**：12-18 个月（廖俊平研判），零佣平台铺开会压缩总收费盘，试点需毛利安全垫

- 所有参数均为研判假设，非实测；2 万线索 RCT 出结果前仅供决策讨论
- 单源数据（客户管家 7.4%）已标注，不得升级为结论
- 与既往报告（沪八条单元经济、零押金月付）参数不混用
