# 把非金融入口变成金融闭环——学习宁波银行"波波知了+数字人力"双平台、加快江苏银行经营模式升级的行领导汇报稿（正式稿）

## 一、核心观点【关键性结论】

**宁波银行双平台的本质，是"资金中介向资源中介升级"在客户经营体系上的完整落地：以企业任务链为入口，先交付非金融价值，再沉淀代发、财富、结算等银行业务。方向正确、路径可行、窗口期紧迫，我行应"靠前发力、能早则早"，以"一套底座、两条主线、三个闭环、90天双场景试点"尽快启动，用业务沉淀说话。**

五个基本判断：

1. 财务已经验证了逻辑。宁波银行2026H1营收+11.54%、归母净利+12.12%，两项收入增速18.2%（高出我行约7个百分点）；最关键的是结构：手续费净收入+53.9%、中收占比10.42%（城商行第二家破10%）、代理类收入49.9亿元占中收85%。双平台沉淀的正是"代理类中收+低成本负债"这两个低利率低息差时代最稀缺的东西。
2. 三低时代，平台是负债端的胜负手。宁波存款成本率2026H1降至1.32%（上半年降39bp）、活期占比35.57%。息差收窄靠规模补不回来，靠负债成本补得回来——这是双平台最硬的账。
3. 差距在结构，不在规模。我行与宁波的差距不是资产规模之差，而是客户经营深度之差：私行AUM我行2552亿元、占总AUM 13.9%，宁波4206亿元、占29.4%；对公理财我行658亿元，宁波2000亿元以上；代理类收入我行比宁波少29.1亿元。客户结构决定收入结构，收入结构决定增长质量。
4. 我行禀赋不差，缺的是组织机制。苏银生活月活800万（年底目标1000万）、全省网点与政府园区关系、制造业大省的政银协同条件，都是现成的底座。缺的不是客户、不是场景，而是"独立运营、价值先行、考核沉淀"的组织机制。
5. 建议按"一套底座、两条主线、三个闭环、90天试点"推进，组织上项目制独立运作，考核转向业务沉淀；严守三条底线：不突破风险底线换业绩、不层层加码、不把平台做成摆设。

## 二、宁波公开定位【关键事实及其变化】

按定稿口径，双平台按**企业任务链分工**，同一企业可同时使用：

- **波波知了＝企业外部经营与综合企服（偏经营侧）**：经营赋能、资源对接、企业家服务。官方口径为"波波知了"企业综合服务平台，公开资料显示已服务17.6万家企业、提供20+项服务。2023年上线，独立运营的非金融平台，团队自阿里、字节社招、base上海、单岗年薪百万级；"帮企业赚钱/省钱/管钱"三层框架，聚焦江浙沪制造、科技、外贸型企业，提供出海对接、节能规划、AI赋能；经政府园区、招商部门联动获客。
- **数字人力平台＝企业内部组织运营与人薪税费（偏组织侧）**：HR、代发、五险一金、报销、供需撮合。为近期另行打造的新平台（非波波知了子集），定位"只撮合、不交付、不收服务费"，计划2026年底上线；量子教育拟以服务商身份入驻、用户购课9折。公开渠道已有"数字人力3.0/4.0"产品形态，其与会议所述新平台形态是否等同，未经访谈核实，**待核实**——决策依据不得建立在未核实事实上。

关键事实的财务印证（2026H1）：营收+11.54%、归母净利+12.12%；手续费净收入+53.9%、中收占比10.42%、代理类收入49.9亿元占中收85%；计息负债成本率1.43%（降36bp）、存款成本率1.32%（降39bp）、活期占比35.57%；拨贷比2.83%、拨备覆盖率373.35%；私行客户3.45万户、私行AUM 4206亿元占29.4%；对公理财2000亿元以上。我行对照：两项收入增速11%、私行AUM 2552亿元占13.9%、对公理财658亿元、代理类收入少29.1亿元。

## 三、经营逻辑【归因分析】

**逻辑链条：非金融平台独立运营（不与信贷捆绑，降低企业戒心）→ 高频服务建立信任与数据沉淀 → 自然引导至金融闭环（代发、财富、对公理财、私行）→ 低成本负债与中收双增。先有企业服务关系，后有资产负债表。**

五个归因：

1. 经营范式：从"分客分层"到"任务链全程经营"。波波知了管企业"对外做生意"，数字人力管企业"对内管人管钱"，两端都嵌入企业日常，金融业务成为任务链上的自然环节而非推销动作。
2. 价值逻辑：先帮企业赚钱省钱管钱，再谈银行业务。非金融价值是获客与活客的"钩子"，金融转化是价值的自然变现。
3. 组织机制：独立运营+市场化团队。宁波把平台当"公司"办而不是当"部门"办，市场化薪酬、互联网打法、非金融主体身份，是平台能做成的组织前提。
4. 客群纪律：行业研究驱动的区域聚焦。聚焦江浙沪制造、科技、外贸，与区域禀赋咬合，不追求覆盖一切企业，追求把一类企业做深。
5. 政银协同制度化：政府园区、招商部门联动获客，园区既是场景又是信任背书，这是单靠客户经理做不到的。

财务端的印证是完整的：代理类收入49.9亿元占中收85%，对应私行AUM 4206亿元（占29.4%）与对公理财2000亿元以上的财富底盘；存款成本率1.32%、活期占比35.57%，结算与代发资金在体系内循环；拨贷比2.83%、拨备覆盖率373.35%，平台扩张没有以风险换增长。

## 四、我行启示

**学宁波，学的不是两个App，而是三件事：任务链经营的客户观、先价值后业务的产品观、独立运营与政银协同的机制观。**

1. 客户经营体系完成三个转变：从分层经营转向任务链经营（严禁"高端/中低端客户分层"表述，同一客户可同时接入经营、组织两条链）；从产品推销转向价值先行（苏银生活800万月活若只用来发权益、卖产品，就仍是资金中介打法）；从单点获客转向生态获客（把消费贷团办、信用卡课程权益、私行C9联培等散点，串成平台体系）。
2. 资金中介向资源中介升级是唯一正确的方向。宁波已证明：这条路径在城商行场景下可复制、可盈利、可持续。
3. 政银协同制度化——江苏禀赋优于宁波。江苏制造业园区密度、政府招商体系完备度不输浙江，要把"领导拜访式协同"升级为"机制化平台化协同"，把江苏制造业园区做成主场。
4. 经营与管理双提质。学宁波若只学平台不学机制，就会重经营轻管理，提质成为口号。

## 五、建议方案

**总体架构（已定稿）：一套企业服务能力底座＋企业经营服务/组织员工服务两条主线＋三个金融闭环＋90天双场景试点。**

1. **一套底座**：企业服务能力底座——整合苏银生活既有月活与政府园区/招商渠道，聚合内外部服务商（含量子教育等）、AI能力、园区与政府接口，统一企业身份与数据治理（行内商密仅聚合口径），底座先行、场景后挂。
2. **两条主线**：企业经营服务线（对标波波知了：出海对接、节能规划、AI赋能、资源对接，聚焦江苏制造/科技/外贸企业）；组织员工服务线（对标数字人力：HR工具、代发、五险一金、报销、供需撮合，"只撮合不交付"的边界先行试点）。
3. **三个金融闭环**（把服务变资产）：
   - 培训代发闭环：企业培训服务（量子教育9折权益）→ 员工以我行卡代发工资+课程权益（信用卡拟嵌365元/年权益）→ 沉淀代发与活期；
   - AI出海闭环：出海对接/AI赋能 → 跨境结算、贸易融资、汇率避险 → 对公+企业家个人跨境金融；
   - 企业家圈层闭环：企业家服务（资源对接、商学院联培，叠加私行C9联培基础）→ 私行与家族财富转化，直击私行AUM占比13.9% vs 29.4%的结构短板；对公理财作为贯穿性承接产品。
4. **渠道协同（"一重两轻"）**：轻渠道高频承接企业简易需求并沉淀数据与账户，复杂金融需求（企业贷款、企业家私行、家族财富）经全旅程智能体自动派单至客户经理/私行中心闭环，建设统一线索流转与智能派单机制，防止渠道割裂退化为孤岛App。
5. **AI与数据**：数据治理先行（企业数据授权采集、分级分类、脱敏与用途限定），在授权前提下将平台经营行为数据纳入智能信贷评估与财富营销；数据治理是AI上线的前提，不是后续补课。

## 六、90天双场景试点

**双场景：场景A＝制造型企业培训代发闭环（组织侧，借力量子教育等服务商）；场景B＝科技/外贸型企业AI出海对接闭环（经营侧，南京或苏州园区联动）。先行地区建议南京或苏州。90天只验证"闭环能否成立"，不铺摊子；验证通过后按季度滚动放量。**

时间节奏：
- **第1-30天（搭台）**：底座MVP上线，完成服务商准入与合规审查；签约试点企业≥30家、服务商入驻≥10家。
- **第31-60天（跑通）**：两条主线各跑通1个完整"服务→金融"转化案例；签约代发≥20家、新增代发人数≥3000人、沉淀代发月额≥3000万元；苏银生活导流页面上线。
- **第61-90天（验证）**：试点企业金融产品渗透率≥40%、沉淀对公存款≥1亿元、私行线索≥50条、企业家圈层活动≥2场；形成《双平台试点验证报告》，同步启动数字人力服务商模式对接（2026年底上线窗口倒排）。

**验收口径**：以业务沉淀为准——企业用户数、代发签约与留存、对公理财/私行转化、活期沉淀、中收贡献，而非平台注册数。过程观察指标：代发90天留存率≥85%、信用卡绑卡率≥30%、课程权益核销率≥15%、试点获客成本较对照组降低30%以上、客户满意度NPS≥40。**以上目标均为测算建议值，立项时按实际资源校准。**

## 七、组织、考核与风险

**组织**：项目制独立运作，参照宁波"产品公司"模式组建产品、运营、技术、合规四线合署的敏捷团队，赋予市场化用人空间（宁波单岗年薪百万级为参照系，我行按行内薪酬体系适配，试点期薪酬可按市场50-70%区间起步、绑定里程碑考核——测算建议值）；明确平台"非金融运营主体"的合规身份。

**考核**：转向业务沉淀——考核代发签约数、活期沉淀、私行/对公理财转化、中收贡献，与分行业绩双算，避免与现有条线争利内耗；平台本身允许短期不盈利；严禁把提质曲解为层层加码、只看短期规模排名。

**合规红线（前置）**：①非金融服务与金融业务边界严格隔离，服务不捆绑信贷、不承诺收益，严禁变相吸储；②数据合规：企业及员工个人信息采集遵循授权明确、最小必要、用途限定，符合个保法与征信业务管理要求，跨境数据传输过安全评估；③服务商准入、外包管理与消费者权益保护审查会签，"只撮合不收服务费"模式的合规边界由法务专项评估；④代发与结算链路落实身份识别与反洗钱监测；⑤对外宣传不使用"客户分层"口径。

**风险提示（边界条件）**：①平台培育期≥18个月，考核周期必须与投入周期匹配，考核短期化易半途而废——若90天试点转化率显著低于测算值，节奏应下修为半年一评；②数据治理滞后会导致AI"无米下锅"；③渠道割裂（线索不回流、客户经理不承接）是最大执行风险，须以统一派单机制前置防控；④"数字人力"公开产品与2026年底新平台形态是否等同待核实，若确认存在合规瑕疵，组织侧上线需推迟。

## 八、提请决策事项

1. 批准设立企业服务平台专项项目组（项目制独立运作），明确牵头行领导与跨部门授权，核定首期预算（建议500-800万元，含系统建设、运营与人才引进——测算建议值）；
2. 批准90天双场景试点方案与量化目标（30家签约/20家代发/3000万元月代发额/40%渗透率/1亿元沉淀存款为建议目标值）及先行地区（建议南京或苏州）；
3. 批准"业务沉淀"导向的考核办法与分行双算机制，明确试点期容错边界；
4. 授权与量子教育等外部服务商的合作模式谈判（入驻、权益分成、数据边界），提交合规与消费者权益保护审查；
5. 要求法务合规部出具撮合平台与金融业务边界、个人信息保护专项意见，并核实"数字人力"公开产品与新平台的关系（消除待核实项）。

## 九、结论【收尾】

宁波银行用三年时间证明了一件事：银行可以不是金融产品的货架，而是企业经营的基础设施。双平台的意义不在17.6万家企业的规模，而在"任务链经营"证明了一条在三低时代可持续的增长路径——中收占比破10%、存款成本率降至1.32%、拨备覆盖率373.35%依然厚实。对江苏银行而言，这不是一道抄作业的题，而是一道组织变革的题：我们拥有苏银生活800万月活、全省园区政银关系和制造业大省的客户禀赋，比宁波更具备把平台做大的土壤。把方便留给客户，把复杂留给自己——建议按"一套底座、两条主线、三个闭环、90天试点"尽快启动，靠前发力、能早则早，让试点说话，让沉淀算数。
