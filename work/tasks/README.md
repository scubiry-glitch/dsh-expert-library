# 任务目录规范（Task Directory Convention）

> 约定：**每做一个任务，新建一个 task 目录，该任务涉及的所有文件都在此目录内完成。**
> 适用：本工作区（`/root/zhijian/dsh-expert-library/work/`）下的一切任务性工作。

## 目录规则

```
work/
└── tasks/
    └── task-<YYYYMMDD>-<任务 slug>/     # 每个任务一个目录
        ├── README.md                    # 任务目标、结论、应用/验证方式（必填）
        ├── <产出物>                      # 本任务产生的文件（补丁、文档、分析、中间产物）
        └── sources/                     # （可选）涉及的外部文件引用/快照
```

- 命名：`task-<日期>-<英文或拼音 slug>`，slug 用 `-` 连接、全小写。
- 自包含：任务目录内必须有 README 解释"这个任务做什么、结果是什么、怎么用"；所有与任务相关的文件都放进来，不散落工作区根目录。
- 涉及插件源码（`/root/zhijian/dsh-expert-library/src/` 等，位于工作区之外）的修改：受沙箱限制**不能直接改源码**，任务目录内放置补丁脚本/替换对/完整说明，记录"待应用"或"已应用"状态。
- 复用/遗留：一个任务一个目录，完成后登记到下方表格；新任务不重复使用旧目录。
