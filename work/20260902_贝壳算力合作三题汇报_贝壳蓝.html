硅基流动 与 无问芯穹 扮演类似角色：组织 token 工厂与算力中间层，模型厂生态战的"招商代理"。

DeepSeek：自建路线

心态 自建 DC、自建推理，全栈自己掌握。

算力业主"新地租"逻辑 × 国产卡换代窗口

token 工厂 / 业主的两类玩家

① 国企 / 上市公司 诉求是把旧"地租"换成"新地租"——算力租赁本质是财政行为；上市公司为市值与利润表哪怕亏钱也干。

② 特殊背景型 以"趋境科技"为代表，资源与订单能力另成一系。

例证：无锡 token 工厂开业两个月即达 80% 满租率，省领导站台支持——地方对算力中心的重视程度堪比当年土地招商。

显卡厂商：以摩尔线程为例

上一代 表现较弱，华为同期产品同样拉不开差距。

这一代 S5000 已完成最新测试，正准备大规模采购，预计年底可达生产可用状态。

对本合作的含义：自建推理的规模放量节奏应卡在国产卡换代窗口（年底）之后，此前以 API 路由为主。

国产卡 vs 非国产：两个特点

① 任务定位 擅长承担 PD 分离架构中 P（Prefill）部分等确定性负载——复杂任务的执行分工。

② 经济性 效能较差，回本周期普遍比非国产卡长很多。

对谈判的含义

业主端是财政逻辑不是市场逻辑：要的是长期稳定的租金与叙事，不追求短期回报——算力租赁价格与租期有较大让利空间，这是我方议价筹码；国产卡回本慢则是压租价的另一个支点。

Token 工厂三类玩家：以趋境科技看"创业型"

① 国企 / 上市公司型

旧地租换"新地租"，算力租赁是财政行为；上市公司为市值哪怕亏钱也干。优势：资源与订单；短板：效能与运营。

② 特殊背景型

清华系等特殊资源背景（趋境科技的清华+智谱星连基因兼具此属性）。优势：拿卡与政企通道；短板：技术纵深参差。

③ 创业技术型（趋境科技）

靠推理效能优化立足，技术代差换市场。优势：单位算力产出最高；短板：无资源兜底、靠融资扩张。

创业型画像：趋境科技（Approaching.AI）

· 定位"AI Token 生产服务商"：ATaaS（Token 即服务），交付生产环境推理效能，不是传统 MaaS 卖调用。

· 技术底座：清华高性能计算所（郑纬民院士团队）成果作价入股；"少模型、深优化"，稳定 TTFT + 30–50 TPS 高速输出。

· 生态位：KTransformers（17k Star）是 GLM / Kimi / MiniMax / Qwen 首发推荐推理引擎；服务智谱、月之暗面等客户，日均处理 Token 近万亿。

· 资本：Pre-A 由星连资本（智谱系）与华控联合领投，A 轮后半年累计融资超 10 亿。

创业型的四个优势（以趋境为例）

技术代差 推理引擎社区话语权（SGLang/vLLM/Dynamo 深度参与），单位 token 成本低于同行。

生态绑定 智谱系资本领投 + 首发引擎地位，订单随模型厂生态扩张自动增长。

对冲国产卡短板 效能优化直接缓解"国产卡效能差、回本周期长"的痛点——同样的卡产出更多 token。

市场化交付 稳定 TTFT/TPS 承诺对生产环境友好，是三类中唯一能直接服务外部付费客户的运营主体。

贝壳

出 脱敏数据非排他授权 · 采购量向合作通道迁移 · JV 股比让渡（待谈）

得 推理成本直降（≈5.0 折组合口径）· JV 按股比分润 · 国产合规底座 · "AI+房产数据"资本市场叙事

软肋 数据授权若无对价＝白送；控股诉求与"非排他"自相矛盾

合作方（业主 + 运营）

出 算力资本开支（卡/服务器）· 运营与 SLA 承担 · JV 平台建设

得 长期推理收入（阶梯锁定）· JV 股权 · 数据要素变现通道与政企客户故事

软肋 若数据非排他 + 贝壳控股，JV 无护城河，重资产投入无对价

待解死结与两条出路

"非排他数据授权" × "贝壳要控股"——合作方法务不会放行，这是全案核心谈判点。

出路 A 数据作价入股：评估机构对数据资产估值，折抵贝壳应缴出资，股比据此定。

出路 B 排他授权 + 对价：授权改排他（限不动产定价领域），贝壳以现金出资为主，数据换优先分成或 usage credit。

第二题 · 价格用量决策
决策建议

三个决策点：承诺什么、保护什么

① 承诺用量档位

按当前 ~1x 签，不为 4 折预承诺 10 倍

阶梯价（500 万 5 折 / 2,000 万 4.5 折 / 1 亿 4 折）本身内含保护：用量真涨自动降档。10–100 倍增长预测需场景清单支撑，否则按 3x 做资金规划。

② 可迁移流量

综合节省按 20–25% 上报，31% 为上限

Claude 占 60%，代码/复杂推理最难迁国产——报价单已解决"价格"但没解决"质量迁移"。建议 2 周 POC：DeepSeek/GLM 跑贝壳真实场景，实测可迁移比例再定口径。

③ 价格保护

MFN + 年度基准复核 + 退出权

直采牌价仍在年降、折扣战在打——两年后直采可能自到 5 折。条款必须：最惠客户价（MFN）＋每年对照厂商牌价复核＋合作价高于直采即触发重议或解约权。

建议决策

一期框架协议：以 8 月报价单为锚，起步价从 5.5 折压至 5 折以内（报价已证明可行），签 MFN + 阶梯自动降档 + 年度复核；4 折档留作用量兑现后的议价筹码，不做预承诺。

第二题 · 价格用量决策
价格形成机制 · 关键决策

价格形成机制：两个核心变量，四个关键决策

核心决策 = 采购价 × 量的预期；市场基准取万界方舟 8 月报价单（实际成交上下浮动）。

决策① 价格：由模型代际组合决定

市场价差的最大变量是代际：GLM-5.2（4 折）vs GLM-5.3（8 折），悬殊巨大。采购组合按场景选代际——常规场景走 5.2 代，旗舰需求限量走 5.3，避开"全上最新旗舰"的成本陷阱。

决策② 应用层优化：两道价差必吃

a. 海外算力 × 国内算力：同一任务可路由，价差巨大；b. 白天 × 夜间算力：错峰调度，谷时算力大幅折让。两道价差在路由层吃掉，是承诺价在代际组合下仍有利差的前提。

决策③ 预付款规模：撬动杠杆

预付款是谈价的核心筹码：4 亿量级足以撬动一个数据中心的建设（换深度折扣+供给优先权）；1 亿也能摊到较低价格，但杠杆弱。建议预付分档设计、与阶梯折扣和 SLA 强绑定。

决策④ Token 质量分层采购

趋境科技：稳定但贵、条款强势（高傲）；新转型上市公司（如安博通，已拿数亿资源）：短期稳定性差，但价格可压到市场均值 3.5 折以下。混合采购：关键业务走稳、非关键走低价，压低组合成本。

收口：采购价三个杠杆 = 代际组合 × 两道价差路由 × 质量分层，把真实成本压向 3.5–5.0 折带——利差即运营层利润，也是预付款谈判的底气；对外承诺价待代际组合定稿后锁定。

业务模式

三层协同：底座 × 内容 × 渠道

渠道层
公共事务线
toG/toB 通道：城投、住建、金融办、银行的现成客户关系与信任；灯塔客户引入、政策需求回流、30/60/90 汇报机制。PaaS 变现链的客户入口。
内容层
智见（专家引擎 + 可复现决策过程）
184 位专家（贝壳域 33 位）知识框架 × 当期目标城市 × 事实包数字锚定；两条首期商业主线：城投"不动产估值框架"、银行"T0 估值 + T+N 监测/预警"。JV 产品的方法论壁垒。
底座层
算力 JV + 运营公司
国产算力（中昊芯英 GPTPU）+ 多模型路由 + 不动产定价 PaaS——模型与数据产品在这里生产。

协同逻辑：JV 出产品 → 智见出方法论与内容壁垒（数字锚定、阈值口径、补数路径）→ 公共事务线出客户与信任。没有内容层，PaaS 只是裸模型 API，卖不出溢价；没有渠道层，JV 客户获取要重走三年。

对外口径

政研通转内为"智见"；对城投/银行统一以智见品牌签约。

表述纪律

卖"可复现决策过程"，不卖"省钱"；覆盖内用专家优先，覆盖外通用认知优先并标注。

验收口径

指标、口径来源、阈值、验证周期、缺数据补数路径——五要素齐备才算交付。

第三题 · 公共事务线 × 智见
模式与汇报

智见业务模式与汇报机制

商业主线（首期两条）

主线一 城投国企 · 不动产估值框架——保障房定价、资产盘点、债务化解中的资产端定价；与 JV 租金定价/估值产品直接重叠。

主线二 商业银行 · T0 估值 + T+N 监测/预警——抵押物估值入口 + 贷后持续监控；需配合估价资质路径设计。

市场监测、专家通、API、大屏、CLI、ISV 认证均降为底座/交付面，不作为独立卖点。

汇报机制（三层节奏）

日常 政策监测周报——住房租赁/公共事务口径，客户侧持续在场。
