## 三、首批试点实测数据（旧版"补数项"已部分填实）

1. **累计收购量**：2026-05 中旬 523 套 → 2026-07-30 试点三区 **551 套**，扩围至全部中心城区（[上海市政府网](https://www.shanghai.gov.cn/nw4411/20260730/6ad68292af8e4c42a37c7ae45be8dd7f.html)）。
2. **首例价格锚（静安）**：40㎡ 老房 → **220 万元专项房票**（收购对价 ≈ 5.5 万元/㎡），用于直购新建商品房；该房挂牌一年多未卖出（[每经](https://www.mrjjxw.com/articles/2026-04-11/4335176.html)、[凤凰财经](https://news.ifeng.com/c/8sF1KNmFuT0)、[财经](https://news.caijingmobile.com/article/detail/567082?source_id=40)）。
3. **浦东首单**：试点收购二手住房作为保租房，"收旧换新"首单落地（[上观新闻](https://www.shobserver.com/sgh/detail?id=1742606)、[浦东房协](https://www.pdrea.org.cn/News/Detail?id=363)）。
4. **模式形态**：以"收购置换"为主——业主卖旧房给政府（区属国企）获房票，房票直购新房；政府收下的旧房改造为保租房（[青年报·40平米老房换专项房票](http://app.why.com.cn/epublish/qnb/h5/html5/2026-04/01/content_120_42977.htm)、[武汉晚报](https://whwb.cjn.cn/html/2026-04/01/content_152974_3283142.htm)）。
5. **户型标准研究**：中房网专题《收购二手房做保障房的户型标准》（2026-06-30）——表明户型筛选（面积段/房龄/标准化改造可行性）已是操作层面的标准问题（[中房网](http://www.fangchan.com/data/19/2026-06-30/7477565656159032296.html)、[乐居](http://m.leju.com/www/news/7476441177819232180.html)）。
6. **行业解读**：丁祖昱评楼市《利好！上海收购二手房，有了新消息》（2026-04-24）（[中房网转载](http://www.fangchan.com/news/1/2026-04-24/7453348395374416497.html)）。

**未披露（重要缺口）**：①各区收购价与市场价/评估价的**实际折扣率**；②改造 CAPEX 与改造周期；③纳管后**实际租金与出租率**；④资金来源结构（再贷款/区财政/国企自筹比例）。——这四项仍是单元经济裁决的核心待验变量，与旧版验证协议一致。

## 六、制度参数（租金与供给框架）

1. **保租房租金 ≤ 市场价九折**（制度性规则，非沪八条新创）：上海保障性租赁住房租金应在市场价九折以下；二三孩家庭可入住三居室（[新华网上海 2022-01-19](http://sh.xinhuanet.com/2022-01/19/c_1310430538.htm)、[文汇报](https://dzb.whb.cn/2022-01-19/5/detail-750715.html)、[房天下](http://m.fangchan.com/news/6/2022-01-20/6889734311390810684.html)）。→ 与旧版"政策租金 85%-90%"口径吻合，收益端上限锁死成立。
2. **保租房供给底座**：上海已建成/筹措约 **60 万套（间）保租房**，国企租赁品牌领衔"公保简并"改革（[解放日报](https://www.jfdaily.com/wx/detail.do?id=1052256)）；松江"公保简并"改革试点（[澎湃](https://www.thepaper.cn/newsDetail_forward_33768930)）。→ 收购二手住房是"十五五"期间的**增量补充通道**而非主要通道。
3. **上海"十五五"规划**：《上海市城市更新和住房发展"十五五"规划》已印发——到 2030 年计划实施老旧小区改造 3000 万–4000 万㎡（[上海市政府·图文解读](https://www.shanghai.gov.cn/zhengce/detail?key=relates&id=f7db0a63a51246088ecbfbf49eb440c9)、[财经网](https://m.caijing.com.cn/article/202608/440061)）；"十五五"保租房量化目标**未在检索中确认，列入补数项**。
4. **配套政策**：保租房开发企业可免缴城市基础设施配套费（[上海市政府](https://www.shio.gov.cn/TrueCMS/shxwbgs/ccjzc/content/5f105f84-412b-4965-8675-5d624bed85c8.html)）。
5. **收购端规则**：各区执行细则不同；收购定价公开细则未统一公布（见第二节）。

## 七、单元经济锚点测算（条件式，基于公开案例+市场数据，非官方披露）

> 目的：把旧版框架落到 2026 年真实价格锚点上，给 t2/t3 提供可检验的输入。所有输出标注【推断】。

**锚点 A——首例收购对价（实测）**：静安 40㎡ 老房 → 220 万元（5.5 万元/㎡）。该房源"挂牌一年多未卖出"，市场公允价值不可直接观测；若其真实市场成交价在 6.2–6.9 万/㎡（中心城区老破小行情带），则实际收购折价约 **8–9 折**【推断】——恰落在旧版"高于九折不可行、7.5–8.5 折可讨论"的临界带上，方向与旧版框架一致。

**锚点 B——租金收益率（实测×推断）**：静安老破小 40㎡ 月租约 3500–4500 元（平台口径内环一室户区间）→ 年毛租金 4.2–5.4 万元 → 对 220 万收购价毛收益率 **1.9%–2.5%**【推断】；保租房按 ≤9 折纳管 → **1.7%–2.2%**；出租率 90% 折后 **1.5%–2.0%**。

**锚点 C——资金成本**：再贷款 1.75%（中央通道）vs 5Y LPR 3.5%（市场化基准）vs 综合（含区财政配套）约 2.0%–3.0%【推断】。

**锚点 D——剪刀差判定（条件式）**：
- 组合①：8 折收购 + 1.75% 资金 + 90% 出租率 → r≈2.2%–2.6% > c≈1.75% → **勉强成立**；
- 组合②：9 折收购 + 3.0% 资金 + 85% 出租率 → r≈1.4%–1.6% < c≈3.0% → **不成立，缺口 1.4–1.6pp**，需财政贴息/REITs 补；
- 组合③：7.5 折收购 + 2.0% 资金 + 92% 出租率 → r≈2.5%–2.9% > c≈2.0% → **成立但依赖折扣纪律**。

结论（条件式）：**收购折扣仍是枢纽**；本次补入的真实锚点（5.5 万/㎡ 收购对价、1.75%/3.5% 资金、9 折租金上限）不改变旧版框架结论，但把可行域从"概念区间"压到了"可检验区间"。
