## 3. 关键设计决策

- **Register**：`product`（对外合作前提说明文档）。不启用 brand 的 grain / hero engine；SPECTACLE=2（仅翻页 reveal + 进度反馈，纯 CSS + 原生 JS，零外部库）；DENSITY=7（中高密度）。
- **分页机制**：`.deck` 容器 `scroll-snap-type:y mandatory`（原生滚动吸附）＋ 底部翻页条（上一页/下一页 + 页码 + 当前页名）＋ 右侧页点导航（≤1024px 隐藏）＋ 顶部滚动进度条；键盘 ←→/↑↓/PgUp/PgDn/Home/End 全支持。`prefers-reduced-motion` 下 `scroll-behavior:auto`、全部 reveal 立即可见。
