## 一、用户 4 大优势展开（每项一页内容源）

### 优势 1 · 信用：声誉 + 可复测 + 可追溯 —— 把"信用"做成可审计工程

**机制展开**（渠道/存量流通视角）：
- **声誉 = 四本账沉淀的可信资产**：长期一致兑现承诺积累的可信度，由四本账（事实/假设/方法/责任）留痕支撑，不靠品牌背书——决策不因人员流动与时间流逝而丢失；
- **可复测 = 同条件重放**：给定历史时点重放数据、假设与计算，结果一致；
- **可追溯 = 五条横向链**（Identity 身份 / Version 版本 / Evidence 证据 / Approval 审批 / Replay 复现）——谁在何时、基于哪个版本、什么证据、经谁审批做的决策，全链可查。

**可量化表述**：任一决策点可回答五个问题——谁做的（身份）、哪个版本（版本）、依据什么（证据）、谁批准（审批）、能否重放（复现）。这把"信任"从关系资产转化为可审计资产，决策可审计从口号变成工程标准。

**对三类合作方的含义**：
- **银行**：估值底稿可复核，应对监管检查与减值计提；押品 T0 估值 + T+N 监测可追溯；
- **政府**：观测指标热力度对比效果，统一口径（40 城 vs 50 城）可解释；
- **国企**："项目可以不赚钱，过程不能说不清"——收储决策审批链 + 复现链可担责。

### 优势 2 · 真实：短时真实交易 + 潜在数据（平台经济视角）

**机制展开**：
- **历史数据价值递减**：不动产受政策强干预（限购限贷、收储、REITs），2021 年后供需结构逆转（新房→二手、刚需→改善、住宅→租赁），旧样本来自旧结构，预测力按**结构断点**衰减——智见指数基期分设（价格 2020-01、活跃 2024-01）、只给同环比（参照 70 城），本身就是对结构变化的承认；
- **潜在数据优势**：挂牌量反映供给意愿、带看反映真实需求意图、去化周期反映均衡速度、**挂牌价-成交价差**反映议价空间与价格发现偏离——他人只有结果数据，贝壳独有成交前过程数据（底稿：二手为"自有强项"，自有挂牌/成交/带看）；
- **对照竞品**：58/安居客"数据噪声大、口径混乱、非决策级"（底稿竞品地图）；中指/克而瑞以调研填报为主、口径黑箱、决策过程不可审计；统计局 70 城只有结果指数、无过程数据。真实成交可直接挂接五链的 Evidence/Replay——合作方拿到的不是承诺，而是可重放的证据。

### 优势 3 · 基础设施：估值框架 + 指数 + 白皮书/峰会 —— 标准制定者位置（存量统筹视角）

**机制展开**：三者叠加构成"标准制定者"位置而非"数据供应商"位置——卖的是标尺，不是尺子量出的数。
- **估值框架（开源化）**：中房协"好房子"标准（安全耐久、健康舒适、绿色低碳、智慧便捷）作价值锚；不动产 CAPM（Rf + β×ERP + 流动性溢价 + 政策风险溢价）定折现率；NOI/DSCR 现金流模型打通收储定价、押品估值、REITs 分派对标——市场不缺房子、缺好房子，品质溢价需要可计算、可审计的标尺；
- **指数体系**：三大一级指数（价格基期 2020-01、活跃基期 2024-01、信心暂无基期暂缓对外）、子指数 7 项、只给同环比（参照统计局 70 城）、40 城 vs 50 城专项说明——克制比发布更能积累公信力；活跃指数基期 2024-01 恰处深度调整期，能灵敏捕捉止跌回稳斜率；
- **白皮书/峰会**：33+ 位专家、五域分类、BK 档案（底稿 3.2）——智力底座；"卖稳定的观点结构、不卖某个人的名字"。

**合作案例（用户反馈展开，已落地为具体合作）**：
1. **清华合作白皮书**：与清华大学合作发布的白皮书（行业研究与方法论输出）；
2. **中房协合作·好房子标准**：与中房协合作制定「好房子」标准（安全耐久、健康舒适、绿色低碳、智慧便捷等品质维度）→ 作开源估值框架价值锚；
3. **人民日报合作·好房子平行论坛**：与人民日报合作举办「好房子」平行论坛（行业话语权平台）；
4. **C 端好房子标示**（素材来源：用户提供，最新图 d3fa7704 新东人才住房房源卡；星级/分数为示例，口径以正式合作文档为准）：好房子评级·四维度 = 舒适 / 绿色 / 科技 / 安全；评价标准 = AI 打分 + 人工复核；综合星级：舒适 3.6 / 绿色 2.6 / 科技 3.9 / 安全 2.9；优质型 65 / 100 分；租金受控 · 试点房源（房型设施、咨询管家见截图）。

闭环：**标准（中房协）→ 评级（AI + 人工复核）→ 标示（C 端·试点房源）→ 论坛（人民日报）→ 白皮书（清华）**——共同证明「标准制定者」位置。

### 优势 4 · 深度：harness + 垂类模型预训练 + 专用终端 三层一体（银行战略咨询视角）

**路线对比**：路线 A＝只使用 skill（提示工程层，四件套中仅一件）；路线 B＝专家 skill ＋ 专用 agent harness（任务编排/工具调用/证据链回写/多步推演）＋ 垂类模型（不动产语料微调）＋ 专用终端（对话+底稿+审批一体）。

| 对比维度 | A 只使用 skill | B harness+垂类模型一体化 |
|---|---|---|
| 效率（一次成稿/少返工） | 通用模型每次重走推理，长任务易丢步、返工多 | 编排+预置知识一次成稿；垂类语料减少术语纠错 |
| 成本（token/缓存复用） | token 随调用线性增长，无缓存复用设计 | Token 用量少、缓存复用，单位成本随量收敛（幅度待灯塔实测，不承诺比例） |
| 质量（口径/证据/审计） | 口径靠提示词硬顶、无证据回写，幻觉难控 | 口径统一、输出必带引用与假设条件；harness 回写证据链，五链支撑可审计可复现 |
| 能力边界（多步推演/工具/私有化） | 只能生成文本；无工具调用、无多步推演 | 多步推演、工具调用、审批流嵌入；模型+框架+工具链整体下沉客户环境 |
| 合规（银行/国企） | 依赖外部 API 或通用模型私有化，成本高、数据出域风险 | 数据不出域、离线可用（33+ 专家预置、BK 档案），满足敏感场景合规 |

**结论**：A 是可被抄走的文档；B 是工程资产（编排/工具/证据回写）+ 参数资产（语料微调）+ 终端资产（决策动作发生地）三层一体，合作方无法在合同期内自建。**私有化部署、数据不出域、离线可用是银行/国企采购的硬门槛**——没有 harness 的证据回写与版本链，可审计只是口号。

**harness 工作机理（用户反馈补充）**：
- **精简 tools**：harness 按方法论收敛工具集，不做大而全；
- **训练特定方法论**：为垂类任务训练专用方法论/工作流；
- **提升缓存命中率、减少无效步骤**：复用中间结果，降低 token 浪费；
- **提升有效上下文质量**：上下文只保留与当前决策相关的有效信息；
- **核心表述（用户原话）**：「是专家团多轮出力，不是预置知识一次成稿」——多专家并行研判 → 依赖链 → 融合成文（示例：5 项任务派给 4 名成员，依赖链 t1 资料梳理 → t2 数据梳理 / t3 风险视角 → t4 宏观研判 → t5 融合成文 → 渲染）。

**收费模式（用户反馈补充）**：与 B 端年费三包并列增加**按次计费**——按调用/查询/报告次数计费，适合低频高价值单次决策场景（如单次估值、单次监测报告）。

## 二、补充优势精选（去重后 8 条）

1. **存量流通时代入口地位**（渠道/存量流通视角）：天象已变、业主社会成型，收储/保租房/REITs/二手置换构成全流通主战场，贝壳占据流通入口（自有挂牌/成交/带看）——银行监控抵押物、国企收储去化、政府监测流通都绕不开。合作前提价值：入口即数据源，数据源即审计源。
2. **政策工具箱落地能力**（渠道/存量流通视角）：收储测算包（收购折扣×CAPEX×保租租金×出租率→NOI→DSCR 基准/压力双情景）+ T0 估值/T+N 监测——从政策文本到项目级落地执行。合作前提价值：合作方不用自建测算与监测体系。
3. **真房源验证哲学**（平台经济视角）："假一赔百"式机制化信任，把真实从口号变成制度，验证成本平台承担。合作前提价值：合作方承接已验证的事实层。
4. **数据飞轮（间接网络效应）**（平台经济视角）：交易越多→数据越全→标尺越准→客户越多。合作前提价值：合作方可借飞轮而不自建数据。
5. **标准采纳权**（平台经济视角）：政府免费入口换标准/共识/数据入口（底稿 1.2），"只给同环比"的克制正是标准供给者姿态。合作前提价值：与标准制定者合作 = 与未来口径对齐。
6. **ACN 合作网络**（平台经济视角）：贝壳能把服务品质写成规则并执行——"品质可标准化"的制度证据。合作前提价值：规则治理能力可迁移到合作项目治理。
7. **存量时代指标体系与政策效果复现**（存量统筹视角）：新旧一体看（二手"自有强项"是存量蓄水池的水位计）；政策库带"发布→市场响应→验证闭环"（底稿 4.2，31 省+重点城市细则）；口径纪律换公信力（指标回归正常化，不期待回到过去热度）。合作前提价值：为政策组合拳效果检验提供统一口径底稿。
8. **生态数据资产与商业模式飞轮**（银行战略咨询视角）：自有真房源成交数据（二手/租赁自有强项）+ 生态数据（生活服务单量/GTV）+ 政策库自爬——垂类模型微调的语料基础是竞品不具备的；"免费换标准"只有平台型机构玩得起。合作前提价值：数据可得性与更新频率领先纯爬虫型机构，飞轮只有合作方共享才能复制。

> 附：**责任纪律 = 合作润滑剂**（银行战略咨询视角）——做底稿不做签章、不抢法定评估，不与评估机构/银行内部合规冲突，降低合作摩擦。

## 三、合作前提条款清单（按优势映射 · 最重要）

| 1 | 数据（自有+生态+合作方输入） | **数据授权边界**：可入合作环境的数据范围、可复用/可分发边界、衍生数据归属；合作方输入数据（押品/信贷台账）反向授权与保密；**禁止用于合作外模型训练** |

| 4 | 审计/五链 | **责任边界**：做底稿不做签章，结论责任归客户决策者；复现仅限"已发生事实+透明假设"同条件重放，**不做反事实承诺**；证据链保留期限与可审计接口；不替客户决策、不隐藏不确定性 |
