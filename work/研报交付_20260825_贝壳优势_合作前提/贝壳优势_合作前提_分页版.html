SEC.01

优势 1 · 全：全业态汇总 ＋ 稳定指数化加工

FULL COVERAGE · INDEX ENGINE
汇总酒店、消费等六业态数据，做稳定的指数化加工；全 = 全业态 × 全周期（领先 / 同步）× 全维度（供给 / 需求） —— 一个入口拿到口径统一的加工结果，而非散点数据。
01

全

FULL-SCOPE · INDEX ENGINE

全业态矩阵

量 / 价 / 成交 × 六业态（新房 / 二手 / 租赁 / 酒店 / 生活服务 / 教育）—— 逐格扫描，先扫缺口、再定优先级。

MECH · 02

多源汇聚

网签备案 · 土地 · 政策库 · 咨询级微观数据 · 酒店 OCC / ADR / RevPAR · 银行 / 房协 / 政府输入 · 挂牌 / 成交 / 带看 —— 覆盖量 / 价 / 成交全链条。

MECH · 03

稳定指数化加工 · 全周期 × 全维度

三大一级指数（价格 2020-01 / 活跃 2024-01 / 信心暂缓对外）＋ 子指数 7 项；基期分设、只给同环比（参照统计局 70 城）；领先指标先于成交、同步指标即已发生事实。

对银行

押品与信贷决策需要跨业态可比口径（住宅 / 商办 / 租赁 / 酒店），一份底稿全覆盖。

对政府

市场监测覆盖交易与消费两侧，政策响应观察不再只盯住宅成交。

对国企

收储与运营测算需要租赁 / 酒店等经营业态数据，与住宅口径同源可比。

多轮协作 5 项任务 × 4 名成员 · 依赖链
t1 资料梳理→ t2 数据梳理∥t3 风险视角→ t4 宏观研判→ t5 融合成文→ 渲染

核心表述：「是专家团多轮出力，不是预置知识一次成稿」 —— 多专家并行研判 → 依赖链 → 融合成文。

结论

A 是可被抄走的文档；B 是工程资产（编排 / 工具 / 证据回写）＋ 参数资产（语料微调）＋ 终端资产（决策动作发生地）三层一体，合作方无法在合同期内自建。私有化部署、数据不出域、离线可用是银行 / 国企采购的硬门槛 —— 没有 harness 的证据回写与版本链，可审计只是口号。

SEC.05

优势 5 · 信用：声誉 ＋ 可复测 ＋ 可追溯

TRUST AS AUDITABLE ENGINEERING
把「信任」从关系资产转化为可审计资产；声誉 = 长期一致兑现承诺积累的可信度，由四本账留痕支撑，不靠品牌背书。
05

信用

CREDIT · AUDIT LEDGER
MECH · 01

声誉 ＝ 四本账沉淀的可信资产

长期一致兑现承诺积累的可信度，由四本账（事实 / 假设 / 方法 / 责任）留痕支撑 —— 决策不因人员流动与时间流逝而丢失，不靠品牌背书。

MECH · 02

可复测 ＝ 同条件重放

给定历史时点重放数据、假设与计算，结果一致 —— 只描述已发生，不做反事实承诺。

MECH · 03

可追溯 ＝ 五条横向链

谁在何时、基于哪个版本、什么证据、经谁审批做的决策，全链可查。

Identity身份链谁在动 · 权限留痕
Version版本链假设可回溯
Evidence证据链数字有来源
Approval审批链谁审谁批
Replay复现链同条件同结果
五问可答 任一决策点可回答五个问题：谁做的（身份）· 哪个版本（版本）· 依据什么（证据）· 谁批准（审批）· 能否重放（复现）
对银行

估值底稿可复核，应对监管检查与减值计提；押品 T0 估值 ＋ T+N 监测可追溯。

对政府

观测指标热力度对比效果；统一口径（40 城 vs 50 城）可解释，口径纪律换公信力。

对国企

「项目可以不赚钱，过程不能说不清」—— 收储决策审批链 ＋ 复现链可担责。

SEC.06

补充优势精选（去重后 8 条）

EIGHT MORE REASONS
每条附合作前提价值 —— 为什么这些优势在合作语境下成立。
1

存量流通时代入口地位

渠道/存量流通

合作前提价值：入口即数据源，数据源即审计源 —— 银行监控抵押物、国企收储去化、政府监测流通都绕不开。

2

政策工具箱落地能力

渠道/存量流通

合作前提价值：合作方不用自建测算与监测体系 —— 收储测算包（收购折扣×CAPEX×保租租金×出租率→NOI→DSCR 基准/压力双情景）＋ T0 估值 / T+N 监测。

3

真房源验证哲学

平台经济

合作前提价值：合作方承接已验证的事实层 —— 「假一赔百」式机制化信任，把真实从口号变成制度，验证成本平台承担。

4

数据飞轮（间接网络效应）

平台经济

合作前提价值：合作方可借飞轮而不自建数据 —— 交易越多→数据越全→标尺越准→客户越多。

5

标准采纳权

平台经济

合作前提价值：与标准制定者合作 = 与未来口径对齐 —— 政府免费入口换标准 / 共识 / 数据入口，「只给同环比」的克制正是标准供给者姿态。

6

ACN 合作网络

平台经济

合作前提价值：规则治理能力可迁移到合作项目治理 —— 贝壳能把服务品质写成规则并执行，「品质可标准化」的制度证据。

7

存量时代指标体系与政策效果复现

存量统筹

合作前提价值：为政策组合拳效果检验提供统一口径底稿 —— 新旧一体看（二手「自有强项」是存量蓄水池的水位计）；政策库带「发布→市场响应→验证闭环」（31 省＋重点城市）。

8

生态数据资产与商业模式飞轮

银行战略咨询

合作前提价值：数据可得性与更新频率领先纯爬虫型机构 —— 自有真房源成交 ＋ 生态数据（生活服务单量 / GTV）＋ 政策库自爬；飞轮只有合作方共享才能复制。

责任纪律 ＝ 合作润滑剂

做底稿不做签章、不抢法定评估，不与评估机构 / 银行内部合规冲突，降低合作摩擦。

SEC.07

合作前提条款清单（按优势映射）

TERMS BEFORE COLLABORATION
八条前提条款，逐条对应优势 —— 先说清楚边界，再谈合作。
1

数据授权边界

优势 · 数据
  • 可入合作环境的数据范围、可复用/可分发边界、衍生数据归属
  • 合作方输入数据（押品 / 信贷台账）反向授权与保密
  • 禁止用于合作外模型训练
2

部署形态与计量

优势 · 深度
  • 私有化 / API 形态与 Token 计量、费用边界、缓存复用权益
  • 微调层 IP 归属与底座模型许可合规
3

口径定义权与变更机制

优势 · 口径/标准
  • 40 城 vs 50 城、指数基期（价格 2020-01 / 活跃 2024-01）
  • 口径变更版本化、双方书面确认；对外发布前过舆情审核
4

责任边界

优势 · 审计/五链
  • 做底稿不做签章，结论责任归客户决策者
  • 复现仅限「已发生事实＋透明假设」同条件重放，不做反事实承诺
  • 证据链保留期限与可审计接口；不替客户决策、不隐藏不确定性
5

免费投入上限与付费测试

优势 · 商业模式
  • 免费投入 ≤ 总成本 20%，以「部委 / 协会采纳智见口径」为继续投入里程碑
  • 付费测试条款：试点意向书、10-100 万级验证，不做规模承诺
6

合规与退出机制

优势 · 合规/私有化
  • 数据不出域技术承诺；等保 / 信创 / 金融合规清单；脱敏责任划分
  • 终止时数据删除 / 归还、底稿与账号处置、白名单回收（领导直问 300 人）
7

生态协同

优势 · 生态（贝壳研究院）
  • 与贝壳研究院的协同协议先于对外叙事落定
  • BK 专家体系（33+ 位、五域分类）即智见 A 智囊层现成资产
8

真实性条款

优势 · 真实/信用
  • 贝壳对成交事实真实性负责（可审计证据链），对决策结论不对结论负责
  • 对事实负责、不对结论负责
9

收费模式：年费三包 ＋ 按次计费

优势 · 深度/基础设施
  • 机构基础包年费（数据 ＋ 模型服务）· 业务解决方案包（工作台定制 ＋ 私有化部署）· 扩展包（Token 额度 / 大屏 / API / 嵌入式组件）
  • 按次计费：按调用 / 查询 / 报告次数计费，适合低频高价值单次决策场景（如单次估值、单次监测报告）

卖的不是数据，
是经得起审计的决策过程。
