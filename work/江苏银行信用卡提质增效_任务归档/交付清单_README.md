## 四、关键结论速览

1. **存量亏损**：2026H1年化每有效卡 -153元/年（E2可复算）；收入65.7%依赖分期息费。
2. **杠杆排序**：CAC管控 > 坏账率 > 分期深度 > 单卡消费（坏账+1pp杀伤≈消费收益10倍）。
3. **产品组合**：增=主题卡/单位卡/标准卡；并=金卡A-B/无界家族/电商双联名；退=E融卡(26.06%不良)/分期卡(11.27%)/低效联名卡。
4. **高端卡**：银联底座+V/M补位+运通蓝盒子旗舰（1,200-2,000张）；r3口径3年回本≥635张；2026年内完成银数续约+运通签约。
5. **数据缺口**：7项P0（CAC/权益核销/切片明细/运营分摊/回收/FTP口径/飞书对标表）补齐前，所有UE/敏感性数值为E4情景，非利润预测。
