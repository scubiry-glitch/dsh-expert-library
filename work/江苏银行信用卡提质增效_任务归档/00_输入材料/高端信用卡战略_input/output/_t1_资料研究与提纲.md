## 六、三态标注与来源编号统一写法（T2 落实为 CSS）

- 徽标：`[事实]`（绿）`[假设]`（黄）`[推断]`（蓝）`[待核实]`（橙）四类 class；冲突警示 `.conflict`（⚠ 口径冲突 + 编号 C1-C13）。
- 来源写法：表内 `数值（来源编号｜口径）`，如 `635 张（任务B｜口径A·3,600档·S1）`、`3.41%（167｜2026-07）`；正文 `（230/234，2025-07~2026-06）`。
- 假设项：`[假设]` + 取值 + 区间 + 依据；待核实：`[待核实]` + 编号 ①-⑧ + 一句话缺口。
- 状态码行（第 3 节）：FB/DV/AS/MO/CF/RC 六徽标 + 图例。
