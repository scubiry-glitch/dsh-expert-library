# 08_现状与卡组织对比_事实基准册

> 江苏银行高端信用卡与卡组织合作战略 · 事实基准册
> 本册只固化事实、口径、缺口和决策输入，不新增产品建议。材料含商密、内部及卡组织方受限信息，仅限行内评估。

## 一、一页纸总览：先确认底座，再讨论路径

### 1. 我行现状五句话诊断

1. **规模在收缩**：2026-07累计卡量590.12万张，但有效卡量330.05万张、有效主卡持卡人308.63万人，交易金额/笔数同比下降；231另以银数托管行横向口径称交易量同比降超40%，为其中降幅最高。
2. **存量在失活**：激活率60.39%，较区域行低15.1pp；30天活跃率26.10%，90天睡眠率69.95%。累计卡量不能作为高端卡真实客户池。
3. **收入结构单一**：分期息费65.74%、利息28.45%、佣金1.85%，卡均收入61.49元/月；佣金达到区域行9.06%的静态差额约1.76亿元/年，但该缺口为派生计算。
4. **风险上行且比较基期不同**：不良率3.41%、损失率2.56%；167分别给出同比+1.81pp、+1.73pp，235给出较年初+1.25pp、+1.08pp，不能混用。
5. **境外客群有价值但经营分层不完整**：境外消费7.6万户/72万笔/4.6亿元；VISA客群AUM6.76万元、EVA3,206.57元，银联客群AUM1.11万元、EVA818.04元；系统依赖银数，行内团队编制/FTE尚未从人事或个贷口径核实。

### 3. 现状×卡组织适配结论（推断）

银联适合承接我行已有境内和亚太底座；Visa适合承接已有高价值VISA境外客群和欧美长线；万事达的增量价值取决于NUCC成本/条件；运通适合高净值旗舰但必须先解决成本、履约和受理边界。该判断是 `RC`/推断，不是本册新增建议，也不替代正式立项。

## 二、统一状态码和编号规则

本册采用六类状态，避免把模型结果误读为事实：

| 状态 | 含义 | 使用规则 |
|---|---|---|
| FB | Fact Base，材料直接披露事实 | 必须带材料、时间/单位/分母和保密级别 |
| AS | Assumption，测算或规划假设 | 必须写取值、范围和原因，不得写成现状 |
| DV | Derived Value，公式派生值 | 列出输入ID、公式和舍入规则 |
| MO | Model Output，模型输出 | 绑定模型版本和输入ID；不能单独作为事实 |
| CF | Conflict，材料冲突/待决 | 两边均保留，标裁决状态和影响 |
| RC | Recommendation/推断 | 只作为决策输入或后续建议，不纳入事实总表 |

不可变主键：`FB-领域-NNNN`、`AS-领域-NNNN`、`DV-领域-NNNN`、`MO-模型-NNNN`、`CF-领域-NNNN`、`RC-领域-NNNN`。本轮先使用简化主键，正式数据仓库落表时补齐原文逐字摘录、页段、责任人和版本。

## 八、三道质量闸

### G1 证据链闸

- 每个摘要数字绑定唯一ID、原文/页段、材料主体、保密级别和时间口径。
- 供应商数字注明“供方口径”，内部汇总不能伪装成独立外部验证。
- 冲突用CF双边保留；P0冲突不裁决不进入无条件摘要。

### G2 数字与计算闸

- 逐项核分子/分母、户/人/卡/张、月/年/时点、同比/较年初；167月度流量不自动年化。
- 独立复算模型输出；回本阈值、回本周期、NPV、LTV须与脚本、正文和摘要三方对账。
- S3必须统一客户/卡片粒度；非零授权费必须统一首年减免逻辑；佣金缺口和30亿元结论不得混用。

### G3 发布闸

- 摘要只允许FB/DV/MO（显式条件）进入；AS/CF必须明示；RC不能伪装事实。
- P0项目（插值、S3、授权费、团队编制、系统已上线、佣金规模）清零后，才可把前两轮模型作为决策输入。
- 待核实项必须有责任部门、截止时点、取数方式和数据不到位时的降级话术。
