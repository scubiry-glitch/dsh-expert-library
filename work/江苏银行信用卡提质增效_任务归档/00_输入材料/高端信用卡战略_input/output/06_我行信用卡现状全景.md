# 06_我行信用卡现状全景诊断

> 江苏银行高端信用卡与卡组织合作战略 · 事实基准册分册
> 用途：行内评估。材料 167/230/231/234/236 及上轮成果均含内部或受限信息，不得外发。

## 一、结论先行：我行信用卡的核心问题是“增量枯竭、存量失活、收入单一、风险上行、系统依赖”

1. **规模和交易双降**：截至 2026-07，累计卡量 590.12 万张，但有效卡量仅 330.05 万张、有效主卡持卡人 308.63 万，交易金额和笔数同比下降；银数纪要显示我行交易量同比降超 40%，在银数托管行中降幅最高，明显差于行业约 10%-15% 的下降幅度。
2. **存量未被激活**：激活率 60.39%，较区域行低 15.1 个百分点；30 天活跃率 26.10%，90 天睡眠率 69.95%。卡量尚在，但可持续交易人口不足。
3. **收入高度依赖分期和利息**：分期息费占收入 65.74%，利息占 28.45%，佣金仅 1.85%，而区域行佣金占比 9.06%；卡均收入 61.49 元/月且同比下降 13.73%。
4. **风险已进入需要约束增长的区间**：不良率 3.41%，较年初上升 1.25 个百分点；损失率 2.56%。167另有同比不良率变动口径，不能与235的“较年初”直接替代。
5. **高价值境外客群已存在，但产品和组织承接不足**：近一年境外消费客群 7.6 万户、72 万笔、4.6 亿元，消费频次约为仅境内客群 1.85 倍，人均 EVA 945.36 元；VISA 境外客群人均 AUM 6.76 万元、EVA 3,206.57 元，显著高于银联境外客群，但现状仍依赖银数托管系统，行内信用卡团队编制和可投入 FTE **待核实**。

按167月收入 20,293 万元计算：当前佣金约 375.4 万元/月、约 4,504.9 万元/年；若达到区域行 9.06%，佣金约 1,838.5 万元/月、约 2.206 亿元/年，静态缺口约 **1.756 亿元/年**。这是数学推导，不是新增材料事实，且假设月收入规模不变；应在取得年费、利息、回佣绝对额及可比区域行分母后重算。

**收入明细缺口**：现有上轮报告明确了分期息费、利息、佣金三项占比，但年费/利息/回佣的绝对金额及“佣金是否含全部网络回佣”仍需从167第45页起收入明细核对。因而“钱从哪里来”可确认结构，不能把年费绝对额当作已核实事实。

## 九、事实基准使用规则

- 167月报指标统一写成“2026-07月报”；230/234统一写成“2025-07至2026-06近一年滚动境外消费口径”；231为2026-08-05纪要；模型数字必须标假设。
- “激活率60.39%”不能与“浦发活卡率60%”直接比较：前者是行内激活率，后者是浦发近一年有交易口径。
- 任何高端卡测算必须区分纯新增与存量升级，不能把7.6万户已有客户的全部AUM/EVA重复计为新增。
- 佣金缺口1.76亿元/年是静态推导，不是167直接披露数；重算前需锁定收入分母和区域行可比口径。
