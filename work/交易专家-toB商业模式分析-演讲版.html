01 · 模式一句话

围绕银行做两类 toB 生意

① 评估与咨询服务

给银行的房产押品贷款加一条"可交叉验证、可持续复核的市场证据线"

估值参考 · 市场监测 · 咨询分析 · 银行场景 Agent

② 营销服务

把贝壳交易流量中的高意向商机开放给金融机构

商机分发（CPA）· CPT 包段服务 · Agent 开放平台接入 · 通用 token 按量

平台不碰金融牌照业务，卖的是三样东西：数据证据、流量、管道。 C 端专家服务（按次/会员/成交分成）仅作定价验证，非主收入。
02 · 产品线① 评估与咨询服务

四类银行场景 × 三层市场证据 × 一条可追溯链

不是替代银行既有评估与审批，而是补充一条高效、透明、可复核的证据线；明确"不构成资产评估报告或房地产估价报告"，规避牌照与责任问题。

场景服务内容
贷前准入单套市场价值参考：可比成交与样本边界
存量监测批量更新与 LTV / 覆盖异常触发复核清单
区域预警城市—板块—小区量价与流动性分层
不良处置处置时点与折价空间、租售流动性参考
监管背景：70 城二手住宅较高点累计回调 23.18%；六大行住房贷不良率 0.67%→0.88%、经营类 1.58%→1.92%——高评高贷与押品估值是处罚关注点。

交付形态：咨询报告 + API 服务（结构化区间、证据与版本）+ 银行场景 Agent（组织案件→匹配证据→留版本→识别异常→人工复核）

02 · 产品线① 评估与咨询服务

平台能力底座：智见专家 Agent 开放能力

评估线的生产能力由智见专家 Agent 平台支撑，合作伙伴开放能力开发文档定义了完整生产体系：

专家 Profile（schemaVersion 2）

persona + 方法 + 约束 + 输出规范 + 评分量规；建队时烘焙成成员，评分反馈闭环让专家越用越准。

任务 DAG（Scenario）

"估价报告复核"场景：要件核验 → 比较法 / 收益法复核并行 → 融合复核意见书——梳理先行、多视角并行、融合收口。

输出模板 + 质量门禁

五道起步门禁：禁例 token 0 命中、数字逐 token 一致、渲染 0 溢出、排版审计、大纲对照。硬门未过的交付物到不了客户手里。

数据源通道

Wind / 政研通 zyt / 贝壳三通道统一调用面，返回信封强制携带口径与单位；"编数字比不回答更严重"的四级数据标注纪律。

02 · 产品线① 评估与咨询服务

容诚最佳实践：单套租金测算咨询报告（v2）

《佳馨苑 1 座 506 单元 · 单套住宅租金测算咨询报告》（容诚，2026-07-01，编号 RCE-FZ-JXY-2026-0701-001；委托方为政府平台公司福州安住发展）——"单套资产"颗粒度的交付标杆。

模型测算 + 样本校验双轨

模型参考点 2,364 元/月；同小区 5 套可比样本修正校验（加权 2,203 元/月），差异 6.8%–16% 如实披露"不宜表述为强支撑"。

逐项差异调整矩阵全披露

面积 / 客厅数 / 卫生间数 / 出租时间逐项量化（如 R-04 面积差 −1,031 元/月），每个数字可追问。

事后检验

另用 2026-06 的 880 条样本回测，平均误差 13.9%——模型可信度可量化。

全样本附录 + 证据留存

8 条候选样本含 3 条落选样本及落选原因；证据留存入口 dss.ke.com/valuation，结论可回溯到样本与参数版本。

核心资产不是"AI 写报告"，而是"测算模型 + 样本调整矩阵 + 事后检验 + 证据留存"的完整证据链工艺——银行买的正是这条链。

03 · 产品线② 营销服务

核心产品分解与计费方式

#核心产品内容计费方式
1商机分发理财引流、按揭线索开放；"圈出高意向人群 + 分类器分发"；有效线索定义合同锁死，空号/拒接/重复不计费CPA 按有效线索计费
2CPT 包段服务包断专属资源时段：专家坐席（每周 N 小时专属金融专家）、板块/楼盘场景冠名、专场活动（如宁波银行理财专场周）CPT 按包段时长/场次，资源独占
3Agent 开放平台接入插件化接入、计费系统、数据围栏、频率限制；机构自带产品"插进来"自主运营年费分层（基础/专业/旗舰）
4通用 token 消耗机构调用 Agent 能力产生的模型消耗按量计费（市场化定价，无差价结构）
口径说明：不含 CPC（按点击）与 CPS（按成交分成）——转化环节完全归机构自主运营，平台只对"交付给机构的确定性资源"（有效线索、包段时段、接入能力、消耗用量）收费，权责边界清晰。

银行收益闭环：高净值客群获取 · 理财转化 · 按揭转化——接入前必须先对齐每家银行自己的商业模式闭环点。

04 · 商业结构

层级结构：谁提供什么、谁得到什么

层主体提供什么得到什么
证据/服务层评估咨询服务估值参考、监测、归因、Agent年费 / 项目费（2000 万级组合的一部分）
流量/平台层贝壳 Agent 开放平台商机、画像、插件化接入服务费、分发计费、包段计费
机构层银行 / 保险 / 券商金融产品、风控、转化运营客群与转化，闭环自身商业模式
（辅助）C 端交易专家服务按次咨询 / 会员陪伴 / 成交分成验证服务价值与定价，非主收入

为什么是这个模式，而非自营

  • 自营财务陷阱（美租/自如教训）：收入分期确认、成本一次确认 → 做得越大亏越多；组织人力也扛不住重履约。
  • toB 两线均轻资产：证据线靠数据+模型，营销线靠流量+管道——跑通一家银行后可复刻。
  • 合规姿态干净：评估线明确"不构成评估报告"；营销线把履约与转化责任交给持牌机构。
05 · 风险治理

核心风险与对策

风险说明对策
金融合规TOC 直连有主体责任；评估线不能越界成"评估报告"先理财后按揭；免责声明与"另行履行程序"条款；合规问题转人工
数据安全开放接口穿透、超范围调用每机构数据权限白名单、并发/频率限制、仪表盘监控
边界冲突与北京试点专家项目、OSA/云管家链路纠缠两项目刻意保持边界；与原项目经理（张强）对齐接口
B 端使用能力银行"能不能接、会不会用明白"自助化装修（类淘宝店铺）+ benchmark 工具；先 1–2 家标杆再复刻
商业闭环银行付费理由必须落到其自身模式接入前逐家定义闭环点（理财 / 按揭 / 高净值）

07 · 待回答的开放问题

七个待校准的问题

  • 2000 万级组合中，评估咨询服务与营销服务（引流/分发）各占多少？
  • 评估线计价基准：按押品规模、场景模块数还是年费？与行内既有评估供应商如何比价？
  • 银行对接部门：授信/押品/风险（评估线）vs 零售/私行（营销线）——是否需要两套话术两拨人？
  • 商机分发的转化数据回写口径：CPA 结算之外，回流数据是优化分发模型与 CPT 定价的基础，机构是否开放？
  • CPT 包段的资源边界：专家坐席如何与 C 端自营排期隔离？服务承诺（响应时长、专家等级）如何写入 SLA？
  • 通用 token 消耗对客计价：官网价直传还是平台统一价？用量超预期的限流策略？
  • C 端 AI 评测通过标准与放开时间表？
