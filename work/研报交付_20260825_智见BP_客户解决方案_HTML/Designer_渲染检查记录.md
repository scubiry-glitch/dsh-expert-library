## 4. 关键设计决策

- **Register**：`product`（对外方案说明文档）；SPECTACLE=2（仅翻页 reveal + 进度反馈，纯 CSS + 原生 JS，零外部库）；DENSITY=7。
- **分页机制**（与「贝壳的优势」分页版一致）：`.deck` 容器 `scroll-snap-type:y mandatory` ＋ 底部翻页条（上一页/下一页 + 页码 + 当前页名）＋ 右侧页点导航（≤1024px 隐藏）＋ 顶部滚动进度条；键盘 ←→/↑↓/PgUp/PgDn/空格/Home/End 全支持；`prefers-reduced-motion` 下 `scroll-behavior:auto`、reveal 立即可见（CSS + JS `no-motion` 双回退）。
- **配色（贝壳蓝金，锁定 token）**：tinted 底色 `#edf0f6`、卡面 `#fcfdff`、Cobalt `#2d5bd8`/`#1e44a8`、金 `#c98a2e`/`#8a5f14`、navy 封面封底渐变、hairline `rgba(20,32,56,.08)`、tinted 阴影（无纯黑）；语义色分离：红/绿仅作装饰性语义，警示金棕 `#8a6a13` 仅用于口径注。
- **P5 估值框架可视化**：公式条（不动产估值 ＝ 估值方法开源 ＋ 过往事实数据 ＋ 情形模拟 → 可溯源 · 可复现 · 可跟踪）＋ 三张术语卡以「＋ ＋ →」连接（方法开源：收益法/比较法/DCF；事实数据：成交/挂牌/租金/去化；敏感性分析：租金/空置/折现率/退出年限压测）→ navy 输出卡（可溯源·可复现·可跟踪 + 时点快照/唯一编码注）；下方八步闭环链（项目建档→取数→假设设定→多法测算→情景压测→审批快照→审计复现与运营跟踪，末节点高亮）+ 四本账注（「在任不出事、离任查得清」）。≤1024px 链降为卡片行 + 通栏输出卡（尾部箭头隐藏）。
- **对比条**：三列网格（旧做法 | → | 贝壳做法），旧做法灰底、贝壳做法蓝左边框 + 金标签；客户六用三方对比卡（智见卡金顶高亮）。
- **数字纪律**：页内关键数字均带口径注或内联口径（300 人/40 城/50 城＝产品配置口径；2800 万＝试单授信记录；1000 万起/3000 万锚＝目标假设；左海 8 套/3000 多套/约 10%/省数千万＝已签约案例；Python＋TS＝2026-08 交付记录；1000+ 收储主体＝STAID 口径）；封底口径声明 9 项逐条对齐源稿，未新增编造数字。
- **密度适配**：桌面一屏一页严格断言；`max-height:820px` 紧凑档 + `max-height:800px` 第二紧凑档（缩小内边距/字号/间距）兜底 1366×768 等矮视口；移动端（<1024px）滚动分页（scroll-snap 保持），单列堆叠无横向溢出。
- **动效**：每页 `.fade` 入场（页进入视口点亮 `.on` 后渐显，stagger 由 `--d` 控制）；返回已读页不重播；reduced-motion 全局回退。
