## 摘要

沪八条把"收购二手住房"从去库存工具改写为保租房供给通道，研究问题随之从"收不收"变为"中心城区二手住宅的收购价—改造成本—政策租金—出租运营这条单元经济链是否成立"。三位专家的圆桌研判达成五点共识：

1. **定价（收购折扣）是整套机制的枢纽**。可行性与否几乎完全由买方定价决定：折扣锚定同期同片区真实成交价，可行域大致落在**七五至八五折**；高于九折则单元经济在中心城区散楼形态下基本不成立。
2. **散楼运营成本是最硬的物理约束**。中心城区单栋、单单元"插花式"持有缺乏园区式规模效应，人均管理间数可能仅为大体量项目的三分之一至二分之一；对冲手段是成栋成片收购与委托规模运营。
3. **REITs 是结果不是前提**。先有稳定出租率与收缴，才有估值与退出；当前衔接只能视为"制度期权"。
4. **现阶段只做框架、不做结论**。收购定价细则未出，应先把折扣率、CAPEX、租金实现率、DSCR 的盈亏边界立起来，待首批项目落地对照检验。
5. **两个季度的验证协议足以裁决**：折扣率、出租率、租金实现率三指标同时达标且规模扩至万套量级，模式成立；"高折扣+低出租"组合则问题不在定价而在选址逻辑。

**核心判断**：这一模式方向上是双轨供给框架在租赁端的正确延伸，但单元经济尚未跑通，其成败取决于评估定价机制是否锚定真实成交价，以及收购形态是"成栋成片"还是"零星点状"。

## 一、研究背景与问题界定

### 1.1 政策事实

2026 年 8 月 20 日上海发布"沪八条"、次日施行，首次把收购二手住房与"十五五"保租房发展要求绑定，限定各中心城区（含浦东外环内）推进收购并"加快改造出租"。政策原文、六部门分工在 48 小时内经新华网、人民网等密集报道可得。

### 1.2 研究问题

中心城区二手住宅转保租房，**收购定价（评估折扣）、改造 CAPEX、政策租金与出租运营的单元经济在什么条件下可行？**

### 1.3 量化口径

收购价/市场价折扣、CAPEX/间、租金折扣、出租率、收缴率、散楼 vs 园区式运营成本差、DSCR。

### 1.4 既有研究基础

内部已有收储三线估值、国企收购报名—成交漏斗（8/19）、收存转保现金流闭环（8/15）、更新转租资金闭环（8/20）四组材料，可拼出二手住宅版单元经济底座。本题为二手住宅资产转换单元经济，区别于 8/19 的交易漏斗与 8/20 的非居改建资金研究，不重复。

## 二、机制链与单元经济框架

### 2.1 资产转换机制链

中心城区选定 → 二手收购评估 → 改造认定保租 → 政策资金/REIT 衔接 → 出租 NOI → 再收购滚动

### 2.2 可行性不等式（学术批判派 L 提出，圆桌采纳）

**租金实现率 × 出租率 × 收缴率 × 政策租金 ≥ 运营成本 + 资本化摊销 + 融资成本**

由于保租房政策租金通常对标同区位市场租金的约九成，分子端几乎被锁死；可行性与否完全取决于分母端——**收购折扣率与 CAPEX 强度**。换言之，这是一道由买方定价决定的算术题，不是运营效率题。

### 2.3 四变量乘积框架（均衡发展派 C）

单元经济 = 收购折扣（足够深）× CAPEX（足够薄）× 租金实现率（足够高）× 运营成本（足够低）

- 收购价不低于市场评估价约九折 → 中心城区散楼形态下大概率不可行；
- 折扣进入七八折区间、且房源楼龄较新可轻改造 → 才具备算账基础。

### 2.4 三段式资金平衡条件（存量运营派 Q）

| 环节 | 可行条件（条件式区间） |
|---|---|
| 折价买入 | 折扣不浅于七至七五折（相对同小区同户型市场成交价） |
| 重资产改造 | CAPEX 控制在每间中低五位数量级 |
| 管制租金运营 | 租金约为市场九折；出租率≥90%；收缴率≥95% |
| 融资与可持续线 | 融资不高于收购成本五成；DSCR ≥ 1.2 |

任一段恶化，模型即从"微利闭环"滑向"财政补贴依赖"。

### 2.5 定价锚机制：比折扣数字更关键

三派一致强调评估折扣的**锚定基准**比折扣数字本身更关键：

- 必须锚定近三个月同板块**实际成交价**再向下浮动——收购方承接的是流动性折价（业主获得确定性退出）与持有期折价（放弃涨价期权）；
- 若以滞后挂牌价或高位成交价为锚，折扣名存实亡（C）；下行市场中挂牌价与成交价锚的差异可达两位数百分点（L）；
- 若首批项目收购价显著高于周边成交折扣价的合理区间，说明定价被"稳房价"目标绑架，保租房资金平衡被架空（Q，可证伪）。

### 2.6 散楼运营的物理约束与对冲

**约束（三派共识，分歧仅在可否对冲）**：

- 中心城区二手住宅天然分散、单栋规模小、无集中管理界面，规模经济在物理形态上被否定（L）；
- 人均管理间数可能仅为大体量园区式项目的三分之一至二分之一，租客结构更杂、纠纷率更高（Q）；
- 修缮责任、消防合规、邻里冲突等隐性成本大概率未计入现有口径，实际 CAPEX 被系统性低估（L）。

**对冲路径（C、Q）**：

1. **收储成片**：以街坊为单元、成栋成套集中收购而非零星散收，把散楼问题在资产获取端转化为"准集中式"；
2. **委托规模运营**：运营打包委托给已具备规模效应的专业机构，跨项目归集后台职能、用组合摊薄成本。

若政策执行变成零星散户式收购，该约束不可对冲，模式不成立。

### 2.7 REIT 衔接：制度期权而非现金流安排

- REITs 要求资产规模、出租率与运营历史达到门槛，且要求**可标准化的现金流**，不是政策意愿（L）；
- 散楼组合若不能形成可整体估值的资产包，只是 Pre-REITs 概念的持有，退出通道未真正打开（Q）；
- 先有稳定出租率与租金收缴，才有资产估值，才有退出通道——把 REITs 可行性倒过来作为收购决策依据是因果颠倒（C）。

## 三、对红队三点反驳的处置

| 红队反驳 | 圆桌处置 |
|---|---|
| ① 上海未公布收购定价细则，现阶段只能做框架不能做结论 | **采纳为本报告立场**。C：框架本身是政策工具，细则公布时对照四变量即可检验其是否在可行域；Q：细则迟迟不出本身即负面信号，细则之日看折扣、CAPEX 上限、租金定价公式三个数即可判定真伪；L：评估锚歧义下做结论即伪科学 |
| ② 中心城区散楼改造成本远高于园区式，REIT 衔接存疑 | **判定为最实质的质疑**（C）。C/Q 主张成栋成片收购 + 委托运营可部分对冲；L 持证伪立场，指隐性成本使 CAPEX 系统性低估 |
| ③ 收购规模若小，两端象征意义大于实际 | **部分保留、列为最高观察权重**。C：混淆试点期属性与终态，判据是两个季度后有无第二三批与细则迭代；Q：象征与实质可转化，取决于扩围与定价守住；L：千套以下量级两端均象征性，须明确区分信号价值与实物供给价值 |

## 四、共识、分歧与开放问题

### 4.1 共识（五点）

1. 定价（收购折扣）是机制枢纽，可行域约七五–八五折（锚定真实成交价）；
2. 散楼运营成本是最硬的物理约束，对冲靠成片收购 + 委托规模运营；
3. REITs 是结果不是前提，当前仅"制度期权"；
4. 现阶段只做框架不做结论，细则不出本身即负面信号；
5. 两个季度的验证协议足以裁决模式性质。

### 4.2 分歧（四点）

1. **先验态度**：C 视之为正确的制度动作；L 强调去库存与保租房目标内生冲突，批判基调更重；
2. **散楼可否对冲**：C/Q 认为可部分对冲、非否决项；L 倾向证伪；
3. **折扣阈值口径**：C"高于九折不可行、七五–八五折可讨论"；Q"低于七五折合格、高于八五折存疑"双线；L"折扣达两成以上需核查筛选偏差"——区间重叠、目的不同（算账 vs 证伪）；
4. **象征意义定性**：C 主张小规模是必要校准；L 以千套量级为象征性门槛；Q 留待观察。

### 4.3 开放问题（六项）

1. 评估折扣锚定机制：挂牌价、评估价还是实际成交价？是否计入议价空间与持有期折价？
2. 改造标准与 CAPEX 口径：隐性合规成本是否计入？散楼最小管理单元如何界定？
3. 政策租金定价公式与市场租金、支付意愿的联动；
4. 资产打包路径：散楼组合能否形成达 REITs 门槛的可整体估值资产包？
5. 收购规模与批次节奏：首批量级、第二批扩围与否、细则是否随经验迭代；
6. 资金结构：财政贴息/政策性资金与市场化融资比例及其对 DSCR 的实际含义。

## 五、验证协议与观察指标

**跟踪窗口**：上海首批中心城区收购项目落地后两个季度。

| 指标 | 阈值/信号 | 来源 |
|---|---|---|
| 收购折扣率（成交价/同期同片区真实成交价） | >九折：基本不可行；七五–八五折：可讨论/双线判定；≥两成折价需查筛选偏差 | C/Q/L |
| 改造周期（交房→出租） | >6 个月：散楼运营模型跑不通 | Q |
| 首季/首年出租率 | 首季<70% 应暂停扩量；首年<85% 模型存疑；两季度内稳定≥90% 为达标 | C/Q/L |
| 租金实现率（实收/政策定价） | 持续<85% 暂停扩量；连续两季<95% 现金流受侵蚀；≥95% 达标 | C/Q/L |
| 散楼单间月运营成本 / 园区式比值 | >1.5 倍且无收敛：收缩为成栋收购；REIT 路径基本证伪 | C/L |
| DSCR | ≥1.2 为可融资/可持续线 | Q/C |
| 收购规模与批次 | 千套以下为象征性量级；两季度内有无第二批与细则迭代为终态判据 | L/C |

**裁决规则（L，圆桌采纳）**：

- 两个季度内折扣、出租率、租金实现率三项同时达标、且规模扩至万套量级 → 模式在中心城区**成立**；
- "高折扣 + 低出租"组合 → 问题不在定价而在**选址逻辑**，政策需重构而非扩围；
- 细则持续缺位、无第二三批 → 模式判定为**象征姿态**。

## 七、结论

沪八条"二手转保租"机制的方向值得肯定——它以存量收购替代增量新建，同时回应中心城区租赁供给缺口与二手市场流动性压力，是双轨供给框架在租赁端的延伸。但**方向正确不等于单元经济已经跑通**。

圆桌的一致裁决是：该模式的可行性是一道**买方定价的算术题**。收购折扣锚定真实成交价并进入七五–八五折区间、CAPEX 控制在每间中低五位数、租金实现率与出租率分别稳定在 95% 与 90% 以上、散楼单间运营成本不超过园区式 1.5 倍且 DSCR 站上 1.2——满足这一条件组合，中心城区二手转保租成立；任一段恶化，即滑向财政补贴依赖或象征姿态。

在定价细则落地前，本报告提供的是盈亏边界框架与验证协议，而非结论。首批项目的两个季度数据，将给出最终裁决。

## 八、风险提示

1. **细则风险**：收购定价细则迟迟不出，或锚定基准偏离真实成交价，则折扣名存实亡，本框架的"可行域"判断失效；
2. **成本低估风险**：散楼隐性合规成本（消防、修缮责任、邻里纠纷）未计入现有口径，实际 CAPEX 或被系统性低估；
3. **规模风险**：首批规模过小导致两端均为象征性操作，政策信号价值大于实物供给价值，易造成"模式已验证"的误读；
4. **筛选偏差风险**：折扣过深（两成以上）需核查是否只收劣质资产，否则去化与出租端将反噬测算；
5. **样本风险**：中心城区先行，结论不可外推至非中心城区或其他城市。
