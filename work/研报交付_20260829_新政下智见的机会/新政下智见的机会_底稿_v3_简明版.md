# 新政下智见的机会 · 简明版（底稿 v3）

**一句话战略**：1+N 新政把中国房地产的估值函数从"关系与暗箱"换成了"数据、核验、审计"——智见的机会不是卖数据，是铸造新函数里流通的 **Token（一枚可验证、可计价、可流转的最小交付单元，像一张带防伪码的电子回执）**。问题只有一句话：这个铸造权是我们的，还是别人的。

**点睛图（图 ⓪·链条流程图，定性示意）**：一个必然 → 三个倒计时 → 三层引擎 → 两台发动机 → 一条纪律。

**框架五句话**（全文都挂在这五句上）：

| 框架层 | 一句话 |
|---|---|
| 一个必然 | 估值函数更换，定价权必须再分配——铸造权不会消失，只会易主 |
| 三个倒计时 | 2026Q4 白名单公布 · 首单银行合同窗（准入 12-18 个月）· 2027-03 信托切换与细则潮 |
| 三层引擎 | 标尺层定锚（卖标尺不卖数）→ 工程层造线 → 信用层立信（四本账五问） |
| 两台发动机 | F1 银行重估订阅 + K1 收储定价；其余 24 张机会卡都是期权 |
| 一条纪律 | 三不＝三卖——可审计性是唯一不可复制的护城河 |

## 一、为什么必须做：三个倒计时

> **本章金句：Token 的铸造权是窗口资产，不是长坡资产——错过即出局。**

**一句话结论**：新政每一条"必须被看见、必须被核验、必须能审计"的条款，都是一张写好金额的制度发票；发票开出后 12-24 个月是口径定型期，谁先被审批链接受谁就是"默认"，后来者要付整个更换成本。

**制度改了什么（三件事）**：

| 新政条款 | 改了什么 | 对智见的含义 |
|---|---|---|
| 《意见》34 条 | 全口径统计＋严防数据造假 | 申报口径必须用交易事实交叉核验——核验需求被制度化 |
| 个贷办法 25 条 | 押品每年重估、不得以再评估净值追加贷款 | **36.29 万亿元**存量按揭（2026-06，Wind EDB）每年必须重估一次，存量变常年滚动需求 |
| 开发贷办法 26 条 | 白名单直报、可问责 | "申报 vs 事实"的差异第一次成为监管责任——差异报告有了制度位置 |

**三个倒计时（不做会怎样）**：

| 倒计时 | 时点 | 错过的后果 |
|---|---|---|
| ① 白名单覆盖率公布 | **2026Q4** | 差异报告的标准卡位窗关闭：官方或竞品口径定型，智见从"立标准"降级为"买标准的用户" |
| ② 首单银行年度合同 | **2026Q4-2027H1 启动** | 名单制准入要 12-18 个月——晚启动一年，收入兑现推到 2028 年；同期头部行自建 AVM 内部化 |
| ③ 信托切换＋细则潮 | **2027-03-01 施行**＋2027 年内三项细则 | "上线即默认"的窗口只有一次；细则出台后再入场，是在别人口径里做填空题 |

**不做的三种死法**（铸造权归谁）：**官方标定**（细则把主办行数据定为法定来源）；**竞品接走**（榜单渠道商套上"审计工程"外壳）；**银行自建**（头部行 AVM 内部化，重估永不外采）。三条路的共同点：**都不需要智见在场。**

**为什么是现在**：净息差约 **1.5%**（金监总局 2026Q2），惜贷是银行的理性——银行不是没钱，是不敢在没有可复现证据时放款；1000+ 收储主体面对约 2% 租金回报率 vs 约 3% 资金成本（测算口径）的闸门，没有中性定价底稿就不敢收房。需求不是"可能的生意"，是写进细则的合规成本。

> **点睛图（图 1·接力时间轴）**：2026Q4（白名单覆盖率公布——标准卡位窗关闭）→ 2026Q4-2027H1（首单银行合同窗——准入 12-18 个月）→ 2027-03（信托切换＋细则潮——上线即默认只有一次）。

## 二、Token 是什么：一张带防伪码的电子回执

> **本章金句：每次制度开票，都是一次 Token 的铸造。**

**一句话结论**：智见卖的不是数据、不是报告，是一枚枚可验证、可计价、可流转的最小交付单元——银行审批链、监管检查链、国企审计链都能认它。

**三性**（缺一不算 Token）：
- **可验证**——证据链回写：谁在何时、基于哪个版本、什么证据、经谁审批、能否重放；
- **可计价**——订阅 / 按次 / 按量三种收法；
- **可流转**——在客户的审批链和监管的检查链上被接受、被引用。

**三层支撑**（每层一行）：

| 层 | 干什么 | 一句话 |
|---|---|---|
| 标尺层 | 定锚 | 估值框架开源＋40/50 城口径分层——卖标尺，不卖尺子量出的数 |
| 工程层 | 造线 | skill＋agent harness＋垂类模型＋专用终端——合作方无法在合同期内自建 |
| 信用层 | 立信 | 四本账（事实/假设/方法/责任）＋同条件重放＋五问可答——把"信任"变成可审计资产 |

**先例**：中行广州 Token 贷 2026-08 落地试单、授信 **2800 万**（授信额≠收入，不得混用）——银行已经接受"一枚押品一枚重估 Token"这种交付形态本身。

**实证（2026-08-29 政研通 CLI 实测）**：指标目录接口实测返回 **analytics-v1.1**（约 20+ 条指标，每条自带分层/置信度/四级贯通/状态标记）；最硬的三条：贝壳官方房价/租金指数（重复交易法，基期 **2018-11=100**，直接入库不做客户端重算）、去化周期冷热分档（<6/6-12/12-24/>24 个月）、带看转化率（＝成交÷带看，需两源交叉才成立——单一数据商造不出）。租赁类指数置信度标注为"低"——**敢把低置信度印在目录上，正是可审计性卖点的实物证明。**

> **点睛图（图 2·链条流程图，定性示意）**：标尺层（供锚）→ 工程层（供产能）→ 信用层（供接受度）→ 铸造流水线（越用越深＝护城河）。对手可以抄走一份报告，抄不走一条越用越深的流水线。

## 三、六类客户怎么接：一张条款对照表看懂

> **本章金句：免费的不是服务，是定价权的入场券。**

### 3.1 中央部委｜免费换标准（A 线，3 卡）

**一句话结论**：部委不付费，但它把谁的标准写进工作流，谁就定义了全行业的口径——免费换的是定价权入场券。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 《意见》34 条（全口径统计） | 申报口径用交易事实交叉核验 | A1 政策执行追踪·失灵变量仪表盘（免费） |
| 好房子认证细则（2027 年内） | 分级分档的可核验依据 | A2"好房子"分级数据基线（免费） |
| 《意见》7/11 条（经营性收入覆盖） | 城更项目入库的现金流门槛 | A3 全周期现金流复现底稿（免费） |

纪律：政府端免费投入 ≤ 总成本 20%（STAID 口径），以"部委/协会采纳智见口径"书面里程碑为继续投入闸门。

### 3.2 地方监管｜守门人的免责底稿（B 线，4 卡）

**一句话结论**：守门人要的不是数据，是出了事能自证的底稿——B1 差异报告是两台发动机的政府侧入口。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 开发贷办法 26 条（白名单直报） | "申报 vs 事实"核验、可问责 | B1 差异报告（四段式）——2026Q4 第一检验；呈报口径：白名单 **300 人**（领导直问） |
| 城市更新办法 8/9/13 条（项目库） | 入库项目现金流核验 | B2 项目库核验（与 K3 测算书同源同口径） |
| 收储贴息落地 | 全省收储台账监测 | B3 收储监测模块（台账订阅计价） |
| 1+N 七文件落地 | 地方细则跟踪映射 | B4 政策日历（细则密集期的即时入口） |

四卡共用同一套数据底座与口径——每多进一个工作流，底座复用摊薄全部产品的边际成本。

### 3.3 金融机构｜36 万亿的年度重估（F 线，5 卡＋1 批判卡）

**一句话结论**：新政给银行开的是存量合规账单——36.29 万亿按揭每年重估是写进细则的强制需求，订阅制、抗惜贷。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 个贷办法 25 条（年度重估） | 每年重估全部押品、留底稿 | **F1 重估 Token 订阅**（发动机①）：批量重估＋三分归因底稿；年费 1000 万起/3000 万锚（目标假设） |
| 个贷办法 23 条（风控独立开展） | 银行独立决策、外部只供证据 | F2 数据前筛（做底稿不做签章） |
| 净息差约 1.5%、惜贷 | 放款要可复现证据 | F3 风险定价参照（40/50 城分层口径打包） |
| 开发贷办法 21 条（第三方留痕核验） | 第三方核验留痕 | F4/F5 核验与机构基础包（随量收敛） |

批判卡 F6 如实记账：替银行做信贷决策的门被新政关小了——这正是"卖底稿不卖决策"的原因。

### 3.4 保租房国企/城投｜谁把闭环算清，谁给闭环定价（K 线，5 卡）

**一句话结论**：城市更新办法把"经营性收入足额覆盖本息"焊死为城投生死线——谁把闭环算清，谁给闭环定价。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 团购房贷（批量收房） | 收储定价、租金覆盖本息 | **K1 定价 Token**（发动机②）：左海模式（单套低约 **10%**、省数千万、续约复购——已签约口径）复制为批量定价 |
| 《意见》7/11 条（收入覆盖） | DSCR 双情景测算 | K3 测算书（政府-城投同源同口径） |
| 土地财政退坡（出让金自 **8.7 万亿**峰值近腰斩，财政部口径） | "卖项目"经营性收入接棒 | K2 闭环全链估值；收储贴息约 **3 万亿**/100-200 万套（测算口径）放大需求 |
| 团购房贷期限延长 | 本金上限约 **+17.5%**（测算口径） | K4/K5 可贷与 REITs 分派对标（一句带过） |

定价闸门：租金回报率约 2% vs 资金成本约 3%（测算口径）——没有中性底稿，1000+ 主体不敢收房。

### 3.5 开发商｜不赚开发商的钱（D 线，4 卡）

**一句话结论**：开发商付费能力在缩表（开发投资 -19.2%、销售面积 -11.8%，Wind EDB 2026-07）——付费方在整合者、收储方和银行。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 第三章（杠杆拆除、资金封闭） | 并购出清要项目级画像 | D1 并购尽调前筛（整合者付费，最高优先级） |
| 托底拿地终结 | 存量土储处置 | D2 处置底稿（随收储工作台打包，收储方付费） |
| "好房子"标准落地 | 甄别可贷资产 | D3 甄别数据包（银行付费）；D4 轻订阅（开发商仅此） |

### 3.6 C 端个人｜C 端不收费（C 线，4 卡＋1 远期）

**一句话结论**：C 端全线引流不收费——收费的是信任的复利（转化与口碑）。

| 新政条款 | 对方要做什么 | 智见做什么（卡号） |
|---|---|---|
| 个贷办法 10 条（月供比 ≤50%、全债务比 ≤60% 红线） | 算清合规边界 | C1 红线合规测算器（贝壳 APP 高频工具位） |
| 带押过户推广 | 置换路径算账 | C2 置换沙盘（单省约 **4.5 万**/单——测算口径） |
| 现房销售推进 | 交付风险提示 | C3 提示位（转现房分销，放款后结佣）；C4 公益、C5 远期只沉淀不铸造 |

按揭止跌概率 55-60%（2027H1 前，研判推断；贴息并联上修 70%+）决定 C 线节奏。

> **点睛图（图 3·卡阵）**：六客户线全景——A 部委·3 卡定标准｜B 监管·4 卡发入口｜F 金融·5 卡付现金（发动机①）｜K 城投·5 卡定闭环（发动机②）｜D 开发商·4 卡借道走｜C 端·5 卡沉淀信任；与本章六张条款对照表逐一对应。

## 五、不做什么：拒绝清单比机会清单更值钱

> **本章金句：在谁签章谁担责的新政体系里，拒绝本身构筑了最深的那道护城河。**

**一句话结论**：可审计性从拒绝开始——伪机会逐条证伪，纪律写成对外话术。

**伪机会 7 条（每条一句话死法）**：①工程监理/核验执行——人力密集＋59-60 条责任连带；②信贷定价/风控决策——个贷 23 条红线，替银行签字即责任模糊；③评估签章——法定资质＋无限责任，无牌即非法；④卖数据给银行——银行要"账户级的真"，补充真无付费理由；⑤替客户预测市场——一次打脸连坐全部底稿可信；⑥给开发商做纾困融资方案——付费方在缩表，制度租金随制度取消；⑦大而全数据门户——与贝壳主站自我竞争，且无审计纵深。

**三不＝三卖（对外话术）**：不卖签章，卖能进审批工作流的底稿；不卖预测，卖可复现的条件化推演；不卖决策，卖客户自己的决策有据可查。

**不铸三种坏 Token**：铸不了的（无证据链）、越权的（签章/定价决策）、预测型的（趋势承诺）。

> **点睛图（图 5·三方对比卡，定性示意）**：不卖签章→卖底稿｜不卖预测→卖推演｜不卖决策→卖可查；对应三种坏 Token：铸不了/越权/预测型。

## 六、风险与四个观察窗口

> **本章金句：每个失灵变量都有对冲，才配叫战略。**

**一句话结论**：Top3 机会各有一个命门和一个对冲，全部写在此处，不对冲就不开工。

| 机会 | 命门（失灵变量） | 对冲 |
|---|---|---|
| F1 重估订阅 | 个贷 23 条被从严解释→外部供应商被挡 | 主攻中小行/城商行（自建不经济）；合同写明"证据非决策"边界 |
| K1 收储定价 | 贴息节奏不落地（止跌概率仅 55-60%） | 与 B3 监测并联（政府侧先进入）；按项目制收费降低客户试错成本 |
| B1 核验 | 细则把核验权收归官方 | 免费换标准卡位口径；差异报告四段式即官方检查的现成格式 |

**Token 三大风险**：断锚（标尺失灵＝全局杀手，用口径纪律对冲）；租金之雷（把平台数据铸成 Token 授人以柄，贝壳数据只做证据层）；实测节奏（成本收敛幅度待灯塔实测，不承诺比例）。

**四个观察窗口**：2026Q4（白名单覆盖率/主办行投放/首批市场化运营主体名单/城更入库数）｜2027-03（信托切换/期房占比基线）｜2027H1（止跌与否/首轮重估检查/REITs 扩募/首单年度合同）｜滚动（期房归因/利差分层/数据前筛采用数/测算口径引用省数）。
