## 〇、执行摘要（五条关键判断）

**判断一（总体）**：新政对江苏银行零售业务部是"**直接冲击有限、间接链条深、结构性机会大于总量风险**"的组合。按揭仅占其贷款总额约 8.9%（2,462.43 亿 / 27,703 亿，2026Q2，Wind，占比为计算值），零售资产重心在消费贷而非按揭——新政直接改写的是按揭规则，江苏银行零售的敞口结构决定了它不是受冲击最重的银行类型。

**判断二（产品层·按揭）**：40 年期限 + "能拿房、再还贷"重塑按揭产品要素：月供降约 15%（100 万 / 3.06% 测算）改善刚需承接，但期房按揭放款整体后移至竣工备案后，按揭投放的**节奏与规模短期双承压**；二手房按揭不受"竣工备案"时点约束，是明确的**结构性替代战场**。

**判断三（渠道层·主办银行）**：主办银行制度把"楼盘项目—按揭客源"的入口向主办行集中。新房按揭获客将与项目主办资格深度绑定，**非主办行的零售分行按揭获客渠道收窄**——对总部在南京、江苏省内县域全覆盖的江苏银行而言，这是必须正面应对的入口之争。

**判断四（客群层·卖旧买新）**：南京"新房率先修复（-1.8%）、二手仍在出清（-5.4%）"的结构，正是零售按揭与消费信贷的**关键夹缝场景**：卖旧买新的资金错配（旧房出售款与新按揭放款的时间差）催生桥接类融资与交叉销售的真实需求窗口。

**判断五（风险层）**：低不良（0.81%，2026Q2）+ 按揭低占比 = 总量安全垫厚；真正的风险在**资产久期拉长（40 年）与利率下行平台（新发放按揭 3.06%、全行净息差 1.64%）**的错配，以及切换期"购房者付首付、银行未放款"阶段的开发商关联风险传导。个人贷款不良率、按揭不良率明细 Wind 未披露，列入补数协议（Part C）。

## 三、五层影响分析

### 3.1 战略层：方向——"按揭小、消费大"的结构缓冲与战略再平衡

新政周期里，零售银行的战略问题从"要不要做按揭"变成"**按揭怎么 position、消费贷怎么防传导、财富怎么接现金流**"。对江苏银行零售业务部：
- 按揭占比约 8.9%，新政直接营收冲击测算有限（即便期房按揭新增投放当年下降三成，对全行营收影响也在低个位数百分比量级——测算推断，非精确口径）；
- 但按揭是**获客与主办关系的入口产品**：房子是家庭最大资产负债事件，按揭客户的交叉销售价值（代发、财富、消金、卡）远超贷款本身利差。放款后移 = 入口事件后移 = 客户旅程重构，这是战略层真正的课题；
- 宏观审慎章节给按揭利率/首付留了制度化下调接口，策略上应把 40 年按揭与后续可能的存量工具视为**政策期权组合**，预留定价与系统弹性。

### 3.2 客群经营层：对象——三条客群主线的旅程重塑

**主线 A｜期房刚需客群**：旅程从"签约即放款"变为"签约—等待竣工备案（2-3 年）—放款—还贷"。等待期内客户处于"已付首付、无负债、无房"的**金融空窗态**：这是财富管理（闲置首付资金打理）、消费分期、装修贷预约的真实窗口；放款后进入 40 年久期还贷态，月供下降 15% 释放当期现金流，交叉销售（代发工资归集、AUM 提升窗口）随放款事件整体后移但生命周期更长（40 年绑定期）。
**主线 B｜卖旧买新改善客群**：南京新房 -1.8% 已率先修复、二手 -5.4% 仍在出清——该客群的瓶颈在"旧房卖不掉"。零售端真实需求是**资金桥接**（旧房未售期间的新房首付周转）与带押过户配套；该场景需求真实但合规敏感，必须以合规产品承接、不得以消费贷违规流入楼市（风险层回填）。
**主线 C｜消费信贷基本盘客群**：消费贷 3,276 亿是零售资产第一大盘。传导链：房企回款后移 → 建筑地产链就业与收入承压 → 消费信贷需求与资产质量双传导；反向看，"能拿房再还贷"与月供下降释放购房家庭当期现金流，边际利好消费。净效应区域分化：江苏本土就业结构对地产链依赖低于全国平均（制造业占比高），缓冲垫相对厚——该判断为定性推断，需就业结构数据验证。

### 3.3 产品层：武器——按揭产品要素重构与产品组合再定位

**按揭产品（要素级变化）**：
1. **期限档位**：30→40 年，同额月供降约 15%（测算：100 万 / 3.06% 等额本息，4,247→3,614 元）；总利息升约 39%（52.9 万→73.5 万，测算）——产品话术必须双面披露，适当性管理前置；
2. **放款时点**：期房按揭从"备案后 T+N"变为"竣工备案后"，产品流程需新增**竣工备案核验**环节，与主办行（若非本行）的数据协作是运营新课题；
3. **价格梯度**：现房/二手房按揭（不受竣工备案约束）与期房按揭形成**流动性价差**，定价上二手房按揭可作为短期主推；
4. **受托支付**：支付指令定向至监管账户/主办行账户，跨行协作流程需重建。
**消费贷/消金（苏银凯基）**：月供下降 15% 释放的家庭现金流是消费贷需求的边际支撑；但严禁消费贷资金违规流入房市（首付桥接需求必须由合规产品承接），共债监测（房贷+消金双高客群）前移。
**财富/AUM**：等待竣工期的首付闲置资金（2-3 年期）是理财/存款的天然场景；40 年久期负债客户的全生命周期财富规划（未来 70 岁仍在还贷的客户，其养老金融需求结构改变）是长线交叉销售主题。
**产品协同链**（触发场景→主产品→关联产品→约束）：签约期房 → 按揭预约+首付资金理财 → 竣工备案放款 → 代发归集+信用卡+消金额度预审批 → 40 年生命周期财富规划；约束：适当性、资金流向监控、销售合规。

### 3.4 资产层：结果——规模、收益、久期三维变化

**规模**：期房按揭投放节奏后移 2-3 年，按揭余额增速短期回落（全国按揭余额已连续净减少：37.90→36.29 万亿，-4.2%）；现房/二手房按揭与"卖旧买新"链条是对冲项。零售总量增长引擎仍以消费贷为主，但需警惕其宏观敏感性。
**收益**：新发放按揭利率全国 3.06%（2026Q2）低位平台，40 年期限并不带来更高利率（期限溢价受宏观审慎约束），反而拉长资产久期；全行净息差 1.64% 背景下，按揭的税后风险调整收益需重算——**低收益率 + 超长久期**的组合使按揭更多承担"入口+合规+政策期权"角色而非利润引擎。
**久期与流动性**：40 年资产久期 vs 存款/理财负债久期缺口扩大；利率下行平台中再定价风险可控，利率反转上行期的资产贬值风险后移——需资产负债表层面做期限对冲（此为司库职责，零售提供久期数据）。
**风险调整后收益**：按揭不良率通常是零售资产最低档（江苏银行全行不良 0.81% 已处低位；个贷/按揭不良明细缺，见补数协议），低资金成本区位（江苏存款禀赋）下按揭风险调整后收益仍优于表观利差——推断，待不良明细验证。

### 3.5 风险层：边界——五道闸门

1. **入口闸门（主办银行制）**：新房按揭客源向项目主办行集中，非主办行获客成本上升。应对：公司/零售联动争夺江苏省内重点项目主办资格；非主办项目探索与主办行的按揭转介合作模式（合规前提）。
2. **切换期闸门（2026-2028）**："付首付、未放款"阶段的开发商资金链风险（全国开发投资 -19.2%）可能以项目停工形式传导为客群投诉与声誉风险；对已签约未放款存量需逐笔重检抵押与在建工程状态。
3. **抵押物闸门**：南京二手 -5.4%、70 城 -3.4%，抵押率（LTV）动态管理；40 年期限放大了抵押物价值波动的暴露年限。
4. **共债闸门**：按揭 + 消费贷 + 信用卡多持客群的压力测试（收入预期下行 + 利息总额上升 39% 的叠加）。
5. **合规闸门**：卖旧买新桥接需求严禁消费贷/经营贷资金违规入楼市；受托支付与资金流向监控嵌入流程；40 年按揭销售必须双面披露总利息成本（适当性）。

## 四、区域禀赋：江苏腹地 × 南京样本

江苏银行基本盘在江苏，样本城市南京给出区域相对优势的证据：南京新房价格同比 -1.8%（2026-07，自 2026-03 的 -4.1 快速修复，修复弹性在可比城市中最大）、二手 -5.4%（探底后连续 6 个月收窄）。对比全国 70 城新房 -3.4%、北京新房 -2.3%：**南京新房修复斜率领先，区域资产价格环境边际改善**。这意味着江苏银行零售按揭的核心抵押物池（南京及江苏城市）的估值压力正在缓解，切换期风险低于全国平均。南京市统计局销售面积口径仅更新至 2026-02（-13.5%），时效受限，列为补数协议。

## 五、分阶段行动建议（每条含：动作—客群—指标—约束）

**第一阶段（0-3 个月，制度落地期）**：
1. 按揭产品要素改造：40 年档位上线、竣工备案核验流程、受托支付跨行协作 SOP——指标：流程时效、改造成本；约束：双面披露总利息。
2. 存量已签约未放款台账重检：逐笔确认项目竣工预期与抵押状态——指标：重检覆盖率 100%；约束：客诉预警线。
3. 主办银行资格卡位：与公司条线联动，圈定江苏省内重点新开盘项目清单——指标：主办行资格项目数、可承接按揭项目渗透率。

**第二阶段（3-12 个月，结构切换期）**：
4. 二手房/现房按揭主推策略（不受竣工备案约束的替代战场），联动带押过户——指标：二手按揭新增占比；
5. "卖旧买新"客群 STP：已持有本行住房贷款 + 有改善意向标签客群，合规产品承接资金桥接——指标：转化率、资金流向合规率；
6. 消费贷共债压力测试：房贷+消金双持客群分层限额——指标：Vintage 逾期、共债集中度。

**第三阶段（12 个月+，新模式稳态期）**：
7. 40 年客群的全生命周期财富规划产品线（养老金融重定义）；指标：按揭客户 AUM 转化、产品持有数；
8. 宏观审慎期权储备：若首付/利率工具启用，48 小时内可落地的定价与系统预案——指标：预案演练完成率。

## 六、观察指标与补数协议（Part C 素材）

**观察指标**：本行期房按揭放款时点分布（放款后移幅度）、40 年期按揭占比、二手房按揭新增占比、按揭客户交叉销售率、消费贷 Vintage 与共债集中度、主办行资格项目数、南京/江苏二手价格收窄斜率、全国按揭余额月度净变动。
**补数协议（Wind 未取到项）**：① 江苏银行个人贷款不良率、住房按揭不良率（2025 年报/2026 中报明细）；② 个人贷款余额绝对值的权威披露口径交叉验证（当前以零售贷款 1.0034 万亿 / 占比 36.22% 为准）；③ 零售 AUM、按揭客户交叉销售率等经营指标（内部数据）；④ 南京商品房销售面积市统计局口径更新。
