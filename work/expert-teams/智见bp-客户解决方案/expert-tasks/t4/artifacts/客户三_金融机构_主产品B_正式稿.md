# 客户三 · 金融机构（银行 / 保险 / 券商 / AMC）——贝壳解题思路与产品优势

## 一页结论

金融机构的不动产风险敞口，卡在「授信时点估一次、贷后放任不管」：抵押物估值依赖单点评估、贷后无持续监测；压力测试缺统一口径；评估报告不可复现、签章责任重。贝壳的答案是**主产品 B · 金融机构不动产风险工作台**——T0 估值 ＋ T+N 监测，把「可审计」翻译成银行的 KPI（减值计提、押品充足率、内审结论、监管检查整改成本），价值侧与付费侧同时成立。

## 需求痛点

- 抵押物估值依赖单点评估报告，贷后无持续监测，估值与市场变化存在时滞；
- 组合层面压力测试缺数据与统一口径（区域 / 物业类型 / 客户集中度）；
- 评估报告不可复现：内审、监管检查时无法还原当时的估值依据与审批过程；
- 评估报告签章责任重：结论类输出一旦出错，责任界面不清。

## 贝壳解题思路的不同（核心）

**主产品 B · 金融机构不动产风险工作台**：

- **T0 授信时点估值参考**：房源级估值区间 ＋ 置信度，与外部评估报告差异自动比对、按数据 / 方法 / 假设三分归因，形成授信参考底稿；
- **T+N 贷后监测**：持续更新估值、价值偏离预警、组合压力测试，自动生成贷后复核底稿，供内审与监管查验；
- **把「可审计」翻译成银行 KPI**：减值计提、押品充足率、内审结论、监管检查整改成本——一次估值偏差的成本远高于系统年费，且是持续需求而非项目制；
- **做底稿、不做签章**：估值只做过程、不做结论；需盖章环节引入持牌评估机构协作——不抢法定评估刚需，分润补位、责任界面清晰。

## 产品优势

- **差异归因（数据 / 方法 / 假设三分）**：与外部评估报告的偏差可解释、可追溯，而非「两个数打架」；
- **价值台账持续可查**：同条件可复现，内审问询一键还原；
- **贷后复核底稿**：直接供内审与监管检查查验；
- **先例背书**：Token 贷已由中国银行广州分行 2026-08 落地试单、授信 2800 万，模式被银行与监管接受——江苏银行谈的是复制升级，非首创。

## 产品组合

主产品 B 金融机构风险工作台（T0+T+N）＋ 机构基础包（数据 ＋ 模型服务）＋ API / 嵌入式组件 ＋（可选）私有化部署。

## 交付团队

银行风控产品团队 ＋ 数据团队 ＋ 模型 / 压力测试工程师 ＋（签章环节）持牌评估机构。

## 定价纪律（内部口径，不对外承诺）

银行年费 1000 万起、3000 万为合适锚（目标假设）；首单让功能不让价格、按机构分档、先签年度。
