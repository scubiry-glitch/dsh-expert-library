## 一、关键性结论（结论先行）

1. **「深度」是唯一难以被复制/采购的壁垒**：从 skill（提示工程层）升级到 harness+垂类模型预训练层次一体化，本质是把"方法论文本"升级为"工程资产（编排/工具/证据回写）+ 参数资产（语料微调）+ 终端资产（决策动作发生地）"三层一体——skill 是可被抄走的文档，后三者抄不走，这是合作方无法在合同期内自建的理由。
2. **深度优势的直接变现载体是合规与审计**：私有化部署（数据不出域）、五链（可审计可复现）是银行/国企采购的硬门槛；纯 skill 方案依赖外部模型 API，数据出域即出局。
3. **深度必须与责任纪律捆绑销售**：做底稿不做签章、只描述已发生——没有责任边界，深度只会放大责任敞口，银行法务关过不去。
4. **合作必须条款化**：数据授权、口径、免费投入上限、付费测试、退出机制缺一不可，否则"优势"退化为"被白嫖的资源"。

## 二、关键事实及其变化分析（技术路线对比）

路线 A＝只使用 skill（提示工程层：解读框架/路由/输出规范/技能包，四件套中仅一件）；路线 B＝专家 skill ＋ 专用 agent harness（任务编排/工具调用/证据链回写/多步推演）＋ 垂类模型（不动产语料微调/预训练层次）＋ 专用终端（对话+底稿+审批一体）。

| 对比维度 | A 只使用 skill | B harness+垂类模型一体化 |
|---|---|---|
| 效率（一次成稿/少返工） | 通用模型每次重走推理，长任务易丢步、返工多 | 编排+预置知识一次成稿；垂类语料减少术语纠错 |
| 成本（token/缓存复用） | token 随调用线性增长，无缓存复用设计 | Token 用量少、缓存复用，单位成本随量收敛（幅度待灯塔实测，不承诺比例） |
| 质量（口径/证据/审计） | 口径靠提示词硬顶、无证据回写，幻觉难控 | 口径统一、输出必带引用与假设条件；harness 回写证据链，五链支撑可审计可复现 |
| 能力边界（多步推演/工具/私有化） | 只能生成文本；无工具调用、无多步推演 | 多步推演、工具调用、审批流嵌入；模型+框架+工具链整体下沉客户环境 |
| 合规（银行/国企） | 依赖外部 API 或通用模型私有化，成本高、数据出域风险 | 数据不出域、离线可用（33+ 专家预置、BK 档案），满足敏感场景合规 |

**结论**：差异化深度 = 编排层（harness）+ 参数层（垂类模型）+ 终端层（决策动作发生地）三层一体；对合作的前提价值＝私有化部署、数据不出域、可审计决策过程——这正是"卖可审计决策过程"定位的技术底座：没有 harness 的证据回写与版本链，可审计只是口号。

## 三、归因分析（补充优势 ≥2 条）

深度优势的根因是**生态数据资产**：自有真房源成交数据（二手/租赁为自有强项，底稿 D 层矩阵）+ 33+ 位专家五域 BK 档案——垂类模型微调的语料基础是竞品（中指/克而瑞靠采购、Wind 不动产微观弱）不具备的。由此派生两条组织/模式层优势：
- **生态闭环优势**：自有数据＋生态数据（生活服务单量/GTV）＋政策库自爬，数据可得性与更新频率领先纯爬虫型机构；
- **商业模式飞轮优势**：政府免费入口换标准/共识/数据入口（§1.2）＋开源估值框架（中房协好房子标准/不动产 CAPM/NOI-DSCR）沉淀行业共识→标准话语权→数据回流→B 端三包年费——"免费换标准"只有平台型机构玩得起。
- 责任纪律（不抢签章）同时是合作润滑剂：不与评估机构/银行内部合规冲突。

## 四、展望与不确定性 + 合作前提条款清单（优势→条款逐条映射）

不确定性：垂类模型 token 节省/质量提升幅度未经灯塔实测（不承诺具体数字）；信心指数暂无基期、暂缓对外（缺对外口径锚）；银行千万级合同为需验证假设（不写进承诺）。

| 优势 | 合作前提条款 |
|---|---|
| 数据（自有+生态） | **数据授权边界**：可入合作环境的数据范围、可复用/可分发边界、衍生数据归属；合作方输入数据（押品/信贷台账）反向授权与保密；禁止用于合作外模型训练 |
| 深度（harness+垂类模型） | 部署形态（私有化/API）与 Token 计量、费用边界、缓存复用权益；微调层 IP 归属与底座模型许可合规 |
| 口径/标准 | **口径条款**：口径定义权与变更机制（40 城 vs 50 城、指数基期价格 2020-01/活跃 2024-01）；口径变更版本化、双方确认；对外发布前过舆情审核 |
| 审计/五链 | **责任边界**：做底稿不做签章，结论责任归客户决策者；证据链保留期限与可审计接口；不替客户决策、不隐藏不确定性 |
| 商业模式 | **免费投入上限**（建议 ≤ 总成本 20%，以"部委/协会采纳智见口径"为继续投入里程碑）；**付费测试条款**（试点意向书/10-100 万级验证，不做规模承诺） |
| 合规/私有化 | 数据不出域技术承诺；等保/信创/金融合规清单；脱敏责任划分；**退出机制**：终止时数据删除/归还、底稿与账号处置、白名单回收（领导直问 300 人） |
