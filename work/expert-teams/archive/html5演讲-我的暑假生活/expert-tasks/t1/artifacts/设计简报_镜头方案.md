## 1. 镜头对照表（幕 × 镜头效果 × 画面要点 × 时长）

| 幕 | 时长 | 镜头效果（卡名 · 出处） | 画面要点（t2 实现规格） |
|---|---|---|---|
| **1 封面** | 10s | `crane-rise-reveal`（opening/）— 升降臂拉升揭示，适配为「太阳升起揭示」 | 起点特写：标题《我的暑假生活》放大 3.2× 占满画幅，**hold ≥1s 让"一行标题"可读**；相机沿 Y 轴**减速升起**（共用一条 Easing.out(quad) 进度，先快后慢=升降臂手感），升起过程中太阳从海平线升出、云/海鸥/海浪逐层涌入画面（元素"涌入"用深色叠层脉冲 0→0.22→0 表达，白底上提亮不可感）；满幅后标题收正居中，副标「演讲者：莫弘毅 · 三年级」随后浮现；**收尾真静止 ≥1.5s（R1 品牌记忆点）**。逐层脉冲触发帧与运镜严格同步。 |
| **2 出发！去青岛海边** | 10s | `depth-layer-moves`（camera/）视差滑轨 3 层 ＋ `list-reveal`（ui-entrance/）文案逐条入场 | 三层视差：海浪（后层，系数 0.35 + blur2 + 降饱和 0.92 + opacity 0.85 退成环境）、沙滩+礁石（中层，系数 0.7，**主阅读层无 blur**）、前景浮块小螃蟹/贝壳（系数 1.4 + blur3 掠过镜头）；**同一条 drive 位移乘各层系数**，梯度 ≥2 倍层间才可辨，层数 ≤4。文案 4 行（暑假天气太热了／妈妈带我和三个表姐／一起去青岛的海边玩／捉螃蟹是我觉得最有趣的事）以纸签形式**逐条浮入**：stagger ≈0.8s/条（慢一档，"读得完"的间隔），scale 0.78→1 + outBack 软过冲扣住，位移 ≤14px。末行「捉螃蟹是我觉得最有趣的事」落定后**全场 hold ≥1s**（它是本幕的钩子）。 |
| **3 捉蟹装备大集合** | 8s | `spotlight-sweep-moves` A 式（effects/）扫光点名 ＋ `element-body-moves` A 落点回弹（ui-entrance/）＋ 收尾 `paper-title-card`（typography/）横幅 | 探照灯束**严格 linear 匀速**（命门：任何缓动都读作"光有意图"，匀速才像探照灯机械扫掠）从装备行一端扫到另一端；光束过处 5 件装备（探照灯／连体防水服／手套／小水桶／大钳子）**依次弹跳立正**：横冲飞入带轴向拉伸（速度差分驱动 scaleX 2.2/scaleY 0.72）+ 落点 8f 压扁回弹（scaleX 过冲 0.85、scaleY 1.1 再回 1）。装备排成弧形陈列在沙滩上，亮场里光束用"高光罩 + 贴边光晕"表达（光到即亮）。末拍「全副武装，向礁石群出发！」**逐词压印**（scale 1.28→1 + blur7→0，letterpress 配方），**hold ≥1s**。扫光与弹起是同一因果链（光到→弹起），只算一个镜头动效。 |
| **4 我的捉蟹妙招** | 15s | 主镜头：步骤卡逐张入场（`list-reveal` 找位语法）＋ 箭头连线 `draw-svg-trace`（ui-entrance/）笔头描线 → 落定后 `line-boil`（effects/）沸腾呼吸；底运动：相机慢速单向推近（zoom 1→1.35，全幕贯穿） | 4 张步骤卡（①碰运气—一开始什么也没抓到 ②守株待兔—坐在礁石上等海水退潮 ③搬石头—石头缝里有水就立刻搬开 ④照水面—探照灯下有波纹就马上夹住）沿斜线排布（阅读顺序 左上→右下）；每张卡入场 scale 0.78→1 + outBack 软过冲（stagger ≈1.5s/步）；卡与卡之间**手绘箭头用笔头描线**（pathLength=1 + dashoffset 1→0，40f inOut-cubic；笔头叠一层 4→7px 短 dash 天然跑在最前——没有笔头就只是"边框在变长"）；箭头闭合后进入 **line-boil**（feTurbulence baseFrequency 0.015 + feDisplacementMap scale=8，**seed=floor(f/3) 每 3 帧重描**，10fps 手翻书质感；**全片仅此一组沸腾元素**，沸腾段之外 filter 条件卸载不渲染）；末卡「照水面」落定 **hold ≥1.5s**。相机推近是底运动（像 list-reveal 的容器漂移：慢、单向、不抢戏），主角是"卡片递进+箭头连线"。 |
| **5 收获满满！** | 12s | `crash-zoom-punch`（camera/）撞停急推点名 ＋ `counter-confetti`（data/）计数冲线+纸屑抢拍 ＋ 螃蟹堆（`card-stack` 堆叠节奏：stagger 越来越快 + 收尾 0.5s 停）＋ 金句 `paper-title-card` ＋ `marker-underline-title`（typography/） | 全景建立「收获满满」hold ≥1s → 数字「约100只」**6f 急推**（zoom 1→2.6，ease-in；**撞停款**：到位帧起机位高频抖+指数衰减 amp14px τ1.8f，不回弹——"就是它"的重量感；全片仅此一次急推）→ 数字从 0 **冲刺计数**（easeOutQuart，前 1/3 时间跑完 2/3 数值；scale 1.3 冲入 → outBack 回落收正）→ **纸屑抢拍**：彩纸在计数到位**前 0.04（约 5 帧）**从两侧抛物线炸入（52 片、重力≈2.5×初速、自转 ±750°——庆祝比结果先到半拍，这是灵魂参数）；随后「1～2小时」「超开心」两枚数字签快速亮相（stagger 快拍 0.3s/枚）；小螃蟹们从两侧**跳入堆成小山**（stagger 节拍**越来越快** + 物理隐喻 + 落定 **0.5s 静止**，R2）；金句横幅「捉螃蟹真是一件令人开心的事情！」压印 + 「开心」关键词**马克笔划线**（8–12f 一笔呵成、贴字底 -0.1em、中段最宽、边缘毛糙；标题落定后 +4~8f 再起笔）；**hold ≥1s**。 |
| **6 谢谢大家！** | 5s | `gradient-transition`（transition/）渐变日落收束（linear→radial 两段）＋ `paper-title-card` 大字浮现（简化：不压印） | 背景从夏日天蓝**渐变**到橙粉再沉入深 navy（HSL 三通道插值防发灰，窄交叉淡化 0.08；radial 段：太阳光斑沿对角线下沉 + 半径扩张，暗色外圈=日落氛围）；太阳（真圆）沉入海平线；「谢谢大家！」大字居中浮现（简单淡入+轻微 scale，保持谢幕低能量，不与幕 3/5 的压印重复）；**收尾真静止 ≥1.5s（全片最后一帧记忆点，R1）**。备选：若队长想要 match-cut 彩蛋，可换 `circle-match-iris` 虹膜收场（光圈以太阳为真圆锚点收缩闭合，太阳变成句号）——默认不用，怕 5s 内两件事太挤。 |

**幕间衔接**：幕与幕之间用短渐变/淡出（0.3–0.5s）硬切即可，不做花式转场——每幕已有一个主角动效，转场再花就超载（P4）。

## 2. 设计 tokens（t2 唯一色值/字体/插画规范）

### 2.1 调色板（沿用已确认 PPT 版夏日海边配色 · tinted neutrals，无纯白/纯黑）

| token | 值 | 用途 |
|---|---|---|
| `--sea` 海蓝 | `#14729E` | 主色：标题、按钮、海浪描边、数字强调 |
| `--sun` 阳光黄 | `#F7B733` | 强调色：太阳、星星、高光、"开心"划线 |
| `--coral` 珊瑚 | `#E86A5E` | 次强调：金句、螃蟹壳、惊叹号 |
| `--mint` 薄荷 | `#4FB3A6` | 装备卡、妙招步骤卡、辅助图形 |
| `--sky` 天蓝 | `#8AC6E8` | 辅助：云、海浪浅层、渐变过渡 |
| `--navy` 深文字 | `#17324D` | **所有正文/标题文字**（对比度 ≥10:1 @ #F0F7FA） |
| `--bg` 浅天蓝背景 | `#F0F7FA` | 全局底色、舞台天空 |
| 补充 tinted 层 | 卡片底 `#FBFCF7`（近白米，非纯白）；描边 `rgba(23,50,77,.12)` 发丝线；阴影 `rgba(23,50,77,.16)` 染色阴影（禁纯黑阴影）；白字仅用于海蓝/深色块上（大字 ≥48px 才用，保对比） |

### 2.2 字体（微软雅黑 / PingFang SC · 圆润可爱 · 大而清晰）

| 层级 | 规格（1920×1080 设计基准） | 说明 |
|---|---|---|
| 封面大标题 | 120px / 900 | 每幕主角字，圆角处理（font-weight 900 + 适当 letter-spacing） |
| 数字（100只 等） | 180px / 900 | 计数主角，最大字号 |
| 幕标题（eyebrow） | 32px / 600 | 半透明 navy，如"妙招 · 第 1 步" |
| 正文 | 40px / 700 | **≥3% 帧高（Q11 辅助文字线）**，三年级孩子与评委远读 |
| 关键句/横幅 | 56px / 900 | **≥5% 帧高（Q11 字幕线）**，如"全副武装"“捉螃蟹真是一件令人开心的事情！” |
| font-family | `"PingFang SC","Microsoft YaHei",system-ui,sans-serif` | 无衬线、无外链字体（单文件约束） |

### 2.3 插画风格（纯内联 SVG 手绘风）

- **线型**：粗圆描边（stroke-width 6–8@1920）、`stroke-linecap:round`、`stroke-linejoin:round`；描边色统一深 navy 或海蓝深调，填充取调色板 6 色。
- **造型**：简笔几何（螃蟹=圆壳+八条腿+大钳；海浪=三层波浪线；太阳=圆+放射短线；云=三圆连体；海鸥=两道弧），不追求写实。
- **每幕插画清单**：幕1 太阳/云/海鸥/海浪；幕2 三层海浪/沙滩/礁石/小螃蟹/贝壳；幕3 五件装备图标（探照灯/连体防水服/手套/小水桶/大钳子）+ 光束；幕4 礁石/水波纹/探照灯/小螃蟹/箭头；幕5 螃蟹堆/小水桶/彩纸屑；幕6 日落太阳。
- **禁令**：无外链图片、无位图、无 emoji、无渐变贴图冒充插画；SVG 全部内联于单文件。

### 2.4 动效与节奏 tokens（约束 t2）

- **总时长 ≈60s**，单文件 HTML；GSAP 主时间线分幕驱动（scene 标签 + 幕内子时间线），自动播放 + 点击/键盘跳幕；禁 Math.random（确定性渲染，伪随机一律固定种子/帧号派生）。
- **每幕一个主角动效**（见对照表），其余动效只能是"底运动"（慢、单向、不抢戏）或"寄生层"（hold 段呼吸）。
- **hold 预算**：每幕关键信息落定 **hold ≥1s**（R1）；批量入场收尾 **0.5s 静止**（R2）；开场动作弧给足 3s（R3）。
- **缓动表**：相机升起 out-quad（升降臂）｜弹跳落位 outBack/spring(0.3)｜计数 easeOutQuart｜扫光 strict linear｜箭头描线 inOut-cubic｜纸屑抛物=闭式弹道。
- **手法去重（P4）**：急推×1（幕5）、视差×1（幕2）、扫光×1（幕3）、line-boil×1（幕4）、彩纸×1（幕5）；压印字卡出现在幕3/幕5 属"呼吸位"配角，幕6 谢幕改用简单淡入以示区别。
- **prefers-reduced-motion**：全部动效静止为各幕终态构图（即"静止版"）。
- **画幅**：16:9（1920×1080 设计基准），等比缩放居中（letterbox 防变形），全屏舞台无滚动。
