# 《关于改革完善房地产信贷管理 推动加快构建房地产发展新模式的意见》点评（正式稿）

**导语**：2026年8月28日，中国人民银行、国家金融监督管理总局联合印发《关于改革完善房地产信贷管理 推动加快构建房地产发展新模式的意见》（七章36条）。本文将其定位为房地产金融的"制度重构"而非又一轮需求刺激——主线是"信贷跟着交付走、资金全程封闭管"。就全国数据看，政策底已现、市场底未到：短期销售与投资仍将承压，文件成效取决于开发贷接续与执行刚性。

## 一、文件定位与核心条款速览

**定位**：这是房地产金融从周期性调控转向制度性重构的标志性文件。它以"能拿房、再还贷"的交付逻辑嵌入信贷制度，把房地产信贷从依附预售制的销售回款驱动模式，切换为竣工交付驱动的全项目周期管理模式；是新发展模式住房、土地、财税、金融四类制度变革中，金融制度率先系统落地的部分，取向是"先立制度、再稳市场"。

**六条核心条款（以《意见》原文为准）：**

1. **开发贷款主办银行制度**：单个项目对应一家主办银行单独或牵头银团放贷；贷款期限覆盖开工至竣工备案，预售项目最长5年、现房销售项目最长7年、商业地产最长7年；首次还本原则上在竣工备案后。
2. **按揭与开发贷衔接**：个人住房贷款受托支付，现房销售付至项目公司在主办银行账户，预售付至预售资金监管账户。
3. **按揭期限延长**：个人住房贷款期限由最长30年延长至40年，由借贷双方协商。
4. **销售阶段延后放款时点**：现房销售备案后发放；预售严格在竣工备案后发放——"能拿房、再还贷"。
5. **开发建设阶段资金封闭管理**：预售资金监管账户与定金账户须在主办银行开立，项目全部相关资金纳入主办银行账户管理；对外负债、投资等重大事项事先告知主办银行。
6. **新设"房地产金融宏观审慎管理"章节**：首付比例、利率、房地产贷款集中度等工具，纳入央行会同相关部门建立的逆周期调节机制，房地产金融调控由行政性、运动式走向制度化、可预期。

## 二、共识与分歧

**共识（五项研判一致）：**

1. **制度重构定性**：文件不是需求刺激，而是把"保交楼"的事后应急转为事前制度，用金融纪律约束高周转预售模式、倒逼现房/准现房销售，符合现房销售渐进论方向。
2. **风险由居民部门转移至银行体系**：延后放款时点与资金封闭管理，实质是把期房信用风险从购房者一侧整体转移至银行体系（主办银行承担项目全周期信用管理），制度消除了"付了钱拿不到房"的信用坍塌点。
3. **预售回款节奏冲击**：预售阶段开发商现金回流锐减，需要开发贷期限与还本安排同步延长形成对冲——文件内部设计是配套的，执行中的时序错配才是真正的风险点。
4. **短期不改磨底格局**：量价双弱、利率工具钝化的背景下，文件不改变"止跌回稳尚需时间"的基本判断，政策底≠市场底。

**分歧与边界条件（降级处理，不作并列观点）：**

1. **40年按揭实效争议**：一方强调其压低月供门槛、拉长居民资产负债表修复时间（按等额本息、3.06%测算，100万元贷款月供由30年期约4247元降至40年期约3614元，降幅约15%）；另一面是按等额本息、3.06%测算总利息增加约四成、债务周期穿透至退休年龄——解决的是还贷能力而非购房能力，对中低收入群体边际受益有限。此争议不影响文件定性，仅提示按揭工具的实际拉动存在上限。
2. **执行次序"一步到位 vs 渐进"**：放款时点后移若先于开发贷供给到位，对预售依赖度高的房企是"先断粮、后补粮"，短期供给收缩（开发投资累计同比-19.2%）可能进一步下探。此为执行节奏风险，需以主办银行开发贷投放节奏跟踪验证。
3. **公积金期限错配**：多数城市公积金贷款期限上限仍为30年，与40年商贷组合将出现期限错配，组合贷产品如何匹配、公积金政策性金融功能如何跟进，是待答的制度衔接问题。

**五组数据的共同指向**：价格工具已用到极限（利率低位走平）、信贷资产持续收缩（余额连续净减少）、量价双弱且价格跌幅二次走阔——这正是文件放弃单纯降息降首付、转向期限、时点、结构三类结构性工具的现实背景。居民去杠杆、房企去产能、市场去库存"三去"叠加，政策着力点已非刺激放量，而是为周期筑底后的新模式运行铺设制度轨道。

**城市分化**（研判推断，结构性定性判断）：城市级量化数据暂缺，以下为基于政策机制与全国数据的结构判断。其一，主办银行制与延后放款对现房占比高、项目资金闭环成熟的核心城市（北京、上海等）冲击银行投放节奏最强——这些城市按揭与开发贷集中度高，放款时点后移对主办银行资金安排与投放节奏的影响最先显现；其二，40年按揭对高总价城市月供摊薄效应最显著——总价越高、期限延长的月供边际改善越明显，对改善型需求集中的高总价市场拉动相对更大；其三，三四线城市受回款后移冲击更大——其对预售回款依赖度高、开发贷承接能力弱，放款后移至竣工备案将放大其现金流压力，城市间执行节奏与银行投放意愿将出现分化。上述判断待城市级数据补充后验证。

## 四、影响展望与观察指标

**展望（研判推断）：**

1. **余额**：若执行刚性到位、开发贷配套供给充足、存量房贷利率跟进下调（新发放3.06%与存量利差仍在，提前还贷压力下余额净减少态势有望在2026Q4前后触底企稳），个人住房贷款余额有望在2027年上半年止住净减少。
2. **销售与投资节奏**：销售端2026下半年有望筑底；投资端受放款时点后移的短期冲击，见底时点或滞后销售2-3个季度。
3. **周期拐点**：参考国际经验（美国2006-2012、香港1997-2003），本轮自2021H2起算的调整进入第6年即2027年具备周期拐点条件，前提是制度底座、收库存、贴按揭三招齐备——若存量利率下调50bp，按36.29万亿元余额测算年减负约1814亿元（测算口径），可配合40年期限共同压低月供负担。
4. **结构演进**：现房销售占比将随"竣工备案后放款"逐步提升，预售制度渐进退出；银企关系从"多行放贷"转为"主办银行全程管理"，低杠杆央国企与现房项目受益，高杠杆主体加速出清。

**可验证观察指标（汇总）：**

- 新发放按揭中40年期占比（最早验证信号之一）
- 竣工备案后放款执行率
- 个人住房贷款余额月度净变动（降幅收窄时点）
- 70城价格同比收窄幅度（-1%以内可作企稳观察锚）
- 主办银行制项目覆盖率与开发贷余额同比（检验"先断粮、后补粮"风险）
- 现房销售项目占比、预售资金监管账户划转节奏
