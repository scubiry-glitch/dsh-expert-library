# 领导提问 FAQ 章节（供行领导汇报直接使用）

> 编制：琉（战略咨询）主持，综合 t7 问题清单与 t8-t12 五位专家应答（W=零售信贷操盘手、一=零售金融分析、袁=战略政银、高=经营中收、梁=数智合规）。
> 排序逻辑：按行领导最可能先问的顺序——先问大局（为什么），再问钱（值不值），再问风险决策（怎么办），再问执行（怎么成），最后尖锐追问。
> 数字纪律：全部口径带来源；未核实参数标「假设（需XX核实）」；禁止编造数字。
> 渲染建议：本章节可直接作为汇报材料「行领导可能提问及应答要点」附页；每条 Q 后为应答话术要点，P0 为必答问题。

## 一、大局之问

### Q1【P0】为什么是我们做？——凭什么由江苏银行承接，而不是五大行、互联网平台？

- **提问意图**：试探不可替代性认知，防资源错配与政银关系透支；领导担心"领导安排就做"的被动承接。
- **推荐主答视角**：袁（战略政银）主答，W（操盘手）补落地证据。
- **综合应答要点**：
  1. 先例三件套（证据高，5·21纪要）：首批接入人社一体化平台、年代发社保超730万笔/超250亿元、省级社保基金专户第一中标——政务信任是多年真金白银积累，不是承建商投标能买来的。
  2. 商务厅80%咨询先例（证据高，董事长5·21讲述）：未参与资金招投标，主动开放客服中心承接政策咨询——"我们不仅是金融机构，更是省委省政府的部门"，主动服务建立排他习惯。
  3. 不可替代点=金融闭环（证据高）：持牌收单+按课时分批结算（防预收费跑路、服务政府监管，已确认事实5）+政务数据可信载体；第三方有技术无持牌收单与监管分账资质，五大行有人社资源无"主动服务"样板+13家分行地推网络（已确认事实6）。
  4. 一句话（袁）："第三方做的是页面，我们做的是信任和闭环——页面可以外包，信任不能外包。"
- **答不好会怎样**：被"交给第三方做"一句话否决，政务卡位机会整体流失。

### Q2【P0】为什么是现在做？——人社厅重点那么多，为什么培训供需平台是优先项？

- **提问意图**：检验战略节奏感：抢窗口还是跟风AI热点；领导在判断立项时点与资源投入次序。
- **推荐主答视角**：袁（战略）主答，高（时度效）协作。
- **综合应答要点**：
  1. 窗口已开、机制已备（证据高）：2027寒假培训以返乡大学生为主客群，"政府统筹+院校组织+机构授课+银行支撑"四方协同已成型；首批16门AI公益课已备（已确认事实1）——平台是四方协同的收口载体，现在做是"承接既有安排"，不是"新开一摊"。
  2. 三低时代卡位稀缺（证据中）：低利率/低息差/低增长下，政务场景是低频高信任入口，先进入者建立习惯壁垒。
  3. 晚一年的不可逆成本（证据中）：①人社厅可能自建/他行承接，结算与数据卡位整体丧失；②寒假档期一年一轮，错过=首个真实报名数据点（16门公益课转化）再等一年；③"现在做是顺水推舟，晚一年做是重新敲门"（袁）。
  4. 时度效（证据中，高）：106人天（已确认事实7）在窗口期内属低成本卡位，时间成本远大于开发成本。
- **答不好会怎样**：被定性"跟风AI"，项目压后立项，错过2027寒假窗口。

### Q3【P0】为什么不直接捐建/只做收单？——直接账才几十万-200万，捐个平台不是更省事？

- **提问意图**：最狠的经济理性拷问——测试三本账逻辑完整性：是否想透了"结算闭环+数据卡位"，还是把政务项目当慈善/当生意。
- **推荐主答视角**：高（经营中收）主答，梁（结算闭环价值排序）协作。
- **综合应答要点**：
  1. 捐建是一次性人情，承接是持续关系载体（证据高，高）：赞助省下106人天，但丢掉三样东西——①收单+按课时分账的合规闭环（服务政府监管的不可替代职能，已确认事实5）；②平台沉淀的数据与场景入口（后续补贴发放/就业创业贷卡位）；③"省委省政府部门"的持续服务者身份。
  2. "只做收单"的前提是平台被别人建（证据中，高）：收单合作就变成别人的施舍、随时可替换；只有平台与结算闭环都在我们手上，收单才是护城河的一部分。
  3. 财务对比（证据中，假设需计财部核实）：106人天≈0.5人年≈25万-40万元（人力综合成本假设50万-80万/人年）；赞助建平台同样花该量级费用，但一分钱沉淀与关系资产都留不下——同样花钱，承接模式把"花钱"变成"卡位"。
- **答不好会怎样**：项目被降级为纯公益捐赠，结算与数据卡位拱手让人。

## 二、经济账之问

### Q4【P0】直接账覆盖不了106人天，这笔账你怎么跟我算？（"106人天值不值"）

- **提问意图**：测试诚实度与算账逻辑——领导不怕账小，怕拿大话糊弄；看我们敢不敢承认直接账不成立并给出完整逻辑链。
- **推荐主答视角**：一（零售分析·口径纪律）主答，袁（战略账）协作。
- **综合应答要点**：
  1. 口径锁死（证据高，一）：直接账只算"行内闭环市场化流水"（补贴课程报名走人社厅一体化平台、行内仅前端展示引流，已确认事实3），补贴流水一律不计入；口径定义=（行内闭环市场化支付流水×收单净价差）+（监管/分账资金日均沉淀×沉淀利率）。
  2. 诚实呈现三段式（证据高，一）：承认中性口径50万-200万/年（构成假设：首年行内闭环市场化流水3-10亿×综合收益率0.1%-0.2%，需人社厅/网金部核实）确实覆盖不了106人天（≈0.5人年，全口径成本金额假设25万-64万，两专家区间口径不同，需计财部核实）；但106人天是一次性建设成本，直接账是每年持续性收入且随流水线性放大，第二年起即净增量。
  3. 三本账分账呈现、严禁加总混用（五方共识，证据高）：直接账=小账（证明平台不是空壳）；间接账=中账（机构对公开户假设首年200-500家、学员留资转化假设5%-20万人×开户转化率5%-15%，首年综合收益约25-800万/年，假设需分行/零售条线核实）；战略账=大账（政务卡位+场景入口，5·21纪要证据高）。
  4. 一句话（一）："直接账是入场券，间接账是门票收入，战略账是长期会员资格。"
- **答不好会怎样**：虚报数字失去信任（编数字比不回答更严重），或被"不赚钱就不做"一票否决。

### Q5【P0】三本账的参数全是假设，拍脑袋的数字凭什么让我信？

- **提问意图**：检验测算严谨性与"假设→核实"闭环管理；领导在为KPI公信力定调。
- **推荐主答视角**：一（敏感性分析）主答，高（参数核实责任清单）协作。
- **综合应答要点**：
  1. 诚实开场（证据中，一）："参数确实没有一个是今天核实过的。所以我不请您按假设批项目，我请您按'假设+核实责任表+敏感性矩阵'批项目。"
  2. 参数分级管理（证据高，一）：已确认（106人天、5类目上限占4、13分行、16门公益课、按课时分批结算——底稿事实）/可核实（费率=网金部、沉淀周期=网金部、全省盘子与行内闭环占比=人社厅/网金部、人力成本=计财部、微信审核周期=网金部）/纯假设（转化率、入驻机构数、客单价——不写入正式汇报正文）。
  3. 敏感性矩阵（证据中，一+高协作）：直接账年化——行内闭环流水1亿/3亿/10亿 × 综合收益率0.1%/0.2% → 约10-20/20-40万、30-60/60-120万、100-150/200-300万（沉淀收益占小头；参数需网金部/计财部核实）。读法："做不做"的结论对参数不敏感（任何档位直接账都是小账），只有"收益多少"对参数敏感——决策依据放间接账+战略账。
  4. 核实闭环机制（证据中）：未核实参数不写入正式汇报正文，凡引用必带「假设（需XX核实）」；汇报附件附《参数核实责任表》（参数|假设值|责任部门|核实时限：费率/沉淀=网金部T0+2周、全省盘子=人社厅T0+4周、人力成本=计财部T0+2周）；首个真实数据点=16门AI公益课T+3月真实漏斗数据替换转化率假设。
- **答不好会怎样**：整个测算被贴"拍脑袋"标签，后续KPI失去公信力。

### Q6【P1】106人天之外，运营、客服、审核、地推的长期人力谁出？总投入到底多少？

- **提问意图**：测试全成本意识，防"建设成本低、运营成本无限"的钓鱼工程。
- **推荐主答视角**：高（全口径成本）主答，W（分行地推口径）协作。
- **综合应答要点**：
  1. 两段式口径（证据中，高）：106人天是一次性开发（≈0.5人年≈25万-40万元，人力综合成本假设50万-80万/人年，需计财部核实；W口径为25万-64万、人天3000-6000元——两档假设需计财部统一）；首年运营按"2-3个兼职编制量级+成本封顶"列支，归属网金部+个贷部。
  2. 运营构成（证据中，假设需网金部/个贷部核实编制）：机构准入审核（网金部，100-300家量级约0.5-1人）；客服承接（复用商务厅模式开放客服中心、边际成本低、不新增编制，证据高）；课程内容巡检（科技部/网金部）；13家分行地推（成本列支行费用、考核挂钩但列支清晰，W）。
  3. 成本封顶（证据中，假设需计财部核实）：首年运营投入封顶30万-50万元，T+6月复盘按KPI决定是否追加——堵死"钓鱼工程"质疑。
  4. 机会成本对比（证据中，高+W）：0.5人年是行内中大型项目投入的零头；外部渠道单客获客成本假设数百元（需个贷部核实），1万-4万条留资名单对应机会成本数百万元量级——106人天是最便宜的获客基建。
- **答不好会怎样**：T+6月复盘被"隐性投入"打脸，项目背上"预算失控"标签。

## 三、风险决策之问

### Q7【P0】类目被拒或被巡检下架，什么时候发生、触发什么？B计划时间表在哪？

- **提问意图**：测试是否把不确定性变成可管理决策（底稿"两个选项均存在不确定性"是最大失分项——领导要决策建议，不是问题转交）。
- **推荐主答视角**：高（硬触发+时间表）主答，梁（载体可切换架构）协作。
- **综合应答要点**：
  1. 三节点时间表（证据中，高，假设需网金部核实审核周期2-4周）：T0提交"综合生活服务"类目申报+同步微信官方预沟通+准备人社厅共建协议/情况说明/机构备案佐证→T0+2周预沟通结论确认→T0+30天未过审触发B计划论证。
  2. 硬触发条件三选一（证据高，高）：①正式驳回；②超期无结果（T0+30天）；③上线后收到巡检风险提示（启动内容合规整改+载体切换预案）。
  3. B计划时间表（证据中，假设需网金部/科技部核实）：T0-T0+2周并行预研人社厅主体与收单服务商模式；T0+30天触发后T0+45天确定主体方案；T0+60天完成迁移（前端切换，业务逻辑沉淀中后台）；切换成本预估为新建的20%-30%。
  4. 架构兜底（证据高，梁）：业务逻辑（准入/审核/报名/分账）全部沉淀中后台与持牌收单体系，小程序仅为前端触达层，前端按序可切：微信小程序→公众号H5→人社厅主体小程序——任一载体被拒/下架，业务与结算不中断，仅切换入口。
- **答不好会怎样**：被评"只会列困难"，项目卡在审批，类目窗口错过。

### Q8【P0】"主体在他、结算在我"——合规上站得住吗？微信允许吗？问过没有？

- **提问意图**：专门测试B计划可行性论证是否扎实，还是想当然；领导不会给"可能可行"的方案背书。
- **推荐主答视角**：梁（支付服务商模式）主答，高（收单侧可行性）协作。
- **综合应答要点**：
  1. 模式界定（证据中，梁）：以"支付服务商+技术服务方"身份嵌入人社厅主体小程序（人社厅事业单位主体天然具备政务民生类目资质，底稿路径二口径），而非挂靠类目规避审核——**挂靠是红线，如实申报是正道**（证据高）。
  2. 与"二清"的本质区别（证据中，梁）：收单主体是我行、清算走持牌通道，资金不经非持牌机构沉淀——我行持有收单资质。
  3. 待核实清单（假设，需网金部/微信官方核实）：微信开放平台对政务类主体小程序内嵌银行收单的规则适配性；收单服务商资质与签约主体要求；微信支付服务商模式下政务主体的进件规则。
  4. 时间预留（证据高，梁+高）：B计划论证结论须在T0+30天前给出（与C1触发机制联动），不能到触发时才去问。
  5. 为什么路径二只能作B计划（证据高，梁）：底稿明确路径二会丧失我行承接培训机构费用结算服务的机会——**结算闭环是全项目唯一不可替代的价值点**（价值排序：结算闭环＞政务关系＞获客场景＞页面开发），作B计划既保留合规退路、又不提前交出价值锚。
- **答不好会怎样**：B计划被当场证伪，路径二堵死，只剩"二选一"死局。

### Q9【P0】平台沉淀的数据，权属是谁的？能做什么、不能做什么？出事谁担责？

- **提问意图**：数据合规是潜在否决项（五方共识）；领导在测试法务意识与红线意识，为可能的舆情事故预先划责。
- **推荐主答视角**：梁（数据合规要件）主答，一（客群分析边界）协作，袁（价值与姿态）补充。
- **综合应答要点**：
  1. 权属框架（证据高，梁）：数据归人社厅与学员个人（政务数据+个人信息双重属性），我行仅按共建协议受托运营——写入共建协议（需法务部核实条款）。
  2. 用途三红线（证据高，梁）：①最小化收集——仅收集平台功能必需字段；②用途限定——仅用于平台运营与授权范围服务，客群分析/留资转化须在授权范围内（一协作：注册/报名协议明示用途、营销触达单独授权+退订通道、禁止默认勾选）；③智能体训练不得使用未脱敏政务数据（供需匹配智能体共建必须建立在脱敏、匿名化之上）。
  3. 责任机制（证据中，需法务部/科技部核实）：数据安全责任写入共建协议（通报/处置/赔偿划分）；平台按等保三级要求建设（假设）；建立数据安全事件应急预案；对接一体化平台人员数据库须签政务数据共享协议（最小必要、用途限定、脱敏规则、留存期限）。
  4. 姿态（证据中，袁）：向领导表述为"用数据服务政务、反哺金融"，绝不表述为"用数据做营销"——**姿态错了，整个战略账都会被否决**。
- **答不好会怎样**：被"数据合规风险"一票否决，或含糊答过给后续埋雷。

### Q10【P1】宣传上能不能承诺"培训后就业增收"？资金上有没有"二清"嫌疑？

- **提问意图**：测试合规底线成熟度；领导宁可项目慢，不愿被监管点名。
- **推荐主答视角**：梁（红线清单）主答。
- **综合应答要点**：
  1. 宣传红线（证据中，梁）：8·17沟通会纪要——人社厅李处明确宣传须经实际调研、合规合法方可表述，"考证后收入提升"须有调研数据支撑，不能代表政府乱宣传；对外物料经合规条线审核、统一话术模板、不做就业/收入承诺。
  2. 资金红线（证据高，梁）：学费按课时进度分批向机构结算、防"预收费跑路"、服务政府监管（已确认事实5）；纳入监管课程按比例分配（8·17口径：一门课售价50%由运营方分配）、市场化课程机构自主定价（已确认事实3）；资金清算必须走我行持牌收单通道，杜绝平台自建资金池的"二清"结构；分账规则落地前由网金部、合规条线确认支付牌照业务边界（假设，需网金部核实）。
  3. 表态收尾（证据高）："类目可以谈，合规底线不能破"——宣传与资金两条线任何一条出问题都是监管点名级事件，声誉风险反噬主业。
- **答不好会怎样**：上线后被监管/微信点名，声誉风险反噬主业，项目被叫停。

## 四、执行成功之问

### Q11【P0】机构凭什么入驻？群众凭什么用？冷启动答案在哪？

- **提问意图**：检验落地思维，防"建好没人用"的政务项目空壳化。
- **推荐主答视角**：W（机构侧四抓手）主答，一（群众侧入口与验证）协作。
- **综合应答要点**：
  1. 机构侧"三件套"（证据高，W）：政府背书（人社厅联合发文=必须锁定的外部前置条件，五方共识）+行内利益（免费入驻假设需计财部核实+结算便利）+考核驱动的面对面服务（13家分行邀约入条线考核、月度通报，已确认事实6）；首批16门AI公益课先行示范（已确认事实1），让机构看到真实流量再决定深度合作。
  2. 群众侧"三个入口"（证据高，W）：政务渠道引流（补贴课程报名走人社厅一体化平台、行内仅前端展示引流，已确认事实3）+公益课引爆（16门免费课，四方协同）+地图就近（培训地图模块）。
  3. 操作承诺（证据中，W）：发文后7天内分行回传首批邀约名单，月度通报第一行就是各分行邀约数——"别给我看PPT，给我看分行的执行进度"；先打样2-3家分行，跑通"机构入驻-开课-报名-结算"全流程再全省复制。
  4. 验证点（证据中，一）：16门公益课报名转化率=冷启动假设的第一个真实数据点，上线即埋点跟踪"浏览→报名→留资→开户/绑卡"漏斗，T+3月出具首份真实转化率报告（假设时间表，需个贷部核实）。
- **答不好会怎样**：被质疑"为上线而上线"，立项价值归零。

### Q12【P0】成功标准是什么？KPI谁背？达不到怎么办？止损机制在哪？

- **提问意图**：测试责任到人与止损意识，防止"人人有份、无人负责"的烂尾项目。
- **推荐主答视角**：高（一标+止损）主答，W（分行考核机制）协作，袁（防层层加码）补充。
- **综合应答要点**：
  1. KPI五项+责任到部门（证据中，高，目标值假设需核实）：①上线时点T+3月试运行（假设需科技部确认排期）——科技部；②机构入驻90天≥100家——网金部+13家分行（邀约入考核、月度通报，W）；③课程上架90天≥300门——网金部；④报名人次90天≥1万人次（16门公益课引爆）——个贷部牵头+分行；⑤收单渗透率：市场化课程线上缴费占比≥50%（假设需网金部核实口径）——网金部。
  2. 考核分三层（证据中，袁+W）：部门背结果（个贷部牵头统筹）、条线背职能（网金/科技）、分行背过程（邀约机构数/入驻数/开课数——月度通报、季度排名、年度挂钩绩效）；**分行只背邀约与开户、不背流水指标**，防注水。
  3. 止损三档（证据中，高）：T+6月复盘——达标率≥70%→扩大试点继续投入；40%-70%→换打法不换项目（局部调整）；<40%→触发收缩止损评估（砍功能保结算、转人社厅主体、或退出），复盘结论报行领导。防层层加码（袁）：不得把"双提升"曲解为"双第一"，考核考执行质量不考数字注水。
- **答不好会怎样**：项目变成无主烂尾项目，T+6月复盘无法收场。

### Q13【P0】补贴课走一体化平台，我们平台值多少钱？与苏银生活/云课堂/五走进什么关系？重复建设？

- **提问意图**：测试平台生态位认知与衔接设计——底稿被追问最易露馅的一问。
- **推荐主答视角**：梁（四平台分工）主答，一（行内平台价值定位）协作。
- **综合应答要点**：
  1. 生态位一句话（证据高，梁+一）：行内平台=市场化课程的前端展示/引流/报名体验+结算闭环；补贴课程由一体化平台承接、行内仅前端展示引流（已确认事实3）——"不是重复建设，是苏银生活生态位自然延伸"。
  2. 四平台分工（证据高，梁）：人社一体化平台=补贴课程报名/审核/补贴发放的政务权威通道（凡补必进，8·17纪要），行内不做、不抢、不重复；人社云课堂=在线课程内容供给（3000多门课，8·17纪要），行内不重建在线学习体系；AI培训五走进=线下活动入口与获客场景；苏银生活=载体底座（月活800余万、承接十余地市政务活动），两步建设：培训地图→培训超市（已确认事实2）。
  3. 不重复建设三条硬证据（证据高，梁）：①人社厅现平台3000多门课但课程老旧、AI新兴课程偏少、仅展示机构名称无课表与联系人、活跃量级远低于苏银生活（8·17纪要李处口径）——供给展示存在真实缺口；②行内核心增量是市场化课程撮合交易+结算闭环，现平台与一体化平台均未覆盖；③以"跳转+引流+接口对接"替代重建（未来对接一体化平台接口实现数据同步，需技术沟通与厅内审批）。
  4. 防质疑机制（证据中，梁）：方案附"四平台边界图"（一体化/云课堂/五走进/苏银生活）作为汇报附件，正面回应"重复建设"。
- **答不好会怎样**：被指出"我们只是做了个展示页"、106人天价值被否认，或背上重复建设嫌疑。

## 五、尖锐追问

### Q14【P1】类目只剩1个名额，为什么当初没有提前预留？教训怎么避免再犯？

- **提问意图**：测试复盘意识与流程缺陷；领导可能翻旧账，考察团队是否敢于承认前期评估粗糙。
- **推荐主答视角**：高（机制补丁）主答，梁（载体解耦）协作。
- **综合应答要点**：
  1. 承认口径（证据高，高）："类目评估滞后于项目立项，是前期流程缺陷"——诚实是加分项，狡辩是失分项。事实：小程序已占用4个类目（银行、办公、信用卡、电子汇票）、仅剩1个名额（底稿口径）。
  2. 机制补丁（证据中，假设需网金部确认流程挂靠节点）：新项目立项评审增加"微信平台规则预检"环节（类目占用/资质要求/审核周期三查），由网金部出具书面意见。
  3. 系统级解法（证据高，梁）：载体可切换架构——业务逻辑与前端载体解耦，类目/下架/政策变化从项目级风险降为执行级问题。
  4. 教训沉淀（证据中，高）：本次教训写入项目复盘报告，列为后续政企合作项目立项检查清单第一条。
- **答不好会怎样**：暴露前期调研粗糙，连带质疑整个项目调研质量。

### Q15【P1】人社厅同时找别的行/平台合作怎么办？排他性多强？

- **提问意图**：测试竞争格局认知与卡位深度；领导要确认投入不是为他人做嫁衣。
- **推荐主答视角**：袁（先发信任+切换成本）主答，W（三道锁）协作。
- **综合应答要点**：
  1. 排他性不是写出来的，是经营出来的（证据高，袁）：先发事实（首批接入/730万笔250亿/专户第一中标，5·21纪要）+主动服务样板（商务厅80%咨询先例）+切换成本壁垒（机构重签/结算重接/数据迁移）。
  2. 三道锁（证据中，W）：结算走我行收单/分账（按课时分批结算，已确认事实5）、机构对公开户/代发沉淀行内、13家分行地推属地粘性——即使不排他，切换成本也在我们这边。
  3. 谈判要点（假设需法务部核实）：共建协议争取排他/优先条款；若拿不到，用"服务密度+响应速度+地推网络"取胜——"事实排他比条款排他更牢"。
- **答不好会怎样**：被"没有排他性凭什么投入"质问，战略账崩塌。

## 加分应答（主动说出口的加分点）

> 使用时机：汇报开场（先例三件套）、冷启动承诺处（首个数据点）、合规部分收尾（底线声明）；均为主动出击，不等领导追问。

1. **先例三件套开场（证据高，5·21纪要）**：主动讲"这不是我们第一次政务合作，是第N次"——首批接入人社一体化平台、社保代发730万笔/超250亿、省级社保基金专户第一中标；商务厅80%咨询先例收尾："我们不仅是金融机构，更是省委省政府的部门"。把"为什么是我们"从被问转为主动立论。
2. **16门AI公益课=第一个真实数据点承诺（证据高，已确认事实1）**：主动承诺"T+3月交出首份'公益课浏览→报名→留资→开户'真实转化率报告"，把冷启动假设变成可验证承诺——领导最怕"假设"，主动给验证路径就是加分。
3. **合规底线声明（证据高，五方共识）**："类目可以谈，合规底线不能破"——数据三红线（最小化收集、用途限定、训练不用未脱敏数据）、杜绝二清、宣传不做无据承诺，三条主动声明抢回信任；再加一句姿态金句："数据为人民服务、为政务服务，而不是为营销服务。"
4. **三本账一句话公式（证据中）**："直接账是入场券，间接账是门票收入，战略账是长期会员资格"——把复杂的算账逻辑压缩成领导能带走的一句话。
