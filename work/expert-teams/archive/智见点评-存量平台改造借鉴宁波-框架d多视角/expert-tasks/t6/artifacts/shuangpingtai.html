01

形势判断：三低时代，拼的是经营逻辑

低利率 · 低息差 · 低增速

低利率、低息差、低增速的三低时代，息差收窄压缩资金中介模式的盈利空间。宁波银行 2026H1 营收 +11.54%、净利 +12.12%、两项收入增速 18.2%（我行 11%），差距不在规模禀赋，在经营逻辑——宁波用服务收入对冲息差压力（手续费净收入 +53.9%、中收占比 10.42%），我行若仍在资金中介单腿走路，双提升就缺一条腿。

借鉴宁波不是可选项，是形势使然。 三低时代的竞争已从「存款价格战」转向「客户经营能力战」，谁的平台能把流量变成中收，谁就掌握下一个五年的定价权。

（四）样板就在腹地：逻辑已经跑通

波波知了 2023 年上线、17 万企业用户（南京约 2 万家；官方公开口径 17.6 万家、20+ 服务），按「帮企业赚钱 / 省钱 / 管钱」三层框架，聚焦江浙沪制造 / 科技 / 外贸，落地出海对接、节能规划、AI 赋能，靠政府园区招商联动获客；数字人力按「只撮合不交付、不收服务费」模式运营、2026 年底上线。

江苏本地已跑通，南京能做各分行就能做。 按定稿口径，双平台按企业任务链分工：波波知了 = 企业外部经营综合企服（经营侧），数字人力 = 企业内部组织运营与人薪税费（组织侧），同一企业可同时使用。

03

学什么：四条可迁移逻辑，形态坚决不学

学逻辑 · 不学形态 · 不新建平台
逻辑 ①

任务链逻辑

从客户「要办成什么事」出发组织服务，而非从产品出发。

逻辑 ②

独立运营逻辑

专业团队配置，把平台当事业而非附属品。

逻辑 ③

政银协同获客

政府园区招商联动，把政策资源变成获客入口。

逻辑 ④

先服务后转化

免费服务换数据与信任，先撮合后交付。

形态上坚决不学 不新建 App、不重复建设、不烧钱获客。再造两个 App 重投入（宁波平台团队阿里/字节社招、单岗年薪百万级）且与零售个人流量错配。平安信用卡仅作旁证，不入主框架。

个人任务链
社保/公积金· 缴费· 健康· 教育· 出行· 以旧换新 → 账户 / 卡 / 分期 / 财富

任务选择决定客户为什么打开——选高频、刚需、有数据价值的任务，把苏银生活从「生活服务陈列馆」改造成「任务型服务入口＋金融转化漏斗」。

企业任务链
工资单· 个税· 报销· 五险一金· 福利商城 → 代发 / 结算 / 授信

代发增值是企业任务链枢纽，且是「任务链＋金融转化」最短路径，直接贡献活期沉淀与存款成本下降。

公私联动 零售个人任务链产生企业线索（个体户收款、企业主身份识别）反哺对公，形成「零售获客 → 对公承接」正循环；「下一步」即渠道协同触发点：公积金提取完成 → 引导消费贷/信用卡；工资单查看 → 引导理财/定投。

渠道协同：「一重两轻」

轻渠道

苏银生活

承接高频简易需求，任务办理即转化入口。

重渠道

网点 / 客户经理 / 私行中心

承接复杂金融需求；私行客户走重渠道，任务入口只做触达与预约。

技术底座

复用 + 数据治理 + AI 嵌入

任务模块 = 外部接口接入 + 统一任务引擎 + 埋点体系；接口口径、更新频率、字段质量先治理再建模。

试点安排：90 天两场景，试点即止损闸门

度量先行 · 标准工具包 · 达标放量
前置 · DAY 0

度量先行

漏斗埋点与北极星指标先定义——否则试点无法回答「转化率」这个核心问题。

试点 A · 90 天

苏银生活高频任务：社保 / 公积金查询缴费

核心测转化率：任务 → 账户 / 卡 / 分期 / 财富漏斗。

试点 B · 90 天

代发客户轻模块：工资单 + 五险一金 + 福利购

核心测留存、沉淀、渗透。

执行机制

标准化工具包 + 样板先行

给分行标准化工具包（任务模板 + 话术 + 考核表），先跑样板，月度通报、季度排名。

闸门 · DAY 90

试点数据达标再放量，不达标回调打法

试点即止损闸门：90 天验证转化率信号，不验证全年中收增量（中收兑现通常需 2-3 个季度）。

06

验收标准：看业务沉淀，不看注册数

经营与管理双提质 · 防止「双提升」被曲解为「双第一」层层加码

验收看什么

  • 活期沉淀（对标宁波活期占比 35.57%）
  • 代发留存
  • 卡渗透
  • 中收贡献（对标代理类占中收 85% 的结构）

不验收什么

  • 注册数
  • 纯功能使用量
  • 表面客户升级（实际仍停留在资金中介）
07

不确定性与趋势

研判推断 · 待验证项明确标注
  • 数字人力形态待核实：2026 年底上线的实际形态与服务细节未经访谈核实，仅作对标逻辑引用；若形态与我行认知不等同，对标结论需修正（待核实后纳入）。
  • 中收兑现存在时滞：任务链转化到中收沉淀通常需 2-3 个季度，90 天试点只能验证转化率信号，不能验证全年中收增量。
  • 政企资源依赖：波波知了获客高度依赖政府园区招商联动，若我行无法复刻同等政企资源，企业任务链转化率预期应打折。
  • 月活目标节奏：苏银生活月活 800 万 → 1000 万目标的达成节奏存在不确定性，试点转化率分母口径需相应调整。
  • 权益产品待校准：365 元课程权益、消费贷团办的接受度与续费率待试点校准。
  • 同业竞争：同业生活平台亦在任务化，须立足江苏本省政务与本地生活资源差异化。
08

风险底线与未来关注

（一）合规与底线五条

  • 个人信息与征信红线：社保/公积金数据用于授信评估须客户单独明确授权，符合个保法最小必要原则，不得以任务办理为名变相采集数据用于营销。
  • 数据来源合法：政务/第三方接口签数据合作协议，权属与使用范围书面厘清。
  • 反洗钱：以旧换新补贴、消费券类任务防范套利刷单，资金流纳入监测。
  • 适当性管理：不因任务入口放松。
  • 不突破风险底线换取一时业绩：非金融权益嵌入须前置合规与消费者权益评估。

（二）外部合作守底线

合作红线 量子教育只配当供应商，客户、数据、账户、核心规则必须在我行手里；宁波百万级单岗的成本结构不照抄，存量团队 + 能力采购，底座必须是自己的。

（三）机制建设（经营与管理双提质）

机制 · 组织

平台运营专业团队

市场化人才机制；政银协同制度化，政府园区招商联动纳入常态化获客渠道，防止「运动式」联动。

机制 · 决策

试点-复盘-推广制度化

建立跨部门数据中台与公私联动线索台账（零售反哺对公的线索量 → 结算/授信落地转化），纳入季度经营分析。

（四）未来关注五件事

  • 宁波 2026 年报双平台经营数据，验证对标逻辑。
  • 90 天试点周度监测（A 转化率、B 留存/沉淀/渗透），达标即启动第二批场景放量。
  • 苏银生活任务功能上线排期与月活目标节奏。
  • 代发轻模块合规评审与个人信息保护审查，与试点同步推进。
  • 季度复盘中收结构与代理类占比，对照宁波中收占比 10.42%、代理类占中收 85% 的结构校准路径。
结语

存量平台改造不是短期冲规模，而是以长期主义重构客户经营体系

把苏银生活从「生活服务平台」升级为「资源整合与转化平台」，实现资金中介向资源中介升级，支撑双提升。考核评价体现长期主义与正确政绩观——三年看体系、五年看格局，不争一时之短长。

本次改造坚持不新建平台、不重复建设、不烧钱获客，用存量资源、增量机制，走出江苏银行自己的资源中介升级之路。
