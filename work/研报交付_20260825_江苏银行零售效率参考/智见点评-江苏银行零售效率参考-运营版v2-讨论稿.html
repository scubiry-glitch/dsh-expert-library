环节现在的问题（99wiki）借鉴的方法（98wiki）提效目标

04

方法库 A/B/C/D

Method Library

方法单独归类，不混在场景里——每个方法 = 是什么 / 用在哪 / 怎么落地 / 验证指标。

A

管户重配法（人效重构）

是什么贝壳「盘级经营 + 人房客重配」银行版：尾部零产出管户收归头部 + AI 辅助承接。零开单率 25%→<10%（内部单源）主要来自「0 变 1」尾部修复
用在哪消费贷用信唤醒（用信率 12%）、信用卡激活（60.39%）、柜面/咨询管户
怎么落地划片管户 → 人客重配 → SOP 化 → 考核分层（分行差分核销 α / 个人行为+净贡献双因子）
验证指标零产单客户经理占比（月度通报）；同店管户 AUM/人净增（控 β 差分）；P25 尾部产出占比（超 50% 属存量激活式修复，分开记账）
B

AI 提效法（AI 规模化）

是什么在「规则能写清楚」的环节用 AI（进件校验/反欺诈初筛/规则审核/名单分层），风险定价与终审人工兜底。物理上限=规则可表达边界，净降本 20-30% 到头
用在哪消费贷进件/审批、信用卡分期电销、电销名单分层、线上进件
怎么落地人工基线先测 6 个月（差分前测，非全行均值）→ AI 辅助/AI 自主两档验证 → 成本 BOM 入账 → 自主可控（外部平台当工具不当大脑）
验证指标AI 承接转化率 ≥ 人工基线且单客成本不升（6 个月证伪）；AI 进件占比（获批且放款口径）作监测；12 个月无证据即撤
C

场景获客法（渠道产能重定价）

是什么获客从「按网点成本付费」改为「按场景转化付费」（杨现领）：产品是转化工具，不是独立卖品
用在哪装修贷（消费贷线）、高端卡（信用卡线）、私行沙龙（柜面/咨询）、政银协同（以旧换新/人才安居）
怎么落地装修贷促转化定位（年化 3% 起、价内加价约 6% 贴息、受托支付+分节点放款）；统一商机池+智能路由+全渠道归因；权益互换合规前置；政银协同第三层
验证指标装修贷交叉销售率 ≥30% + 结算资金日均沉淀额；沙龙新增达标户/场、AUM 净增/场；权益互换新增达标户数
D

数据与验证法（口径 + 差分 + 止损）

是什么把「效率叙事」变成「可证伪工程」：同店口径 + α/β 剥离 + 对照差分——贝壳最有价值的不是结论而是验证协议
用在哪全部场景——是其他三个方法的「裁判」；行内已有止损先例（30/90/180 止损、电销净贡献 ≤0 即撤）
怎么落地口径字典（总行数据管理部统一发布、禁止分行自报表）→ 6 分行 90 天差分（控 AUM 自然增速 5-8%）→ 考核三原则 → 止损线
验证指标口径字典定稿 / 基线快照（不补基线则差分无可比）/ 差分初判 / AI 证据（时间节点后续再定）
