金 SEC.03

客户三 · 金融机构

FINANCIAL INSTITUTIONS
一页结论

把「可审计」翻译成银行的 KPI——T0 估值参考 ＋ T+N 价值监测，复核底稿直供内审与监管检查；边界声明——仅提供价值参考与监测信号，不替代法定评估、不直接决定授信或减值计提。

① 需求痛点 PAIN POINTS
▲单点评估＋贷后放任估值与市场存在时滞 ▲压力测试缺统一口径区域 / 物业类型 / 客户集中度 ▲评估报告不可复现内审、监管检查无法还原 ▲签章责任重结论出错责任界面不清
② 贝壳解题思路的不同 · T0 → T+N WHAT WE DO DIFFERENTLY

→ 形成授信参考底稿
→
T+N · 贷后监测持续
  • 持续更新估值
  • 价值偏离预警
  • 组合压力测试
→ 自动生成贷后复核底稿
→
复核底稿 · 可审计输出
  • 价值台账持续可查
  • 同条件可复现、内审问询一键还原
  • 直接供内审与监管检查查验
持续需求，而非项目制
做底稿、不做签章

估值只做过程、不做结论；需盖章环节引入持牌评估机构协作——不抢法定评估刚需，分润补位、责任界面清晰；一次估值偏差的成本远高于系统年费。

协作机理 「是专家团多轮出力，不是预置知识一次成稿」 —— 多专家并行研判 → 依赖链（资料梳理 → 数据梳理 ∥ 风险视角 → 宏观研判 → 融合成文）→ 渲染。
结论A 是可被抄走的文档；B 是工程资产（编排 / 工具 / 证据回写）＋ 参数资产（语料微调）＋ 终端资产（决策动作发生地）三层一体，合作方无法在合同期内自建。私有化部署、数据不出域、离线可用是银行 / 国企采购的硬门槛 —— 没有 harness 的证据回写与版本链，可审计只是口号。
优势 5 · 信用：声誉 ＋ 可复测 ＋ 可追溯TRUST AS AUDITABLE ENGINEERING

把「信任」从关系资产转化为可审计资产；声誉 = 长期一致兑现承诺积累的可信度，由四本账留痕支撑，不靠品牌背书。

MECH · 01

声誉 ＝ 四本账沉淀

长期一致兑现承诺积累的可信度，由四本账（事实 / 假设 / 方法 / 责任）留痕支撑 —— 决策不因人员流动与时间流逝而丢失。

MECH · 02

可复测 ＝ 同条件重放

给定历史时点重放数据、假设与计算，结果一致 —— 只描述已发生，不做反事实承诺。

按优势映射 TERMS BEFORE COLLABORATION

八条前提条款 ＋ 收费模式，逐条对应优势 —— 先说清楚边界，再谈合作。

1

数据授权边界

优势 · 数据
  • 可入合作环境的数据范围、可复用/可分发边界、衍生数据归属
  • 合作方输入数据（押品 / 信贷台账）反向授权与保密
  • 禁止用于合作外模型训练
2

部署形态与计量

优势 · 深度
  • 私有化 / API 形态与 Token 计量、费用边界、缓存复用权益
  • 微调层 IP 归属与底座模型许可合规
3

口径定义权与变更机制

优势 · 口径/标准
  • 40 城 vs 50 城、指数基期（价格 2020-01 / 活跃 2024-01）
  • 口径变更版本化、双方书面确认；对外发布前过舆情审核
4

责任边界

优势 · 审计/五链
  • 做底稿不做签章，结论责任归客户决策者
  • 复现仅限「已发生事实＋透明假设」同条件重放，不做反事实承诺
  • 证据链保留期限与可审计接口；不替客户决策、不隐藏不确定性
5

免费投入上限与付费测试

优势 · 商业模式
  • 免费投入 ≤ 总成本 20%，以「部委 / 协会采纳智见口径」为继续投入里程碑
  • 付费测试条款：试点意向书、10-100 万级验证，不做规模承诺
6

合规与退出机制

优势 · 合规/私有化
  • 数据不出域技术承诺；等保 / 信创 / 金融合规清单；脱敏责任划分
  • 终止时数据删除 / 归还、底稿与账号处置、白名单回收（领导直问 300 人）
7

生态协同

优势 · 生态（贝壳研究院）
  • 与贝壳研究院的协同协议先于对外叙事落定
  • BK 专家体系（33+ 位、五域分类）即智见 A 智囊层现成资产
8

真实性条款

优势 · 真实/信用
  • 贝壳对成交事实真实性负责（可审计证据链），对决策结论不对结论负责
  • 对事实负责、不对结论负责
9

收费模式：年费三包 ＋ 按次计费

优势 · 深度/基础设施
  • 机构基础包年费（数据 ＋ 模型服务）· 业务解决方案包（工作台定制 ＋ 私有化部署）· 扩展包（Token 额度 / 大屏 / API / 嵌入式组件）
  • 按次计费：按调用 / 查询 / 报告次数计费，适合低频高价值单次决策场景（如单次估值、单次监测报告）
