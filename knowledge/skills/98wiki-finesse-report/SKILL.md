# 98wiki 图文报告 Finesse UI · 固定工艺

本 Skill 只处理经审核的研究报告图卡与渲染，不修改研究结论。选择 editorial publication 的阅读型版式；桌面与窄屏均保持正文优先，A4 打印为主文。读取 `knowledge/skills/finesse-ui/SKILL.md` 的 register、`references/chart-crafting.md` 和 §8 pre-flight 后实施；本文件是任务冻结的执行底线。

## 点睛图

- 每个选定分析章一图，一图一论点；视觉编码与结论相称，禁止把无量化依据画成比例图。
- 数字、单位、地域、时点与口径逐项取自已审 `report.md`，标明来源。无原文数字则做定性机制/对照图。
- 图卡在默认 DOM 中可见；动画、reveal、交互只增强表达。禁用脚本、弱网或减少动态效果时仍可阅读。
- 不制作假 CTA 或死按钮；无真实业务回调的元素用静态说明。

## 渲染与 pre-flight

- `report.md` 保持已审原字节；HTML 的正文层与图层分别登记，已审图卡片段原样嵌入；PDF 导出完整 HTML 可见内容。
- 字号保持可读下限：屏幕正文至少 14px，其余可见文本至少 12px；A4 正文建议至少 10pt，图注至少 8pt，须再由人工看实际印刷尺寸。禁止通过缩小字体容纳超长内容；窄屏与 A4 均无横向裁切。
- 实测 HTML DOM、键盘焦点、语义标题与图替代说明；检查宽屏和窄屏，PDF 首、中、末页。记录当前文件哈希、渲染时间、方法、页面数与截图/检查回执。
- 检测器零告警仍需人工复查；假 CTA、死按钮、依赖 reveal 才能看见内容、字号过小与裁切均按 blocker 处理。
