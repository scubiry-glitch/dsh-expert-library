# 专题取证与反证

读取用户选定观点、各专家分歧及 viewpoints.md 的共同事实表。先核对现有回执能否回答自己的问题；复用有效的原始数据，针对关键结论抽查原来源并独立重算。缺失、过期或口径不适用的数据再取，并说明为何不能复用。按自己的专业追踪关键证据、核对反例、说明样本和推断边界；必要时推翻原观点并记录理由。输出 evidence.md，包含真正读取的来源位置、时间、统计口径、单位和回执路径/哈希。空序列不是零；挂牌不等于成交；单位未知时不引用数值。只取所需数据；技术日志作为附件，正文突出判断。没有来源数量、章节或字数配额。

## 提交

遵循 Host 的 current_action，以本任务发布声明为准。在原任务同一 attempt 内修订，不为提交方式错误新建替代任务。内部材料由 Host 校验并锁定后自动流转；只有正文和成品进行独立评审，不把内部材料称为已审结论。提交失败按具体错误重试，不能伪造回执。
