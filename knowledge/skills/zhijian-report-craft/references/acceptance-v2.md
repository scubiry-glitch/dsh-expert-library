# 当前字节的验收矩阵

必需结果只接受 passed。failed/unverified/缺证据/过期/摘要不一致不得整合为质量合格；not_applicable 要有冻结范围依据。

| 领域 | 必需依据 | 范围限制 |
|---|---|---|
| 材料 | 同包版本、digest、角色必读 id/SHA、完整正文交付及本 task/attempt/session 接纳 | 路径存在或模型说已读不算完整交付 |
| 结构 | 真实 h2 分析章与 ledger 一一对应，五件套各有实质，来源/开头/收束完整 | DOM 标记和文本跨度证明定位，语义须独立审核 |
| 数据计算 | 来源、单位、共同基准、公式参数及结果；支持的 ledger 公式由 Host 重算 | 声明的计算块不代表全文数学认证 |
| 格式 | MD 可见正文逐块映射 HTML，选择的数字与 PDF/HTML对应；最终三个SHA | 同一个错误被复制三次仍是错误 |
| 视觉 | 本版 HTML 离线浏览器 1280/375；几何、锚点、计算样式 AA 与实际截图 | CSS grep/局部标记不能代替浏览器或审美审核 |
| PDF | 解析最终文件；封面封底、正文 i/N、品牌、章节大纲、必要页面渲染 | HTML 写了页脚不证明 PDF 有页脚；合并后重验大纲 |
| 独立审核 | 非作者，逐项指出所审文件SHA、位置、依据、复算和未决问题 | 不接受全 true 布尔值代替审阅依据 |
| 交付 | 同task/attempt、材料digest、契约与当前字节检查/审核/整合一致 | 旧回执或外部复制不自动取得通过身份 |

`craft_gate_report.sh` 与 `craft_density_check.py` 仅做明确标示的 HTML 局部预检，永远不输出“完整工艺 ALL PASS”。实际 Host 检查回执由可信执行路径生成，作者不得伪造。机器依赖缺失记录 unverified 与恢复入口。修复使用限定预算；撤回、重新打开、换契约不能重置已经用掉的预算。只有新版本全部适用项被覆盖后才能称合格交付。
