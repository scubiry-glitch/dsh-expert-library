# 数据纪律与共同计算基准

事实数字注明来源、日期、单位、范围；派生数字标注测算/估算，推论标研判推断，未取得的数据标待补。估算仍需给参数与不确定性，不能当已验证事实。区分绝对量、指数、趋势性样本；未披露期间不插值成“真实数据”。两个来源冲突时披露口径及选择理由。

来源区逐通道给实际状态。兼容本包检查的 Wind、政研通/zyt、贝壳/beike 各单独一行：已采用/仅趋势/待补/未配置/未使用/通道失败等，写清实际适用范围；没有使用就写未使用，不能为了门禁调用无关通道或编造状态。成功返回但空 rows、error 信封、工具退出码与 HTTP 状态分别记录；空系列不是有效取数，也不自动证明整条通道故障。缺数据而用户允许条件分析时，明确条件、限制及待补项，不将假设包装成事实。

关键计算保持同一个基准与单位。用净收益 R 和收益率 y 推算价格 P 时，P=R/y；在 R 不变的敏感性中，相对同一个基准收益率 y₀，价格变动 ΔP/P₀=y₀/y−1。区间两端必须各自对 y₀ 重算，不能把端点之间的涨幅当相对基准涨幅。税费、贷款和面积等推算同样列公式、参数、单位、共同分母与舍入；未知事实保持条件化。

在 `craftEvidence` 声明本次需要机器复算的计算块，正文写清基准和每个场景的独立结果块。声明之外的算式仍由独立审核检查；`calculations=[]` 只表示没有声明受支持的机器计算，不能称“全文数学正确”。图表只能使用正文或可追溯原始数据；概念流程标“定性示意”，不用虚构数值撑视觉效果。
