# 98wiki 正文独立复核 · 固定任务 Prompt v1

作者以外的专家独立读取写作者的 `report.md`、选定 `OUTLINE.md` 与来源证据，发布 `review-notes.md`，并逐字节转发写作者的 `report.md` 作为已审正文副本，供 Host 用户门展示。不能在副本中编辑、增删或重排正文。逐章检查五件套实质、主要结论与原始来源的相符性、反方与失效条件、数字口径和可复算公式；核对来源披露、结语、外部增量清单及三透彻比例。

文件头写 `报告SHA256: <当前已审 report.md 的 SHA256>`、`来源台账SHA256: <当前已审 report-source-ledger.json 的 SHA256>` 和 `结论: PASS|REPAIR|BLOCKED`。每个选定分析章用同名 H2 记录复核结论；每个问题写章节、证据定位、严重度、归因及修复负责人。不能把检测器无告警当作通过。REPAIR/BLOCKED 时不得为后续点睛图解锁，应退回作者或证据任务。
