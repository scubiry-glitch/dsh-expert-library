# 银行活动效果评估闭环

用于信用卡/零售业务的营销活动与大促评估：判断活动有没有用、哪里起作用、下一轮怎么改。

## 先确认任务

识别用户处在哪个环节，不要四种工具平均展开：

- 活动前评估：定目的、定指标、定对照组（用"活动定位→指标匹配"）。
- 活动中监测：看曝光-转化结构，找到掉人的环节和关键时间节点。
- 活动后复盘：算增量、分客群归因、沉淀认知（用"平行世界对照"与"单变量 A/B"）。
- 能力演进复盘：多个活动串起来看团队认知怎么迭代（三阶段演进复盘）。

## 四件工具

### 1. 平行世界对照（简化 PSM-DID）

给活动人群找一个"没被活动但其他条件相似"的对照人群，用对照人群的同期走势
当作"如果没有活动会怎样"的替身世界，活动增量 = 实际走势 − 替身走势。

- 适用：已有全量触达、无法随机分流的历史活动复盘。
- 不适用：对照人群与活动人群在客群质量上明显不同（会高估或低估增量）。
- 纪律：没有对照组不下因果结论；只能描述相关时明确说"未见因果证据"。

### 2. 活动定位 → 指标匹配

先问活动目的是哪一类（拉新促激活 / 提交易频次 / 提资产沉淀 / 挽流失），
每一类只看它该看的指标，不要用一张全指标表评价所有活动：

- 拉新促活 → 看新增激活、次月留存；
- 提交易 → 看人均笔数、动卡率增量（相对对照组）；
- 提资产 → 看沉淀余额增量，而非交易笔数；
- 挽流失 → 看留存率增量与回流成本。

### 3. 曝光-转化结构定节点

把活动漏斗拆成 曝光→点击→办理→首用→复用 各环节，比较各环节转化率与
历史基线，找到"掉人最狠"的环节；时间轴上标记关键节点（大促日、权益
发放日），判断效果集中在节点前还是节点后。

### 4. 单变量 A/B + 分客群双指标

同一轮活动里只改一个变量（文案/权益/门槛），按客群分层同时看两个指标：
响应率（短期）+ 质量指标（留存/风险，防"吸引来的是羊毛客"）。
只报相对提升，不报绝对值当结论。

## 能力演进复盘

连续多个活动后，把团队的认知变化分三阶段记录：'会做'（能执行流程）→
'会算'（能量化增量与ROI）→ '会迭代'（能据上轮结论改下一轮设计）。
每个活动复盘必须写一条"本轮学到了什么、下一轮改什么"，没有这条不算复盘完成。

## 证据纪律

1. 区分事实、推断与假设；增量结论必须挂对照组。
2. 引用历史活动数据时保留活动时点，不当作现行事实。
3. 平台方经营分析中的图表绝对值若原文自陈"示意数据"，只引排序不引数值。
4. 缺数据时列待验证项，不虚构转化率、ROI 或客群行为因果。
