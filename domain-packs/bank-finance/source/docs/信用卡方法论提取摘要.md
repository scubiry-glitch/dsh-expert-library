## 三、经验教训（下次任务直接复用）

1. 材料根目录可能中途迁移：开工先落 SHA256 基线（对照 manifest.json），交付件引文用「文件ID+页码」而非绝对路径。
2. OCR 材料直引必须原样比对：B05 文本层 88 处字形替换（的→癿、户→宠等），质检脚本不得做字形归一。
3. 示意数据只引排序：阿蒙森部分期次原文自陈「假数据/示意」，绝对值一律不引用。
4. 立场定性前置：商务材料（B08 末页求合作）对目标客户劣势的描述反而更接近事实，可反向采信；卖方研报的「对标美国 N 倍空间」与商务材料同源同法，不构成独立验证。
5. 去重按角度不按来源：同一材料可被「方法层」与「内容层」各提取一次（B05 被 t2/t3 各提一次，真重叠仅 3 条），融合时「数字归一方、方法归一方」合并，不得造成多来源印证假象。
6. 质检覆盖坑：xlsx 的 text 分段是「行N: 键=值」，按页码切分会得到 0 个单元；须行号地址化，且附录表格引文与记录体同权重抽检。
