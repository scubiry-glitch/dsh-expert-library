# 银行房产价值咨询报告

输入至少包含城市、小区、建筑面积（平方米）。银行名称、支行名称和评估公司可留空；缺省时不得从模板样例继承。城市没有给出时，先从可信会话上下文确认，无法唯一判定就请用户补充。

## 执行

在获授权的使用方身份中运行包内 `runtime/generate_bank_property_report.py`。生产实例可使用账号 C 私有环境中的只读贝壳与政研通 CLI；不得复制其凭据。示例：

```sh
python3 runtime/generate_bank_property_report.py \
  --city 北京 --community 碧兴园 --area 85.43 \
  --output /secure/deliverables/房产价值报告.docx
```

脚本先验证贝壳精确小区命中，再用真实小区 ID 查询小区详情，筛同小区、面积偏差不超过 20% 的在售房源，查询政研通小区与城市 `SH_PRICE` 时序。小区详情中的停车、安防、物业费与周边设施可写入对应模板字段；用户点评只能作为有来源的主观意见，不得推断犯罪率、住户构成或邻里关系。没有可核实的“小区缺点”时留空，不得沿用模板示例，也不得输出“待核”“待调研”“待审核”等过程占位文字。第三方信息与现场勘查结果冲突时应暂停填报冲突字段并复核。小区时序为空时只在说明中使用城市趋势，不以城市均价推算小区房价。三个及以上挂牌样本可形成内部初步参考值；样本不足时金额留空，并在证据回执记录样本数量。原模板的段落、两张表及样式保留，旧示例数据全部替换或清空。

生成器同时输出 `.evidence.json`，包含来源、样本 ID、面积、挂牌单价、时序及口径。复核 DOCX ZIP 可打开、两表分别为 6 行和 20 行、旧公司名清除、证据数值一致。报告不是正式房地产估价或抵押价值证明。

把 DOCX **上传至当前会话的受控附件服务**，收到实际文件 URL 后才向用户回复可点击下载链接。若宿主不支持附件上传，只能说明文件已生成及可用交付方式，不能把本地路径、文件名或 Markdown 占位符冒充下载链接。
