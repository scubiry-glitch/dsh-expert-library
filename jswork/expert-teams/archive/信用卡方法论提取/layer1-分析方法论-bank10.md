### A-03｜STP 三段式（细分→目标→定位）选客群

| 字段 | 内容 |
|---|---|

| 出处 | A11 阿蒙森洞察报告-2021年第3期.pdf，PDF页码2–3（STP 引言与理论释义图）、PDF页码4–7（六档细分与 Targeting / Positioning） |

| 方法拆解 | **① S（细分）**：六档客户＝按"风险×美团活跃度×支付习惯"分档（A11，PDF页码2–3）；**关键约束**——分层维度须是"在和客户发生接触之前就能够有效识别的、显性的特征"（A11，PDF页码3），因为要能指导**获客前**的投放。<br>**② T（目标）**：用**价值表现**选目标，而非规模。原文给出可核验的利润口径公式组：风险调整后资产收益率＝税后收益率−4.0%资金成本−年化NCL；年化NCL≈年内净新增M2+余额/年平均余额/发生月×12；税后收益率＝单位余额生息资产年化收益率＋单位余额交易佣金年化收益率（A11，PDF页码5）。<br>**③ P（定位）**：定位＝**找客与获客方式**。按渠道判定打法：1–3 档在营销渠道转化效率高→主动出击的 **Hunter 模式**（获客成本更高、激活率更低）；5–6 档在金融类渠道转化效率高→经营固定入口的 **Farmer 模式**（A11，PDF页码5–6）。<br>**④ 取舍要显式**：原文对两类目标客群分别写明代价——要 1–2 档须接受高获客成本与权益升级/高额度投入；要 5 档须有更高风险容忍度与更强风险识别能力（A11，PDF页码2–3）。 |
| 适用条件与边界 | **成立**：细分维度可在触点前识别；有可分摊到分档的收益与风险成本数据（否则 T 段退化为拍脑袋）。<br>**失效**：① 维度定为"隐性特征"（如意愿）就无法用于前端投放；② 分档收益口径若含平台侧营销费用分摊，跨机构不可比（A11 PDF页码5 的"户均常态权益成本"含尝鲜/天天减等活动费用，是**平台侧口径**）；③ STP 选出的目标客群只是**策略假设**，需经 A/B 测试才能当结论。 |
| 可迁移性初判 | **高（框架）／中（参数）**。三段式与 Hunter/Farmer 判别逻辑可整段迁移；但利润口径公式里的资金成本（4.0%）、NCL 折算方式必须换成本行口径重算，**不可直接套用 2021 年平台参数**。 |

### A-04｜分层维度的年度迭代法

| 字段 | 内容 |
|---|---|
| 方法名 | 分层维度的迭代法（按业务阶段更换切分维度并保留可解释性） |
| 出处 | A11 阿蒙森洞察报告-2021年第3期.pdf，PDF页码3 |
| 原文关键句 | 「在去年，我们对于客户的分层主要依据"城市×年龄×美团活跃度"这三个维度，而在今年…通过"风险×美团活跃度×支付习惯"的分类方式进行了客户分层。」（A11，PDF页码3；省略号处为原文"我们结合业务实践进行了迭代"，仅为压缩字数）<br>（同页续：「特别增加风险维度的逻辑在于当具体获客时，会重点考虑在当前的风险能力下最有把握通过的客群是哪一部分。」） |
| 方法拆解 | **① 旧维度**：城市×年龄×平台活跃度（人口统计＋行为）。<br>**② 新维度**：风险×平台活跃度×支付习惯（风险＋行为＋支付心智）。<br>**③ 迭代动因**：原文表述为结合业务实践迭代，并**特别增加风险维度**——即当业务约束从"规模获客"转向"风险可控获客"时，分层维度随之更换（A11 PDF页码3；旁证：A05 PDF页码4 以客户风险分级为固定视角做全面经营分析）。<br>**④ 隐含规则**：分层维度不是一次性设计，而是**随业务阶段滚动重检**；且新旧维度需保持可对照（活跃度维度被保留）。 |
| 适用条件与边界 | **成立**：业务目标或风险约束发生阶段性切换时；有新旧两套维度下的历史可比数据。<br>**失效**：频繁更换维度会破坏时间序列可比性——**改维度同时必须锁定"口径切换时点"并做双轨过渡**，否则跨年数据不可比（🚫 本批材料未给出双轨过渡做法，属待验证项）。 |
| 可迁移性初判 | **中**。"随业务阶段换维度"的元规则有价值，但落地依赖行内是否有能力同时维护两套标签；建议一次只换一个维度并保留对照期。 |

### A-05｜大促活动效果评估：PSM-DID 与简化平行世界

| 字段 | 内容 |
|---|---|
| 方法名 | 无对照组的活动增量评估法（双重差分倾向得分匹配 PSM-DID ／ 简化平行世界法） |
| 出处 | A01 阿蒙森洞察-2022年第1期.pdf，PDF页码9（方法论述与口径定义）、PDF页码9–10（实例） |
| 原文关键句 | 「两种方法的核心思想都是：构建一个没有大促的平行世界，观察现实世界与平行世界的区别。」（A01，PDF页码9） |
| 方法拆解 | **① 问题**：普适性/大促活动面向全体客户，**没有干净对照组**，活动前后直接比会混入外部环境效应（原文举例：双十一本身会推高交易）。<br>**② 科学解法（PSM-DID）**：在所有未参与客户中，按特征或评分**一一匹配**出与参与客户相似的群体作为对照组，再比较——优势是最科学，劣势是耗时耗力，且「不同分析师可能会根据不同的匹配规则圈选出不同的对照组，导致分析结果难以被其他人复现」（A01，PDF页码9）。<br>**③ 简化解法**：以活动参与客户为研究对象，取其活动前一个月的自然交易表现，**叠加自然时间效应**作为平行世界；自然时间效应＝全量客户两个月之间户均交易金额的差值。优势是**可复现**，原文称「也是各家大行较常使用的评估方法」。<br>**④ 指标口径（必须锁定）**：活动渗透率＝参与活动激活流通用户÷平均累计激活流通用户数；增量交易金额＝活动组大促期间交易金额−对照组大促期间交易金额（拉齐人数）（A01，PDF页码9）。<br>**⑤ 判读规则**：ROI＝1 时成本:增量交易金额＝1:43，活动可持续（A01，PDF页码10）。 |
| 适用条件与边界 | **成立**：全量投放、无随机对照的活动；有活动前一个月以上的自然表现期；外部冲击可被"全量客户同期变化"近似吸收。<br>**失效**：① 外部冲击对活动组与全量客户的**影响不同质**时，简化法会高估或低估（这是简化法相对 PSM-DID 的核心代价）；② 人群未拉齐则规模不可比；③ 原文自陈 PSM-DID 结论**难以复现**——同一活动换分析师可能得出不同增量。 |
| 可迁移性初判 | **高**。行内同样大量存在"全量短信/权益活动无对照组"的场景；且方法自带"科学版/可复现版"两档，可按分析资源择一，**关键在于把口径写进分析模板**（渗透率、增量金额、ROI 三条定义）。 |

### B-06｜单一公司深钻拆解（招行/中信/浦发三案例）

| 字段 | 内容 |
|---|---|
| 方法名 | 板块论证的"代表公司深钻"法（以机构案例支撑行业结论） |
| 出处 | B05，PDF页码19–22（"4.3 信用卡收入贡献有多大？—细看招行、中信、浦发"与投资建议节） |
| 原文关键句 | 「招行由10 年的24.2%升至17 年的49.4%，中信银行则由27.65%升至71.84%。」（B05，PDF页码20） |
| 方法拆解 | **① 选代表**：按"路径差异"而非"规模排序"选三家——招行（先行者、多元零售）、中信（依赖信用卡的高零售占比）、浦发（"绕道超车"高增速）（B05，PDF页码19–22）。<br>**② 用同一组比率横向比**：信用卡收入/营收、信用卡收入/零售银行收入、卡均收入（浦发 975.02 元居首）、信用卡收入/平均透支余额（浦发 14.77% 居首）、授信使用率（招行 71.12%）（B05，PDF页码20–21）。<br>**③ 由比率差异反推经营模式差异（本方法的关键一步）**：原文据"招行与中信信用卡/零售营收差距"推断"中信零售对信用卡依赖较大，而招行通过私人银行、财富管理实现较为综合而多元的零售银行经营"（B05，PDF页码20）——**同一指标的不同水平对应不同商业模式**，而非简单优劣。<br>**④ 口径说明**：明确"以信用卡收入/期初期末平均贷款粗略估计信用卡资产收益率"（B05，PDF页码20），承认是粗略替代口径。 |
| 适用条件与边界 | **成立**：能拿到同一可比口径的多年披露数据；机构选择覆盖不同模式。<br>**失效**：① 原文自陈"国内上市银行披露的信用卡收入以及利润的寥寥无几"（B05，PDF页码7）——数据可得性本身就是约束，样本非全体；② 比率差异反推模式属**解释性推断**，不是因果证明（原文亦用"我们认为"）；③ 卡均收入、资产收益率等比率受分期口径（招行 2015 年切换）影响，跨行跨年比须先做口径还原。 |
| 可迁移性初判 | **高**。"按模式差异选代表 + 同组比率横比 + 由比率反推经营模式 + 标注粗略口径"是一套完整的同业对标纪律；**行内对标时应先做机构范围/口径还原，再解读差异**（与本专家"口径先统一，再谈比较"一致）。 |

## 3. 横向对照：两套范式的方法论差异（本层小结）

> 这不是"哪套更好"，而是**任务类型不同 → 分析路径不同**。选择前先确认要解决什么问题。

| 对照维度 | 阿蒙森洞察（平台经营分析） | B05 天风证券（卖方行业研究） |
|---|---|---|
| 分析对象 | **单一业务线条的客户级行为**（曝光→申请→批核→激活→实动→分期→风险） | **行业与上市公司板块** |
| 数据底座 | 平台侧经营数据 + 算法模型 + 自有问卷/访谈 | 央行支付体系报告、银联数据、上市公司年报、Bloomberg/Wind |
| 核心方法 | 实验（A/B、PSM-DID）、分层聚类、算法模型、闭环复盘 | 收入结构解构、比率横比、国际对标、规模测算 |
| 时间粒度 | 月度/账龄（MOB）级，看 vintage | 年度/半年度，看趋势与占比 |
| 结论形态 | **可执行动作 + 过程性指标**（谁在什么时点对哪层客群做什么） | **方向判断 + 标的建议**（行业是否有空间、谁受益） |
| 主要局限 | 平台口径，跨机构不可直接搬运；部分期次自陈为示意/假数据 | 披露数据稀缺；历史经验阈值；卖方立场 |
| **互补关系** | 阿蒙森提供"怎么做"的操作级方法；B05 提供"为什么值得做"的行业级推导与**口径还原纪律**（B-01） | — |

**跨材料共性方法（两套范式都出现的三条元规则）**
1. **口径先统一**：B-01（科目-实质映射+还原）、B-04（分母选择）、A-13/A-16（渗透率与归属口径显式定义）。
2. **无对照不做因果**：A-05（平行世界/PSM-DID）、A-08（实验组vs对照组）、A-14（阶段归因需同期对照）。
3. **缺数据显式标注**：A-18（单卡收益率不详）、B-06（披露者寥寥无几）、A-09/A-17（示意/假数据仅排序为真）——**本批材料本身即反复示范"不补数"**。
