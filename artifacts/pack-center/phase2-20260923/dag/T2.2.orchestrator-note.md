# T2.2 host execution note

The Codex sandbox cannot access the Docker daemon or bind/listen on loopback. Execute the idempotent runner from the workspace root on the host orchestrator:

```bash
/root/.nvm/versions/node/v22.22.0/bin/node scripts/phase2/t22-bind.mjs
```

It creates only the labelled `dsh.pack-center.phase2` PostgreSQL container, writes credentials under `/tmp/p2-20260923/secrets/` with mode 0600, starts the center API and workers with logs in this DAG directory, and writes the T2.2 evidence files. It refuses to proceed when either T2.1 endpoint is absent or was started without `packCenterOrigin=http://127.0.0.1:18430`; rebinding such a manager requires a restart, which is outside T2.2's no-stop boundary.
