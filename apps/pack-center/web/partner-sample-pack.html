文件格式速览

文件格式要点
pack.jsonJSONcaliberDeclarations 是领域包的数据宪法：包内专家引用任何数据源必须落到声明过的口径
experts/*.jsonJSONschemaVersion 2 全字段：persona（九子字段）/ emm / outputSchema.rubrics（1-5 级量规）/ modelPolicy
scenarios/*.jsonJSONtasks[].dependsOn 引用数组下标构成 DAG；skill.appliesToTaskIndex 绑定场景技能
output-templates/*.jsonJSON章节骨架 + 四级数据标注规则 + 渲染要求
quality-policies/*.jsonJSONgates[] 硬门阻断 / 软门警告；maxRepairRounds 修复轮次
skills/<id>/SKILL.mdMarkdown + YAMLfrontmatter 的 description 写全触发词；正文 §0-§3 结构
capability-contract.csvCSV每能力一行：capability / method / schema / caliber / unit / dataView / SLA
SOURCE-MANIFEST.jsonJSON每份材料登记出处 + 授权状态；无授权不入库
