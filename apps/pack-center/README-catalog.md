# 授权目录与下载服务

`createCatalogService` 只分发已发布、签名有效、清单身份与批准快照逐项一致的版本。API 仅获得受保护公钥库存，不读取发布私钥；配置见主 README。中心返回的公钥/指纹是待核对信息，部署点必须通过可信管理渠道独立确认信任，不能自动信任任意中心。

## 可见性

- `organization`：只有拥有组织的有效成员或该组织有效部署身份可见。
- `authenticated`：任一有效人类会话或机器身份可见，不允许匿名。
- `selected`：只允许列明组织成员/部署身份，或列明的具体部署点；不隐含授权拥有组织。
- 平台管理员、审核员管理权限不自动授予私有目录读取权。管理回执与分发 API 分开。
- 过滤在分页之前执行；不可见版本详情与不存在版本同为 404，不泄漏版本数或私有条目。ID 游标按字典序，不承诺创建时间排序。
- 所有目录请求重新读取当前身份权限。机器 principal 由服务认证绑定，复制或伪造对象不能调用。

详情返回固定清单、校验报告、许可证与说明。`downloadAvailability` 单独显示固定依赖是否仍可获得；任一传递依赖被下架/撤权会阻止新下载，不删除已有本地副本。

历史差异包含旧文件名、实体名和权限信息。仅在调用者也能访问历史 baseline 时返回；旧版不可见或下架时返回 `diff: null` 和 `diffAvailability: {available:false, code:"BASELINE_UNAVAILABLE"}`，不暴露旧版 ID 或私有差异。客户端不可把缺少差异显示为“没有变化”。

## 短时许可与实时检查

`issueDownloadGrant` 默认签发 60 秒随机许可，只在当前响应返回明文，数据库只保存摘要。许可绑定 release、签名清单摘要、归档摘要与用户；机器许可额外绑定具体 credential，另一点或同一点的新 credential 不能复用。它不提供匿名访问，也不放进 URL。

下载必须同时携带原身份和 `X-Pack-Download-Grant`，检查当前会话/凭据、组织/点状态、scope、下架、传递依赖、许可到期与制品完整性。验权事务锁住相关行至授权提交；签发后发生的撤权会拒绝后续新下载。已授权并开始发送的流不会因之后的撤权被远程回收。

存储先校验完整归档，再把同一文件描述符交给惰性流，读取中继续校验摘要。失败/断连/事务失败均销毁流；不重新按路径打开已验证文件。只提供完整 tar；不提供 Range、条件缓存、存储跳转或公开 URL。

许可可在有效期内随相同身份重试；不承诺“消费一次”。绑定码则是单次兑换：默认 10 分钟（最多 15 分钟），机器凭据默认 30 天。轮换步骤为管理员签发新码 → 宿主兑换 → 核验并安全保存新凭据 → 撤销旧 credential。兑换响应丢失时从管理回执查 credential 元数据、撤销不确定凭据后重绑，不能回放取回明文。禁用点会撤销全部旧码/凭据，重新启用不会复活。

## 尚未完成的运维边界

本轮无 S3 适配器、生产反向代理限流/硬配额、历史 grant/CAS 的安全 GC 或数据库最小权限部署。`download_grants` 是只追加记录，需要后续明确保留与归档策略；不能把短时许可误认为已实现存储自动回收。API、数据库、Worker 的独立角色与真实恢复演练仍须交付。

当前测试覆盖实际数据库和身份协议，不等同于插件远端接线、浏览器 UI 或两套 DSH 实例验收。
