## 配置失效缺陷与修复

scoped preset 会遮蔽 Host 注册的同名工具，但旧入口没有消费 Host 设置，也遗漏 `expertModelOverrides`。因此仅在网页保存正确值不足以证明实际成员使用 Kimi。

新入口按需读取 Host 已注册 namespace，透传模型默认、专家覆盖和并发配置；不重复注册 namespace。支持设置后注册、热更新和服务移除后的配置回退。已有成员与已确认研究计划继续使用自己冻结的模型，不通过更新默认值改写历史。

显式 profile/member 路由仍按已有优先级生效；这是默认设置及当前专家预设覆盖，不是禁止用户再显式选择其他模型的全局安全策略。本次重跑输入明确要求所有成员及审核员使用 Kimi，运行后按 `request/header` 和后续用量记录核查实际请求。
