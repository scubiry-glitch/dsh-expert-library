# 观澜真实试跑（粘贴到新的 DSH 会话）

请进入专家团队的目标模式，做一轮**观澜**真实试跑。研究题目：**截至运行当天，中国利率、信用与居民资产配置的最新变化，对一线城市存量住宅的持有、出售决策有哪些可验证的影响？** 交付对象是投委会，目标是形成一份有证据、有反方观点的决策备忘录。

1. 先核对当前会话实际启用的领域包版本、专家与 Skill。优先由 `macro-capital-analyst`（观澜）承担宏观与资本分析，由 `style-renderer`（砚边）负责表达与呈现；仅在当前运行时确实可用时绑定。其他专家、Skill、模型从当前可用清单中选择，并解释选择理由；不要把包中心已发布等同于本租户已安装。
2. 生成可执行的子 DAG：数据核查、宏观传导、住宅市场验证、反方审查、主文撰写和表达检查。计划图逐节点列出专家、Skill、模型、输入、输出、依赖和验收规则。停在**计划确认门**，返回可直接打开的独立页 URL，等我在页面确认；不要代我确认。
3. 确认后用真实、可追溯的时点数据完成研究。区分事实、推断和情景；记录数据日期、口径、来源链接或调用回执。没有可靠数据的结论降级为待验证假设，不填造数字。提出至少两条能推翻主结论的证据条件。
4. 大纲形成后停在**大纲确认门**，再次返回独立页 URL。确认后完成备忘录、来源台账和反方审查记录。正式表达避免工程术语。
5. 在每个门和最终交付时报告真实会话 ID、团队 ID、计划 ID、当前状态、已完成节点、待处理事项及独立页 URL。所有 ID 与状态必须从运行时读取，不要编造。若包、工具或确认门缺失，明确停在预检并列出精确阻塞；不要换一个旧包默默继续。
