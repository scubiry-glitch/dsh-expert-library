执行路径

专家与框架推荐 → 所有选中专家提出观点 → 用户选择方向 → 各专家取证与反证 → 表达策划 → 正文及独立内容评审 → 用户确认正文 → HTML/PDF 及独立视觉评审。

候选观点确定前不要求最终章节；大纲随证据重组。两位研究专家时，内部执行图为 10 个节点；三位为 12 个，五位为 16 个。增加的节点对应实际专家贡献，不增加人工审批。用户参与的两道阶段门为方向选择、正文确认；创建团队前仍需确认专家、框架与模型安排。

门禁如何放宽

取消固定章数、标题逐字锁定、逐章六件套、研究占比、外部增量数、每章图数、全渠道探针及固定结束语。V5 允许一个明确的分析轴与主命题，不必为了数量另造假设。

保留真实来源、单位与口径、关键计算、反证与不确定性、独立内容/视觉复核。内部材料锁定为“工作材料版本”，不会伪称独立评审通过。声明文件不齐或提交格式错误，返回明确可重试状态，不消耗内容修复预算；Host 检查未验证时进入技术等待，不能用作者改稿次数填补工具故障。

核心判断台账采用 schemaVersion 2，记录来源、正文原句、实质数值单位/统计期/口径、计算说明和未决问题。机器格式通过不认证事实；独立评审还须检查遗漏及错误推断。
