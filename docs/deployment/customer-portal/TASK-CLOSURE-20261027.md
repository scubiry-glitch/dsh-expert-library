## 实现

- 客户页在已有会话和无会话状态均可发起任务；银行房产价值报告只对 C 账号开放，自定义任务适用于已开通的账号。聊天入口继续独立使用。

- 产物登记发生在 Agent 校验文件之后；单纯文字声称已生成报告不会使任务进入“成果可下载”。
