# 账号能力管理页（2026-10-23）

2026-10-26 新增第四个「使用分析」分区，口径、验证与发布记录见 [C 账号使用分析](USAGE-20261026.md)。

## 入口与权限

- `/app` 左下角仅在当前登录成员为账号 `admin` 且研究实例已开通时显示「能力管理」，跳转 `/manage`。原会话、工作区、数据三视图不变。
- 管理页依次显示「智见数据」「领域包」「专家库」。`/api/capabilities/*` 每次请求重新验证浏览器登录、账号管理员角色和该账号绑定的独立 DSH 实例；写入还需同源 Origin 与 CSRF。分享令牌没有管理权限。
- BFF 只调用固定白名单路由；实例地址由服务端账号绑定决定，域名和服务凭据都不由浏览器提交。设置写入经当前实例的私有 customer gateway 和 DSH settings 服务完成，凭据仅保留在服务端。

## 三个分区

- 智见数据：数据源健康与密钥存在状态，非凭据路径和端点，工具执行模式。
- 领域包：本地包及逐包校验结果、版本中心连接与绑定、安装列表、更新检查、安装/启停/更新启用、全局及逐包更新策略、操作记录。
- 专家库：自定义专家和场景覆盖层的添加/删除、技能 zip 安装、默认模型、逐专家模型覆盖、运行参数。权限区说明账号管理员边界；不向浏览器发管理令牌。
