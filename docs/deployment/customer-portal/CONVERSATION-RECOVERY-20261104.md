# 客户会话状态与恢复修复（2026-11-04）

## 范围

- `REQUEST_EXTENSION`：在 Host 的 `agent/error` 上记录脱敏的 cause 链、错误代码、系统调用和当时注册的请求扩展字段。不会记录请求正文或凭据。
- 会话投影：从持久事件流计算末轮的运行、完成、额度不足、上游限流、扩展失败、参数错误、输出截断和中断状态。客户页按末轮状态显示回执；运行态与实际活动不符且超过 60 秒时提示失去运行状态。
- 输出截断恢复：客户页从账号隔离的 Host 读取恢复检查点，使用持久待办、最近用户要求、此前助手进展、已返回及未返回的工具名称生成续做提示。提示明确要求先核验已有文件和外部写入，再继续剩余步骤；旧会话无待办时使用可见对话兜底。恢复接口须经过门户会话归属和 Host 会话归属两层校验。
- 模型网关：仅在上游明确返回 429、502、503、504 且流尚未开始时最多重试两次；遵循不超过 5 秒的 `Retry-After`，否则短退避。400、401、403、本地额度不足和结果不明的传输错误不重试。一次请求只保留一次额度预留。
- 验收发现 A/B 预设目录只提供 `standard`，但原默认值指向不存在的 `zhijian`。预设列表现返回可用的默认值；A/B 选择 `standard`，C 保留 `zhijian`。
