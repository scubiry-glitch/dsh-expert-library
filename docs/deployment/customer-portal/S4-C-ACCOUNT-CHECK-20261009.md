# C 账号公网链路实测（2026-10-09）

本次使用短时、可撤销的 C 账号浏览器会话，直接验证已部署的客户页和真实 DSH 实例。测试会话已撤销；因此本次不构成开发者中心 OIDC 输入密码与回调流程的验收。

- 公网 `/app` 在 390px 手机视口加载，C 账号研究功能可用。`@` 选择菜单显示智见、贝壳、公开银行行业库，以及待接入的领域包和专家。
- 从页面新建会话 `ec1ddd1c-94d5-4535-80b8-368ef07f8499`，选中 `@数据-bank-industry` 并发送公开库查询。页面先显示“消息已接收 · 正在写入会话”，随后模型实际调用 `localdb.bank-industry.query`，得到所请求的 `bank_code/year/nim` 三行结果和助手回复。
- 刷新后再次选中该会话，数据页显示 5 项调用快照；其中原始 SQL 查询快照有 3 行，表格列为 `bank_code`、`year`、`nim`。手机页面无横向溢出或脚本异常。
- C 登录态读取 B 的会话消息、数据、工作区和报告文件路径均为 404；设置与用量页面能读取 C 的 200 万 token 日限额，页面退出后返回登录视图。
- 模型实际调用产生约 162,495 token 用量（测试前 857,711，测试后 1,020,206）；助手为验证字段与来源做了多次 schema/query 调用，产生 5 项快照。此开销应单独优化。

本次验证了 C 的会话、`@` 查询、数据持久化、移动页面、用量及跨账号拒绝。C 的现有 staged 报告计划缺少正式 `reportBundle`，没有通过正式报告门槛；C 剩余约 98 万 token，本次未启动报告团队，不能据此宣称 C 的报告生成与下载已验收。B 的报告闭环已有独立验收记录。
