# 客户账号积分用量（2026-10-27）

## 规则

- 模型网关的账号级 `tokensPerPoint` 为正整数，表示多少 token 换算 1 积分；未设置的账号沿用 token 展示。比例由平台后台私有配置管理，租户管理员无权自行更改。
- 模型调用仍按上游返回的总 token 结算并受原有 UTC 日 token 额度约束。积分在服务端按账号、按 UTC 日总 token 换算；向用户展示到 0.01 积分，额度和已用分别向上取整，显示剩余为两者之差，避免逐次调用取整带来的额外计量。
- 客户门户的“设置与用量”和管理员的 `/manage#usage` 显示积分的今日已用、每日额度、剩余和近七日记录，并说明当前比例。管理页的能力调用排行榜统计调用次数，与模型积分用量分别展示。模型网关与 BFF 仍保留原始 token 字段供核对。
- 比例变化会重新折算历史**展示值**。现阶段没有积分充值、财务账单或价格版本快照，因此这些数字不能用于金额结算；正式财务扣费需另建不可变费率版本与对账账本。

## 后台设置

在模型网关私有 `MODEL_GATEWAY_CONFIG` 对应账号记录中加入 `"tokensPerPoint": <正整数>`，例如 `1000` 代表 1,000 token = 1 积分。修改前备份配置，修改后重启 `zhijian-model-gateway.service`。不要将包含凭据哈希的完整配置复制到仓库或聊天中。只配置目标账号，其他账号沿用原展示；配置文件缺少字段或值非法时，旧 token 账本不受影响，非法值会阻止服务启动。

验收：网关 `/internal/usage` 的 `points.tokensPerPoint` 与后台设置相符；客户登录后打开 `/app` →“设置与用量”，三个数值和近七日记录显示“积分”；其他账号仍显示其自身的配置与用量。匿名、分享访客与跨账号请求不能读取用量。
