# C 账号使用分析（2026-10-26）

## 产品位置与口径

- `/manage#usage` 是当前账号管理员可见的第四个分区，提供最近 7 天、30 天的专家、Skill、领域包、数据源排行。每项展示成功调用次数和使用过它的不同会话数；调用入口提供版本时按版本拆行。
- 排行归属账号独立的 DSH 实例。Pack Center 继续负责分发、版本与安装，不收录跨租户调用明细；未来如果需要中心视图，应由租户按权限上报聚合数据。
- 采集自本次上线开始，没有历史回补。专家统计已完成的定向问答及任务领取时实际指派的专家；Skill 统计任务材料成功交付；领域包统计定向调用及领域 Skill 交付；数据源统计 provider 成功执行。目录浏览、安装、计划预览和失败调用不计数。
- 只写时间、种类、对象 ID、可选版本、会话 ID 和去重键；不存问题、回答、查询参数、数据内容或用户姓名。事件保存在 C 实例私有的 `DSH_HOME/customer-usage/YYYY-MM-DD.jsonl`；管理 API 只输出聚合排行。

## 授权与链路

浏览器 `GET /api/capabilities/usage?days=7|30` 先通过门户登录和 `admin` 角色检查，然后按账号绑定的实例调用私有 customer gateway。Gateway 仅接受环回请求及服务凭据，参数只允许 7 或 30 天。不同客户使用独立实例和 `DSH_HOME`，浏览器不能传实例地址或账号 ID。

## 现有限制

当前只统计接入上述受控入口的调用。其他 Agent 在宿主机直接读取 Skill 文件、通过未经专家库工具注册的外部工具取数，不会被这四类排行计入。后台未做跨租户汇总，中心视角应在指标口径和租户授权确定后另行开发。

## 2026-10-26 每日截图推送

- `apps/customer-portal/scripts/daily-usage-report.mjs` 每次从 C 实例私有 gateway 读取最近 7 天排行，在无浏览器登录凭据的本地隔离浏览器中渲染实际 `/manage#usage` 页面，生成 PNG；超过企业微信图片上限时改为 JPEG。截图只含聚合数据。
- `zhijian-customer-usage.timer` 每天北京时间 09:00 触发，错过计划时由 systemd 补跑。服务以 `zhijian-portal` 身份运行，失败时最多重试 3 次。Webhook 仅放在宿主机 root 可读的 `/etc/zhijian/customer-usage-webhook.url`，通过 systemd `LoadCredential` 注入；仓库、截图和发送回执不含地址或 key。
- 截图和当日成功发送回执保存在 `/var/lib/zhijian/customer-portal/usage-reports/`，文件权限 0600。当日回执阻止重复推送。首次实发企业微信接口返回成功；再次手动启动服务正常跳过重复发送。次次触发时间可用 `systemctl list-timers zhijian-customer-usage.timer` 核查。
- 首次推送时采集刚上线，四类排行均为空。浏览器无脚本错误，截图约 242 KB；企业微信图片接口回执成功。服务、计时器和门户均正常。
