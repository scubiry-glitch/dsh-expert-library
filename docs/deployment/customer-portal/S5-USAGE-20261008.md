# 客户页 S5：账号用量可见（2026-10-08）

状态：已在 `https://zhijian.meizu.life/app` 发布。“设置与用量”显示当前登录账号的模型 token 日额度、已用、剩余、调用次数和最近七天有调用的日期。配额按 UTC 日重置。额度不足的会话回执提示到此处查看。

## 计量与权限

- 数字直接取模型网关的 `model_calls` 账本与当前服务端配额配置，覆盖该账号所有会话和专家协作调用。运行中或缺少可信上游 usage 的调用保留预留量；上游错误不收费。剩余额度为 `max(0, 配额－已计量)`，单轮预留需求高于剩余额度时仍可被拒绝。
- 浏览器只请求客户 BFF 的 `/api/usage`。BFF 从登录会话解析账号及绑定的 DSH backendRef，再请求仅监听 loopback 的模型网关只读接口。浏览器传入的 `account_id` 参数不参与选账。网关接口须提供服务器间只读凭据，且只能访问配置中的账号。此凭据存放在受限文件中，不包含在网页和仓库里。
- C 的客户展示名 `zhijian` 对应模型网关账号 `zhijian-demo-c`；计费映射以账号绑定的 backendRef 为准，不以展示名猜测。
- UI 仅展示用量；修改额度继续由服务端账号配置控制。当前数据表示 token 消耗，不代表费用或上游账单。动态发放额度、账单对账与管理员操作界面未纳入本阶段。
