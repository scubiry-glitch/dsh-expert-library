# 领域包中心验收样例

这些样例直接符合现有 V2 领域包加载结构，使用完整单文件 `pack.json`；不需要先执行 v1 adapt。

| 目录 | 预期 | 用途 |
|---|---|---|
| demo-v1 | 校验通过，1.0.0 | 首次提交/安装，公开名称“样例 V1” |
| demo-v2 | 校验通过，1.1.0 | 同包更新，公开名称“样例 V2” |
| invalid | 校验失败 | 验证错误报告，不能提交发布 |

两个合法版本均包含一个专家、一个场景和对应团队、输出、质量模板；无工具提供方、无真实数据、无凭据、无执行脚本。

`digest-vectors.json` 固定三个目录的协议 v1 内容摘要、文件数与未归档字节数，供中心、离线工具和插件交叉验证；它不属于任何一个包的文件树。改变夹具内容时须明确更新向量，不在测试运行时自动重写预期值。内容摘要能证明字节一致，不能把非法夹具变成合法包。

中心首版只接收包位于根目录的公开 Git 来源。请将 demo-v1 的内容放到测试仓库根目录，提交并标记版本；然后用 demo-v2 内容形成下一版本。此处目录仅是夹具，不是已发布或已获审核的中心产物。
